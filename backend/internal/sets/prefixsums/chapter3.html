Difference Array прибавляет число ко всему отрезку двумя изменениями, а одна Prefix Sum в конце восстанавливает все значения.

1. Много прибавлений на отрезках

Вход: Array a из n = 6 нулей, номера с 0. Нужны три прибавления: +2 на [1, 3], +5 на [2, 5] и +1 на [0, 0]. Оба конца отрезка входят. Значения читают только после всех прибавлений.

Прямой цикл проходит по каждому месту отрезка: 3 + 4 + 1 = 8 прибавлений. После них a = [1, 2, 7, 7, 5, 5]. Проверим место 2: его покрывают +2 и +5, получается 7.

В худшем случае каждый из m отрезков покрывает весь Array, и прямой цикл делает n · m прибавлений. В LeetCode 1109 и n, и число бронирований до 2 · 104: 20 000 · 20 000 = 4 · 108 прибавлений. Лимит 2 с на пример, 3 с на скрытый тест: Python не успеет.

Время: O(сумма длин отрезков), в худшем случае O(n · m). Дополнительная память: O(1) сверх a.

2. Две отметки вместо отрезка

Заведём список d длины n + 1 = 7 из нулей. Для прибавления v на [l, r] поставим две отметки: d[l] += v в начале отрезка и d[r + 1] -= v сразу после его конца. Prefix Sum по d прибавит v на каждом месте от l до r. С места r + 1 плюс и минус вместе дают 0.

+2 на [1, 3]: d[1] = 2 и d[4] = −2. +5 на [2, 5]: d[2] = 5 и d[6] = −5. +1 на [0, 0]: d[0] = 1 и d[1] = 2 − 1 = 1. Итог d = [1, 1, 5, 0, -2, 0, -5]. Prefix Sum первых n чисел: 1, 1 + 1 = 2, 2 + 5 = 7, 7 + 0 = 7, 7 − 2 = 5, 5 + 0 = 5. Это тот же a = [1, 2, 7, 7, 5, 5].

Правило. Чтобы прибавить v ко всем a[l..r], сделайте d[l] += v и d[r + 1] -= v. В конце a[i] = d[0] + d[1] + ... + d[i]. Длина d равна n + 1: при r = n − 1 запись идёт в d[n].

n = 6
ops = [(1, 3, 2), (2, 5, 5), (0, 0, 1)]
d = [0] * (n + 1)
for l, r, v in ops:
    d[l] += v
    d[r + 1] -= v
print(d)
a = []
s = 0
for i in range(n):
    s += d[i]
    a.append(s)
print(a)

Программа печатает [1, 1, 5, 0, -2, 0, -5] и [1, 2, 7, 7, 5, 5]. Последнее число d[6] = −5 в a не входит: оно только закрывает отрезок [2, 5], который кончается на последнем месте.

Время: 2 изменения на прибавление и n сложений в конце, O(n + m). Дополнительная память: d из n + 1 чисел, O(n). Ответ отдельно: n чисел.

На маленьком входе прямой цикл даже короче: 8 операций против 12. Выигрыш начинается на длинных отрезках, потому что цена двух отметок не зависит от длины отрезка.

3. Difference Array и Prefix Sum: обратные действия

Откуда название. Возьмём готовый a = [1, 2, 7, 7, 5, 5] и запишем разности соседей: d[0] = a[0] и d[i] = a[i] − a[i − 1] для i ≥ 1. Получим d = [1, 1, 5, 0, −2, 0]: те же числа, что в разделе 2, без последней отметки. Prefix Sum этих разностей снова даёт a: 1, 2, 7, 7, 5, 5.

Prefix Sum и Difference Array обратны друг другу, как сложение и вычитание. Прибавление v на [l, r] меняет только две разности: на входе в отрезок разность растёт на v, на выходе из него падает на v. Разности внутри отрезка не меняются, потому что соседи внутри получили одну и ту же прибавку.

Если a в начале не из нулей, проще копить в d только прибавки. Одна Prefix Sum по d даёт прибавку каждого места, и в конце a[i] получает свою прибавку. Так сделано в Codeforces 295A в разделе 6.

4. Годы: начало и конец

LeetCode 1854: для каждого человека даны год рождения birth и год смерти death. Человек жив в годы birth..death − 1: год смерти не считается. Это отрезок [birth, death − 1], поэтому минус ставят в d[death − 1 + 1] = d[death]. Годы от 1950 до 2050 дают Y = 101 место: год y хранится в d[y − 1950].

logs = [[1950, 1961], [1960, 1971], [1970, 1981]]. Население 1 в 1950..1959, 2 в 1960, 1 в 1961..1969, 2 в 1970 и 1 в 1971..1980. Наибольшее население 2, первый такой год 1960. Знак >, а не ≥, при сравнении с лучшим оставляет самый ранний год.

logs = [[1950, 1961], [1960, 1971], [1970, 1981]]
d = [0] * 101
for b, e in logs:
    d[b - 1950] += 1
    d[e - 1950] -= 1
best, year, s = 0, 1950, 0
for i in range(101):
    s += d[i]
    if s > best:
        best, year = s, 1950 + i
print(year, best)

Программа печатает 1960 2. В 1970 году население тоже 2, но 2 > 2 неверно, и ответ остаётся 1960. Год смерти не больше 2050, поэтому d[e − 1950] не выходит за место 100.

Время: 2 изменения на человека и Y сложений, O(n + Y). Дополнительная память: O(Y), здесь 101 число. Ответ отдельно: одно число.

5. Две Prefix Sum подряд

Codeforces 816B: n рецептов, рецепт советует температуры [l, r]. Температура допустима, если её советуют не меньше k рецептов. На каждый вопрос [a, b] нужно число допустимых температур в нём. Температуры от 1 до T = 200 000, номера с 1.

Первый пример: рецепты [91, 94], [92, 97], [97, 99], k = 2. Difference Array по температурам даёт число рецептов для каждой температуры. Два рецепта советуют 92, 93, 94 и 97, остальные температуры получают один рецепт или ни одного. Поставим 1 для допустимой температуры и 0 для остальных. Вторая Prefix Sum c по этим отметкам: c[t] это число допустимых температур от 1 до t.

Вопрос [93, 97]: c[97] − c[92] = 4 − 1 = 3. Это 93, 94 и 97, как в примечании к задаче. Вопрос [90, 100]: c[100] − c[89] = 4 − 0 = 4, все допустимые температуры.

Правило. Сначала Difference Array: сколько отрезков покрывают каждую точку. Потом отметки 0 и 1 и Prefix Sum по ним: сколько подходящих точек на отрезке.

Номера здесь с 1, поэтому вопрос [a, b] стоит c[b] − c[a − 1], как в Codeforces 1807D из главы 1. Отметка d[r + 1] при r = 200 000 попадает в d[200 001], поэтому длина d равна T + 2.

Время: 2 изменения на рецепт, по T сложений на каждую Prefix Sum и одно вычитание на вопрос, O(n + T + q). Дополнительная память: d и c, O(T). Ответ отдельно: q чисел. Подсчёт по каждой температуре каждого вопроса стоит O(q · T), до 200 000 · 200 000 = 4 · 1010.

6. Difference Array два раза

Codeforces 295A: Array a, m операций «прибавить d на [l, r]» и k запросов «применить операции с x по y». Номера с 1. Первый пример: a = [1, 2, 3], операции (1, 2, 1), (1, 3, 2), (2, 3, 4), запросы [1, 2], [1, 3], [2, 3].

Запрос прибавляет 1 к отрезку номеров операций. Это тот же Difference Array, только по номерам операций: cnt = [2, 3, 2], операцию 2 применяют три запроса. Применять операцию i cnt[i] раз не нужно: одно прибавление d · cnt[i] даёт то же. Получаем 1 · 2 = 2 на [1, 2], 2 · 3 = 6 на [1, 3] и 4 · 2 = 8 на [2, 3].

Второй Difference Array по номерам элементов собирает эти прибавки: [8, 16, 14]. Ответ [1 + 8, 2 + 16, 3 + 14] = [9, 18, 17].

В коде номера с 1 переходят в места с 0. Запрос [x, y] ставит +1 в cd[x − 1] и −1 в cd[y]. Операция [l, r] ставит отметки в ad[l − 1] и ad[r].

cd = [0] * (m + 1)
for x, y in queries:
    cd[x - 1] += 1
    cd[y] -= 1
ad = [0] * (n + 1)
cnt = 0
for i in range(m):
    cnt += cd[i]
    l, r, d = ops[i]
    ad[l - 1] += d * cnt
    ad[r] -= d * cnt
s = 0
for i in range(n):
    s += ad[i]
    a[i] += s

Время: 2k + 2m изменений, m + n сложений Prefix Sum и n прибавлений к a, O(n + m + k). Дополнительная память: cd и ad, O(n + m). Ответ отдельно: n чисел. Прибавка к одному элементу бывает до 105 · 105 · 105 = 1015, int Python хранит такое число без переполнения. Прямое применение операций стоит O(k · m · n) в худшем случае.

Когда Difference Array не подходит

Если чтения идут между прибавлениями, каждое чтение a[i] складывает d[0..i]: до n сложений, всего O(n · q). Пример: после каждого из 3 прибавлений раздела 1 прочитать a[5]. Это 3 прохода по 6 числам d вместо одного прохода в конце. Difference Array хорош, когда сначала идут все прибавления, а потом все чтения.

7. Что нужно запомнить

  • Прибавление v на [l, r]: d[l] += v и d[r + 1] -= v. Длина d равна n + 1.
  • Prefix Sum по d восстанавливает значения: O(n + m) вместо O(n · m).
  • Человек жив в годы birth..death − 1, поэтому минус ставят прямо в d[death].
  • Число покрытий точки и число подходящих точек на отрезке: две Prefix Sum подряд.

8. Как решать задачи этой главы

  1. Запишите отрезок прибавления: номера с 0 или с 1, входит ли правый конец.
  2. Поставьте две отметки и проверьте отрезок, который кончается в последней точке.
  3. Восстановите значения одной Prefix Sum, затем считайте ответ.
  4. Посчитайте наибольшее значение и размер ответа.
