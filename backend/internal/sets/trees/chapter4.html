Между двумя вершинами Tree ровно один путь, и два обхода BFS находят самый длинный из таких путей, диаметр, а его середина даёт центр.

1. Путь между двумя вершинами

В главе 1 мы видели: между любыми двумя вершинами Tree есть ровно один путь. Теперь найдём сам путь. Возьмём Tree T: рёбра 0 − 1, 0 − 2, 1 − 3, 1 − 4, 2 − 5, 4 − 6. Нужен путь от вершины 3 до вершины 5.

Сделаем BFS от вершины 3, а не от корня 0. BFS записывает в parent[u] вершину, из которой он пришёл в u. Эта вершина на один шаг ближе к 3. Получаем parent = [1, 3, 0, -1, 1, 2, 4] и dist = [2, 1, 3, 0, 2, 4, 3]: у старта 3 родителя нет, там −1.

Теперь идём от 5 по parent: 5 → 2 → 0 → 1 → 3. Каждый шаг приближает нас к 3 на одно ребро, поэтому подъём закончится в 3. Список получился от конца к началу. После разворота путь [3, 1, 0, 2, 5]: 5 вершин и 4 ребра. Это и есть dist[5] = 4.

from collections import deque

adj = [[1, 2], [0, 3, 4], [0, 5], [1], [1, 6], [2], [4]]
s, t = 3, 5
parent = [-1] * len(adj)
q = deque([s])
while q:
    v = q.popleft()
    for u in adj[v]:
        if u != parent[v]:
            parent[u] = v
            q.append(u)
path = [t]
while path[-1] != s:
    path.append(parent[path[-1]])
path.reverse()
print(path)

Код печатает [3, 1, 0, 2, 5]. Рисунок показывает BFS от 3 и подъём от 5.

Правило. Чтобы найти путь s → t, сделайте BFS от s и идите от t по parent до s. Число рёбер пути равно dist[t].

Так устроена задача LeetCode 2467. BFS от 0 даёт parent и глубину каждой вершины, и Алиса стоит в вершине v в момент depth[v]. Боб идёт bob → parent[bob] → ... → 0 и стоит в i-й вершине этого подъёма в момент i. В T при bob = 6 Боб проходит 6, 4, 1, 0 в моменты 0, 1, 2, 3. В вершине 1 Алиса в момент 1, раньше Боба, и берёт всё amount[1]. В вершине 4 она в момент 2, позже Боба, и не получает ничего. При равных моментах каждый получает половину.

На T BFS снимает 7 вершин из Deque, а подъём делает 4 шага.

Время: O(n) для BFS и O(длины пути) для подъёма. Дополнительная память: O(n) для parent, dist и Deque; путь до n вершин.

2. Диаметр двумя BFS

Диаметр Tree - число рёбер самого длинного пути между двумя вершинами. Сначала найдём его на T двумя обходами BFS.

BFS от 0 даёт расстояния [0, 1, 1, 2, 2, 2, 3]. Самая дальняя вершина 6, до неё 3 ребра. Теперь BFS от 6: [3, 2, 4, 3, 1, 5, 0]. Самая дальняя вершина 5, до неё 5 рёбер. Диаметр T равен 5, это путь 6, 4, 1, 0, 2, 5. В главе 3 мы получили те же 6 вершин через top1 + top2 у корня.

from collections import deque

adj = [[1, 2], [0, 3, 4], [0, 5], [1], [1, 6], [2], [4]]


def far(s):
    dist = [-1] * len(adj)
    dist[s] = 0
    q = deque([s])
    last = s
    while q:
        v = q.popleft()
        last = v
        for u in adj[v]:
            if dist[u] == -1:
                dist[u] = dist[v] + 1
                q.append(u)
    return last, dist[last]


a, da = far(0)
b, d = far(a)
print(a, da)
print(b, d)

Код печатает «6 3» и «5 5». BFS снимает вершины из Deque по возрастанию расстояния. Поэтому последняя снятая вершина last - самая дальняя, и отдельный поиск максимума не нужен.

В задаче Codeforces 690C2 «задержка мозга» - это диаметр. Один BFS даёт только высоту при своём корне: для T от вершины 0 это 3, а диаметр 5.

Правило. Самая дальняя вершина от любой вершины - конец некоторого диаметра. Второй BFS от неё находит второй конец и длину диаметра.

Почему первый BFS находит конец диаметра

Начнём не с 0, а с 3. Самая дальняя от 3 вершина 5, до неё 4 ребра. BFS от 5 находит вершину 6 на расстоянии 5: тот же диаметр 6, 4, 1, 0, 2, 5, только с другого конца.

Идея доказательства. Пусть a − b - диаметр, а x - последняя вершина этого диаметра на пути от s до самой дальней вершины u. Назовём a тот конец диаметра, путь к которому от s идёт через x. Вершина u - самая дальняя от s, поэтому от x до u не меньше рёбер, чем от x до a. Тогда путь u − x − b не короче диаметра a − x − b, то есть тоже диаметр. Случай, когда путь от s до u не задевает a − b, разбирают так же.

Время: O(n): 2 BFS, по 7 popleft и 12 чтений соседей. Дополнительная память: O(n): dist из 7 чисел, в Deque не больше 3 вершин. BFS от каждой вершины: n обходов, O(n²): здесь 49 посещений, при n = 20 000 уже 4 · 108. Проверка даёт 3 с на скрытый тест, а Python делает около 107 простых шагов в секунду, поэтому O(n²) не успеет.

3. Центр и наименьшая высота

Высота Tree с корнем r - наибольшее расстояние от r до других вершин. У T при корне 0 высота 3. Высоты для корней 0, 1, ..., 6 равны 3, 3, 4, 4, 4, 5, 5. Наименьшая высота 3 у корней 0 и 1. Такие вершины называют центрами.

Центры лежат в середине диаметра. Путь 6, 4, 1, 0, 2, 5 имеет d = 5 рёбер и 6 вершин. В середине две вершины, 1 и 0. От каждой из них до дальнего конца 3 ребра: 3 = (5 + 1) / 2. У пути 0 − 1 − 2 − 3 − 4 диаметр d = 4 и середина одна, вершина 2, высота 2 = 4 / 2.

Запись ⌈d / 2⌉ значит «d / 2 с округлением вверх»: ⌈5 / 2⌉ = 3, ⌈4 / 2⌉ = 2. В Python это (d + 1) // 2.

Правило. Центр лежит в середине диаметра. При чётном d центр один, высота d / 2. При нечётном d центров два, высота (d + 1) / 2.

Чтобы найти центры, восстановите путь диаметра по parent второго BFS, как в разделе 1, и возьмите вершину d // 2 шагов от конца (с округлением вниз), а при нечётном d ещё следующую: для d = 5 это 2 шага, вершины 0 и 1. В LeetCode 310 ответ - это центры.

В LeetCode 3203 два Tree соединяют одним ребром. Выгоднее всего соединить их центры. Тогда новый диаметр max(d1, d2, ⌈d1 / 2⌉ + ⌈d2 / 2⌉ + 1): самый длинный путь остаётся внутри одного Tree или идёт от дальнего конца первого Tree через новое ребро к дальнему концу второго. T (d1 = 5) и путь из 4 вершин (d2 = 3): 3 + 2 + 1 = 6, и это больше 5 и 3. Ответ 6.

Время: O(n): 2 BFS по 7 popleft и 5 шагов подъёма по пути диаметра. Дополнительная память: O(n): dist и parent по 7 чисел, путь из 6 вершин.

Центры можно найти и без диаметра: срезать листья слоями. Удаляем все листья, у их соседей степень уменьшается, появляются новые листья. Когда осталось 1 или 2 вершины, это центры. T теряет листья 3, 5, 6, затем 2 и 4. Остаются вершины 0 и 1.

Каждую вершину удаляют один раз, и каждое ребро уменьшает степень один раз: время O(n), дополнительная память O(n) для степеней и слоя листьев.

Ответ для каждого корня

Иногда нужен ответ для каждого корня, например сумма расстояний от корня до всех вершин. Возьмём путь 0 − 1 − 2 − 3. Сумма от 0: 0 + 1 + 2 + 3 = 6. Перенесём корень в 1. Три вершины 1, 2, 3 стали на 1 ближе, одна вершина 0 стала на 1 дальше: 6 − 3 + 1 = 4. Проверка: 1 + 0 + 1 + 2 = 4.

При переходе от корня p к ребёнку c сумма меняется на n − 2 · size[c], где size - размеры поддеревьев из главы 2. Для пути 0 − 1 − 2 − 3 с корнем 0 size[1] = 3, и 4 − 2 · 3 = −2: сумма 6 − 2 = 4. Поэтому ответ для всех корней считают за O(n), а не n обходами за O(n²). Подробнее - в ссылке «Ответ для каждого корня».

4. Листья и сжатие путей

В Codeforces 1905B одна операция сжимает путь в одну вершину. В Tree без корня лист - вершина степени 1. Внутренняя вершина пути имеет на пути двух соседей, её степень не меньше 2, и она не лист. Листьями могут быть только два конца пути. Поэтому одна операция убирает не больше 2 листьев.

У T листья 3, 5 и 6, их L = 3. Две операции нужны: одна убирает не больше 2 листьев. Двух хватает: сожмём путь 3, 1, 0, 2, 5 в вершину w, останется путь w − 4 − 6, и вторая операция сожмёт его.

Правило. Если операция сжимает путь, листьями на нём могут быть только два конца: одна операция убирает не больше 2 листьев, поэтому L листьев требуют не меньше ⌈L / 2⌉ операций.

Можно доказать, что ⌈L / 2⌉ операций всегда хватает, но здесь мы это не доказываем. Поэтому достаточно посчитать степени. Частая ошибка: выбрать корень 1 и считать листьями только вершины без детей. В Tree с рёбрами 2 − 1, 2 − 3, 2 − 4 вершина 1 тоже лист: листьев 3, ответ 2, а не 1.

degree = [0] * (n + 1)
for u, v in edges:
    degree[u] += 1
    degree[v] += 1
leaves = degree.count(1)
print((leaves + 1) // 2)

Для звезды с центром и 7 листьями ответ (7 + 1) // 2 = 4.

Время: O(n): для T 6 рёбер и 12 прибавлений к degree. Дополнительная память: O(n): n + 1 счётчиков, для T их 8.

5. Что нужно запомнить

  • Путь s → t: BFS от s и подъём по parent от t.
  • Диаметр: BFS от любой вершины, затем BFS от самой дальней.
  • Центр - середина диаметра, высота ⌈d / 2⌉.
  • Сжатие пути убирает не больше 2 листьев, потому что листьями на пути могут быть только его концы: ответ не меньше ⌈L / 2⌉.

6. Как решать задачи этой главы

  1. Решите, что нужно: один путь, самый длинный путь, центр или число листьев.
  2. Для одного пути сделайте BFS и восстановите путь по parent.
  3. Для диаметра и центра сделайте два BFS и найдите середину пути.
  4. Если операция сжимает путь, посчитайте листья по степеням.
