Из набора [100, 10000] можно взять первое число, второе или оба сразу. Каждую из n позиций можно оставить или пропустить. Если исключить пустой выбор, получится 2n − 1 вариантов. На наборе из 100 единиц Brute Force проверит все 2100 − 1 произведений, потому что каждое равно 1. Это больше 1030 проверок.

Проверка отдельных чисел

В наборе [1, 5, 4] оставим только 5. Это число лежит между соседними квадратами 22 = 4 и 32 = 9. Произведение из одного числа равно самому числу, поэтому ответ YES. В наборе [2, 2] произведение всех чисел равно 4. Одна двойка даёт произведение 2, так что и здесь ответ YES.

Во втором наборе из условия 100 = 102 и 10000 = 1002. Если взять оба числа, получится 102 · 1002 = (10 · 100)2. Запишем каждый выбранный квадрат как произведение двух одинаковых целых множителей. Если взять по одному множителю из каждой пары, их произведение будет целым числом, а остальные множители дадут такое же число. Значит, произведение выбранных квадратов тоже квадрат. Если каждый элемент набора оказался квадратом, ответ NO.

Для x = 5 функция isqrt(x) возвращает r = 2, целую часть квадратного корня. Квадрат r · r = 4 отличается от x, поэтому код меняет ответ на YES и выходит из цикла по числам. Для x = 100 получаем r = 10. Равенство r * r == x означает, что x есть квадрат целого числа r. Функция isqrt(x) находит наибольшее целое r с условием r2 ≤ x, поэтому r2 ≤ x < (r + 1)2. Между r и r + 1 других целых чисел нет, поэтому при r * r != x число x не равно квадрату ни одного целого числа.

Таблица показывает ответы Brute Force: наборы [3] и [5] дают YES, а [4] даёт NO.

from math import isqrt

t = int(input())
for _ in range(t):
    n = int(input())
    parts = input().split()
    answer = "NO"
    for part in parts:
        x = int(part)
        r = isqrt(x)
        if r * r != x:
            answer = "YES"
            break
    print(answer)

Во втором наборе цикл проверяет и 100, и 10000. В наборе из n квадратов цикл проверит все n чисел. По условию x ≤ 104, поэтому каждая проверка занимает O(1) времени. Обозначим через S общее количество элементов во всех наборах, а через m длину самого большого набора.

Время: в худшем случае O(n) на один набор и O(S) на весь ввод. Дополнительная память: в худшем случае O(n) для отдельного набора и O(m) за весь запуск. После split() список parts хранит n строк длиной не более пяти цифр каждая. Программа печатает ответ сразу после обработки набора.
