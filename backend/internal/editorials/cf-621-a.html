В первом примере 1 + 2 + 3 = 6. Сумма уже чётная. Все числа положительные, поэтому без любого из них сумма станет меньше.

Во втором примере сумма нечётная: 5 · 999999999 = 4999999995. Уберём одно число и получим 4999999995 − 999999999 = 3999999996.

Числа 5 и 3 можно взять оба: 5 + 3 = 8. Если добавить 7, получим нечётную сумму 15. Уберём 3 и получим 15 − 3 = 12. Если убрать 5, останется 10, а без 7 получится 8. Если дано только число 3, чётную сумму 0 даёт лишь пустой набор.

Сумма чётных чисел всегда чётна. Поэтому при нечётной общей сумме среди данных чисел есть хотя бы одно нечётное. Чтобы из нечётной суммы получить чётную, нужно вычесть нечётную сумму. Значит, среди убранных чисел должно быть хотя бы одно нечётное. Наименьшее нечётное число выгодно убрать одно: оно меняет чётность, а потерять меньше нельзя. Если дано только число 7, убираем его и получаем 0.

За один проход запомним сумму в total и наименьшее нечётное число в smallest_odd. Если total % 2 == 1, то smallest_odd уже хранит нечётное число, а не None.

import sys

n = int(sys.stdin.readline())
tokens = sys.stdin.readline().split()
total = 0
smallest_odd = None
for token in tokens:
    value = int(token)
    total += value
    if value % 2 == 1 and (smallest_odd is None or value < smallest_odd):
        smallest_odd = value

if total % 2 == 1:
    total -= smallest_odd
print(total)

Время: O(n) в худшем случае для всего ввода: программа читает один набор из n чисел и проверяет каждое. Дополнительная память: O(n) в худшем случае для этого набора и всей программы. При чтении в памяти находятся строка ввода и список из n частей. Каждая часть занимает не более десяти цифр, поскольку число не больше 109. Программа печатает одно число длиной не более пятнадцати цифр: сумма не превышает 100000 · 109 = 1014.
