Проверка через целую часть корня

В первом примере 22 = 4, поэтому пропускаем 4. Число 2 лежит между квадратами 1 и 4, поэтому ответ равен 2.

Для числа 8 функция isqrt даёт 2, потому что 22 ≤ 8 < 32. Для неотрицательного x она находит наибольшее целое root, квадрат которого не превышает x. Если root · root < x, то следующий квадрат уже больше x.

Во втором примере остаются 2, 8 и 32. После каждого такого числа сохраняем в best большее из него и прежнего ответа. После последнего числа в best остаётся наибольшее из подходящих чисел: 32.

Для пары −1 и 0 ответ равен −1: отрицательное число подходит сразу, а 02 = 0. Поэтому начинать с нуля нельзя. Начнём с нижней границы −106: любое подходящее число не меньше неё, а хотя бы одно такое число есть по условию.

Для трёх чисел −4, −2 и 0 пропускаем 0, а из −4 и −2 большее равно −2. Для двух чисел 8 и 9 пропускаем квадрат 9 = 32 и получаем ответ 8. Для трёх чисел 10, 9 и 8 тоже пропускаем 9, а число 10 лежит между квадратами 9 и 16, поэтому выбираем 10.

from math import isqrt

n = int(input())
words = input().split()
best = -10**6
for word in words:
    x = int(word)
    if x >= 0:
        root = isqrt(x)
        if root * root == x:
            continue
    best = max(best, x)
print(best)

Время: O(n) в худшем случае: для каждого из n чисел проверка занимает O(1) при заданной границе 106. Дополнительная память: O(n) в худшем случае: при вызове split() в памяти есть строка ввода и список из n коротких строк. Программа решает один случай и печатает одно число, поэтому вывод занимает O(1) памяти.

Brute Force: проверка целых корней

Для 4 проверяем квадраты 0, 1 и 4: равенство обнаружится только на самом корне 2. Начнём с root = 0 и будем прибавлять единицу, пока квадрат меньше x. Если при остановке квадрат больше x, равенства уже не будет: дальше квадраты только растут. Для отрицательного x цикл сразу остановится на нуле, и число попадёт в сравнение с best.

n = int(input())
words = input().split()
best = -10**6
for word in words:
    x = int(word)
    root = 0
    while root * root < x:
        root += 1
    if root * root != x:
        best = max(best, x)
print(best)

Время: O(n · √M) в худшем случае, где M = 106 задаёт верхнюю границу числа. При n = 1000 цикл сделает не более 1000 · 1000 = 106 прибавлений за весь ввод. Дополнительная память: O(n) в худшем случае: при вызове split() в памяти есть строка ввода и список из n коротких строк. Программа решает один случай и печатает одно число, поэтому вывод занимает O(1) памяти.
