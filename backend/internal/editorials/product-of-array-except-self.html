Для каждого места i нужно перемножить все числа nums, кроме числа на этом месте.

Решение 1. Prefix Product слева и справа

Возьмите пример 1: nums = [1, 2, 3, 4]. Для места 2 нужно 1 · 2 · 4 = 8. Слева от места 2 стоят числа 1 и 2, их произведение 2. Справа стоит одно число 4. Ответ это произведение двух частей: 2 · 4 = 8. Число nums[2] = 3 не входит ни в левую часть, ни в правую.

Для мест 0, 1, 2, 3 левые произведения равны 1, 1, 2, 6, а правые 24, 12, 4, 1. Слева от места 0 чисел нет, справа от места 3 тоже. Для пустой части берём 1: умножение на 1 не меняет другую часть. По местам получается 1 · 24 = 24, 1 · 12 = 12, 2 · 4 = 8 и 6 · 1 = 6.

Правило. ans[i] равно произведению чисел слева от места i, умноженному на произведение чисел справа от места i.

Левое произведение не нужно считать заново для каждого места. Для места 2 оно равно 1 · 2 = 2, а для места 3 оно равно 1 · 2 · 3 = 6. Разница в одном множителе: 6 = 2 · nums[2]. Переменная left хранит произведение начала nums, это Prefix Product. Первый цикл идёт слева направо. На месте i он пишет ans[i] = left, а потом умножает left на nums[i]. Перед записью переменная left равна произведению чисел на местах от 0 до i − 1: это левая часть места i. При i = 0 таких чисел нет, и left = 1. После умножения она равна произведению чисел на местах от 0 до i: это левая часть места i + 1. После первого цикла ans = [1, 1, 2, 6]. Отдельный список для левых частей не нужен: они уже лежат в ans.

Второй цикл идёт справа налево и хранит в right произведение конца nums. Перед строкой ans[i] *= right переменная right равна произведению чисел на местах от i + 1 до последнего: это правая часть места i. В ans[i] лежит левая часть, и строка умножает её на правую. Например, на месте 2 перед этой строкой right = 4 и ans[2] = 2, а после неё ans[2] = 8. Число nums[i] попадает в left и в right только после работы с ans[i], поэтому в ans[i] его нет.

Ноль не требует отдельной ветки. В примере 2 nums = [-1, 1, 0, -3, 3], ноль стоит на месте 2. Первый цикл даёт ans = [1, -1, -1, 0, 0]: ноль входит в левую часть мест 3 и 4. Во втором цикле перед строкой ans[i] *= right переменная right на местах 4, 3, 2, 1, 0 равна 1, 3, −9, 0, 0: ноль входит в правую часть мест 1 и 0. У места 2 ноль не входит ни в одну часть, и ans[2] = (−1) · (−9) = 9. Ответ [0, 0, 9, 0, 0].

class Solution:
    def productExceptSelf(self, nums: list[int]) -> list[int]:
        n = len(nums)
        ans = [1] * n
        left = 1  # произведение чисел слева от места i
        for i in range(n):
            ans[i] = left
            left *= nums[i]
        right = 1  # произведение чисел справа от места i
        for i in range(n - 1, -1, -1):
            ans[i] *= right
            right *= nums[i]
        return ans

Время: n - длина nums. Первый цикл делает n записей в ans и n умножений left. Второй цикл делает n умножений ans[i] *= right и n умножений right. Всего 3n умножений, O(n) на каждом входе. В примере 2 это 15 умножений. Дополнительная память: n, i, left и right, O(1). Ответ отдельно: список ans из n чисел.

По условию произведение каждого начала и каждого конца nums помещается в 32-битное число. Переменные left и right принимают только такие значения, а ans[i] хранит левую часть и потом ответ, который по условию тоже помещается в 32-битное число. Поэтому в C++ для них хватает типа int.

Что не подходит

Brute Force для каждого места перемножает остальные n − 1 чисел: n(n − 1) умножений, O(n²). В примере 2 это 5 · 4 = 20 умножений. При n = 105 это 9 999 900 000 умножений: слишком долго.

Другая идея: поделить произведение всех чисел на nums[i]. В примере 1 произведение всех чисел равно 24, и 24 / 3 = 8 совпадает с ans[2]. В примере 2 оно равно 0. Для места 2 нужно делить 0 на nums[2] = 0, и Python останавливается с ошибкой ZeroDivisionError. Верный ответ для места 2 равен 9. Условие тоже запрещает деление.

Два отдельных списка, для левых и для правых произведений, дают верный ответ за O(n) времени. Они хранят 2n чисел: это O(n) дополнительной памяти вместо O(1).

Типичные ошибки

  • Начальное значение 0, как у суммы. При left = 0 каждое умножение даёт 0, и в примере 1 код возвращает [0, 0, 0, 0]. У произведения начальное значение 1.
  • Умножение перед записью: сначала left *= nums[i], потом ans[i] = left. Тогда nums[i] входит в свой ответ. В примере 1 первый цикл даёт [1, 2, 6, 24], и код возвращает [24, 24, 24, 24].
  • Второй цикл for i in range(n - 1, 0, -1). Он заканчивается на месте 1. В примере 1 в ans[0] остаётся 1 вместо 24, и код возвращает [1, 12, 8, 6].
