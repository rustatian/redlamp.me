Для второй клетки второй строки берём по единице сверху и слева. Получаем 1 + 1 = 2, а в следующей клетке справа уже 1 + 2 = 3.

Сохраним первую строку в списке row = [1, 1, 1]. После записи двойки в нём будет [1, 2, 1]. Для следующей клетки row[2] ещё хранит единицу сверху, а row[1] уже хранит двойку слева.

При любой ширине n начинаем с n единиц. В каждой новой строке оставляем первую единицу на месте и идём слева направо. К прежнему значению row[j] прибавляем число новой строки row[j - 1]. К концу прохода в списке готова вся новая строка.

В правом нижнем углу таблицы 3 × 3 получаем 3 + 3 = 6, а во втором примере 35 + 35 = 70. Все числа положительны, ведь мы начинаем с единиц и только складываем. Поэтому ниже первой строки и правее первого столбца число больше соседей сверху и слева. Вдоль верхней строки и левого столбца стоят единицы. Из любой клетки можно дойти до правого нижнего угла шагами вправо и вниз. При таких шагах число не уменьшается, поэтому последнее число row[-1] и есть максимум.

При n = 1 верхний левый и нижний правый углы совпадают. Цикл по строкам пуст, поэтому сложений 0, а правый нижний угол и максимум всей таблицы равны 1. При n = 2 нужно 1 сложение, а при n = 3 уже 4 сложения. В этих таблицах правый нижний угол и максимум совпадают: 2 и 6 соответственно.

n = int(input())
row = [1] * n
for i in range(1, n):
    for j in range(1, n):
        row[j] += row[j - 1]
print(row[-1])

Время: O(n · n) в худшем случае. При n = 10 нужно 9 · 9 = 81 сложение. Сначала записываем n единиц. В каждой из n − 1 остальных строк выполняем по n − 1 сложений. Дополнительная память: O(n) в худшем случае. В списке row ровно n мест для чисел. Список [1] нужен только при создании row. Число n, номера i и j, границы и позиции двух циклов и очередная сумма занимают O(1) памяти. Строка от input() нужна лишь для чтения числа n длиной до двух цифр. Для вывода print превращает ответ в строку и добавляет перевод строки. Даже у наибольшего ответа 48620 всего пять цифр. Ввод задаёт одну таблицу, поэтому обе оценки относятся и ко всему запуску.
