Нужно выписать каждый порядок чисел nums по одному разу. Пусть n будет длиной nums. В примере 1 первое место можно занять 3 числами, второе 2 оставшимися, третье последним: 3 · 2 · 1 = 6 ответов. Для n чисел ответов n!, при n = 6 это 720.

Решение 1. Backtracking

Ответ строим слева направо. List path хранит уже выбранные числа, а used[i] равно True, пока nums[i] лежит в path. Вызов dfs(path) пробует каждое свободное число на следующее место в три шага. Выбрать: used[i] = True и path.append(nums[i]). Пойти глубже: dfs(path). Отменить: path.pop() и used[i] = False. Когда в path лежат все n чисел, копия path[:] идёт в res.

Возьмите пример 1, nums = [1, 2, 3]. Рисунок показывает первые 7 из 16 вызовов. В вызове dfs([1]) пометка used[0] равна True, поэтому цикл пропускает число 1 и пробует только 2 и 3. Так ни одно число не попадает в path дважды. Вызов dfs([1, 2, 3]) сохраняет первый ответ.

Отмена возвращает path и used в состояние до выбора. Ветка числа 1 даёт 2 ответа, и после неё вызов dfs([2]) видит used = [False, True, False]. Число 1 снова свободно, поэтому ветка числа 2 тоже даёт 2 ответа: [2, 1, 3] и [2, 3, 1].

Каждый порядок появляется ровно один раз. Возьмите ответ [2, 3, 1]: вызов dfs([]) выбирает i = 1, вызов dfs([2]) выбирает i = 2, вызов dfs([2, 3]) выбирает i = 0. Каждый вызов пробует все свободные i, поэтому так находится любой порядок. Ответы [2, 1, 3] и [2, 3, 1] начинаются с 2, поэтому оба проходят через вызов dfs([2]). В нём их строят разные шаги цикла: i = 0 и i = 2. Все числа nums разные, поэтому эти шаги ставят на второе место разные числа: 1 и 3. Так любые два ответа расходятся в одном вызове на разных шагах цикла и получают на месте, которое заполняет этот вызов, разные числа: ни один порядок не повторяется.

Уровень d это все вызовы с len(path) == d. В примере 1 на уровнях 0, 1, 2 и 3 по 1, 3, 6 и 6 вызовов: всего 16. Каждый из 10 вызовов с len(path) < 3 проверяет все 3 пометки used: 30 проверок. Шесть ответов копируют по 3 числа: 18 чисел.

Время: вызов уровня d соответствует выбору d разных чисел по порядку. Для n = 3 и d = 2 это 3 · 2 = 6 вызовов, а в общем случае n · (n − 1) · ... · (n − d + 1) вызовов. При d = n − 1 и при d = n это n! вызовов. Для n = 6 уровни от 0 до 5 равны 1, 6, 30, 120, 360 и 720: каждый следующий больше предыдущего в 6, 5, 4, 3 и 2 раза. В общем случае уровень d в n − d + 1 раз больше уровня d − 1, а при d ≤ n − 1 это хотя бы в 2 раза. Поэтому уровни от 0 до n − 1 вместе не больше n! + n!/2 + n!/4 + ..., а это меньше 2 · n!. Для n = 6 сумма 1 + 6 + 30 + 120 + 360 + 720 = 1237 меньше 2 · 720 = 1440. Все вызовы вместе меньше 2 · n! + n! = 3 · n!. Вызов с len(path) < n проверяет n пометок, а каждый из n! ответов копирует n чисел. Всего O(n · n!) в худшем случае. При n = 6 это 1957 вызовов (меньше 3 · 720 = 2160), 7422 проверки used и 4320 скопированных чисел.

Дополнительная память: used хранит n пометок, path до n чисел, Call Stack до n + 1 вызовов dfs: O(n). Ответ занимает n · n! чисел.

class Solution:
    def permute(self, nums: list[int]) -> list[list[int]]:
        res = []
        used = [False] * len(nums)

        def dfs(path):
            if len(path) == len(nums):
                res.append(path[:])  # копия: path ещё изменится
                return
            for i in range(len(nums)):
                if used[i]:
                    continue
                used[i] = True  # выбрать
                path.append(nums[i])
                dfs(path)  # пойти глубже
                path.pop()  # отменить
                used[i] = False

        dfs([])
        return res

Решение 2. Next Permutation

Два порядка сравним по первому месту, где числа разные: [1, 3, 2] меньше [2, 1, 3], потому что 1 < 2. Это лексикографический порядок. Список a = sorted(nums) самый маленький. Цикл сохраняет копию a и меняет a на следующий по величине порядок, пока такой есть.

Шаг на числах. Пусть a = [1, 3, 2]. Код идёт справа налево и ищет первое место i, где a[i] < a[i + 1]. Пара 3 и 2 не подходит, пара 1 и 3 подходит: i = 0. Хвост правее i равен [3, 2] и убывает, а это самый большой порядок чисел 3 и 2. Поэтому с началом [1] больших списков нет, и a[0] должно вырасти. В убывающем хвосте самое правое число больше 1 это самое маленькое такое число: 2 на месте j = 2. Обмен даёт [2, 3, 1]. Хвост [3, 1] всё ещё убывает, и так всегда. До обмена числа хвоста левее j больше a[j], потому что хвост убывает, а a[j] больше a[i]: в примере 3 > 2 > 1. Место j самое правое, где число больше a[i], поэтому числа правее j меньше a[i]. Обмен ставит a[i] на место j: левее него в хвосте числа больше a[i], правее меньше. Разворот делает хвост возрастающим: [2, 1, 3], самый маленький список с началом [2]. Числа правее j есть на шаге 4 рисунка ниже: там a = [2, 3, 1], i = 0 и j = 1, а правее j стоит 1 < 2.

Новый список больше старого, и между ними нет других: на место i встало самое маленькое число хвоста, которое больше старого a[i], а хвост стал самым маленьким. Поэтому цикл проходит все списки по порядку и ни один не пропускает. На [3, 2, 1] весь список убывает, места i нет, и код возвращает 6 списков. Рисунок показывает все 6 списков примера 1 по порядку.

Время: один шаг проверяет до n − 1 пар для i, до n − 1 чисел для j, разворачивает до n − 1 чисел и копирует n чисел в res: O(n). Шагов n!, поэтому всего O(n · n!) в худшем случае, плюс O(n log n) на Sorting. Скопированных чисел столько же, сколько в решении 1: при n = 6 это 4320.

Дополнительная память: sorted создаёт новый list a из n чисел. Строка разворота создаёт две временные копии хвоста, по n − 1 чисел или меньше. Recursion нет, поэтому Call Stack не растёт: O(n). Ответ занимает n · n! чисел.

class Solution:
    def permute(self, nums: list[int]) -> list[list[int]]:
        a = sorted(nums)
        n = len(a)
        res = []
        while True:
            res.append(a[:])
            # самое правое i, где a[i] < a[i + 1]
            i = n - 2
            while i >= 0 and a[i] >= a[i + 1]:
                i -= 1
            if i < 0:
                return res
            # самое правое j, где a[j] > a[i]
            j = n - 1
            while a[j] <= a[i]:
                j -= 1
            a[i], a[j] = a[j], a[i]
            a[i + 1:] = a[i + 1:][::-1]

Типичные ошибки

  • res.append(path) без копии. Все ответы ссылаются на один list path, а в конце он пустой. Для [1, 2, 3] код вернёт [[], [], [], [], [], []].
  • Отмена без used[i] = False. После первого ответа все пометки остаются True, и код вернёт только [[1, 2, 3]].
  • Цикл от start, как в Subsets: for i in range(start, len(nums)) и вызов dfs(i + 1). Тогда индексы выбранных чисел только растут, и для [1, 2, 3] код вернёт только [[1, 2, 3]]. Порядок [2, 1, 3] берёт nums[0] после nums[1], поэтому цикл идёт с нуля, а used пропускает занятые i.
  • Next Permutation без Sorting. Начало с [3, 1, 2] даёт только [3, 1, 2] и [3, 2, 1]: порядки меньше начального не появятся.
