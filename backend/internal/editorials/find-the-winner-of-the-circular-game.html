Нужно найти друга, который останется в круге последним. Решение 1 проводит игру ход за ходом на Deque. Решение 2 считает место победителя по формуле и не хранит круг.

Решение 1. Simulation на Deque

Храните круг в Deque circle. Слева направо в нём стоят друзья по часовой стрелке, и первым стоит друг, с которого начинается счёт. После последнего элемента круг продолжается с первого. В примере 1 сначала circle = [1, 2, 3, 4, 5] и k = 2.

Первый счёт идёт 1, 2 и останавливается на друге 2. Вызов rotate(-1) переносит друга 1 в конец: [2, 3, 4, 5, 1]. popleft() убирает друга 2, остаётся [3, 4, 5, 1], и счёт начинается с друга 3. Следующие ходы убирают друзей 4, 1 и 5. Остаётся [3]: победил друг 3.

Счёт k друзей делает k − 1 шагов по кругу и останавливается на k-м. Вызов circle.rotate(-(k - 1)) даёт такой же результат, как k − 1 переносов первого друга в конец. Теперь k-й друг стоит первым, и popleft() убирает его. Первым становится друг, который сидел сразу за ним. С него начинается следующий счёт.

В примере 2 (n = 6, k = 5) на ходу 4 остаётся circle = [1, 2, 3]. Счёт идёт 1, 2, 3, 1, 2: он проходит круг больше одного раза, и друзья 1 и 2 посчитаны дважды. 4 раза первый друг уходит в конец: друзья 1, 2, 3 и снова 1. Получается [2, 3, 1], и rotate(-4) даёт то же. popleft() убирает друга 2.

В примере 1 из [3, 4, 5, 1] вызов rotate(-1) делает [4, 5, 1, 3]: за другом 1 снова идёт друг 3. Перенос первого друга в конец не меняет порядок по часовой стрелке. Каждый ход убирает одного друга, поэтому после n − 1 ходов в Deque остаётся один друг. В примере 1 это 4 хода.

Вызов rotate не всегда делает k − 1 переносов. Для Deque длины s CPython берёт остаток a = (k − 1) % s и поворачивает в более короткую сторону: ds = min(a, s − a) переносов. Знак % даёт остаток от деления: 4 % 6 = 4, 4 % 3 = 1. В примере 2 первый ход имеет a = 4 и d6 = min(4, 2) = 2. CPython переносит 2 друзей из конца в начало вместо 4 друзей из начала в конец. Результат тот же: [5, 6, 1, 2, 3, 4]. На ходу 4 a = 1 и d3 = min(1, 2) = 1: CPython переносит только друга 1.

Время: n − 1 ходов. Каждый popleft() стоит O(1), каждый rotate O(1 + ds) для s от n до 2. Всего O(n + d2 + d3 + ... + dn). В примере 1 каждый ход переносит одного друга, сумма 4. В примере 2 при s = 6 числа a = 4 и s − a = 2 дают в сумме 6, и меньшее число 2 не больше 6 / 2 = 3. Числа a и s − a всегда дают в сумме s, поэтому ds не больше s / 2 с округлением вниз. При n = 500 сумма таких половин равна 62 500 = 5002 / 4, а худшие k = 179 и k = 180 дают по 45 167 переносов. Граница растёт как n2, поэтому в худшем случае время O(n²). При постоянном k каждый ход переносит не больше k − 1 друзей, и время O(n). Дополнительная память: Deque из n номеров, O(n).

from collections import deque


class Solution:
    def findTheWinner(self, n: int, k: int) -> int:
        circle = deque(range(1, n + 1))
        while len(circle) > 1:
            circle.rotate(-(k - 1))  # k - 1 раз первый друг уходит в конец
            circle.popleft()  # k-й друг выходит из круга
        return circle[0]

Решение 2. Josephus Recurrence

Дополнительный вопрос просит O(n) времени и O(1) памяти.

Нумеруйте места с 0 от друга, с которого начинается счёт. В примере 1 места 0, 1, 2, 3, 4 занимают друзья 1, 2, 3, 4, 5. Счёт k = 2 кончается на месте 1, и друг 2 выходит. Новый счёт начинается с друга 3 на месте 2. Пронумеруйте 4 оставшихся друзей заново от него: друзья 3, 4, 5, 1 получают новые места 0, 1, 2, 3. Новое место x равно старому месту (x + 2) % 5: новые места 0, 1, 2, 3 дают старые 2, 3, 4, 0. Нет только места 1 проигравшего друга.

Так происходит в круге из любого числа s друзей. Проигравший сидит на месте (k − 1) % s, новый счёт начинается с места k % s, и каждый следующий друг сидит на 1 место дальше. Поэтому новое место x равно старому месту (x + k) % s. Игра оставшихся s − 1 друзей идёт по тем же правилам от нового места 0. Если в ней победитель сидит на новом месте j, то в круге из s друзей он сидит на месте (j + k) % s.

В круге из 1 друга победитель сидит на месте 0. Цикл по s = 2, 3, ..., n переводит это место в круг из n друзей. Место 0 занимает друг 1, поэтому ответ j + 1. В примере 1: j = 0 при s = 1, затем j = (0 + 2) % 2 = 0, j = (0 + 2) % 3 = 2, j = (2 + 2) % 4 = 0, j = (0 + 2) % 5 = 2. Ответ 2 + 1 = 3.

Время: n − 1 обновлений j, O(n) в худшем случае. При n = 500 это 499 обновлений. Дополнительная память: j и s, O(1). Цикл идёт от s = 2 вверх. Рекурсивная запись той же формулы держала бы до n вызовов одновременно: O(n) памяти.

class Solution:
    def findTheWinner(self, n: int, k: int) -> int:
        j = 0  # место победителя в круге из 1 друга, места с 0
        for s in range(2, n + 1):
            j = (j + k) % s
        return j + 1

Типичные ошибки

  • rotate(-k) вместо rotate(-(k - 1)). Друг, с которого начинается счёт, тоже посчитан, поэтому счёт делает k − 1 шагов, а не k. В примере 1 код с rotate(-k) отвечает 4 вместо 3.
  • rotate(k - 1) без минуса поворачивает круг в другую сторону: k − 1 раз переносит последнего друга в начало. В примере 1 первым выходит друг 5, а не друг 2, и ответ 1 вместо 3.
  • Ответ j вместо j + 1 в решении 2. Места начинаются с 0, а номера друзей с 1. В примере 1 код вернёт 2.
