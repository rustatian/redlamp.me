Нужно наименьшее число плит a × a, которые вместе закрывают прямоугольник n × m.

Решение 1. Деление с округлением вверх

Возьмите пример: n = 6, m = 6, a = 4. Положите первую плиту в угол площади. Вдоль стороны n она закрывает 4 метра из 6. Для остальных 2 метров нужна вторая плита. Она выходит за край площади на 2 · 4 − 6 = 2 метра, и условие это разрешает. Вдоль стороны m тоже нужны 2 плиты. Плиты лежат 2 рядами по 2 плиты, всего 2 · 2 = 4 плиты.

Вдоль стороны n нужно наименьшее целое число плит rows, для которого rows · a ≥ n. Это n / a с округлением вверх: 6 / 4 = 1,5, поэтому rows = 2. Число плит cols вдоль стороны m считают так же, а ответ равен rows · cols.

Округление вверх можно сделать без дробей. Прибавьте к n число a − 1 = 3 и разделите нацело: (6 + 3) // 4 = 9 // 4 = 2. Если n делится на 4, прибавка 3 не доходит до следующего кратного 4: (8 + 3) // 4 = 11 // 4 = 2, ровно 2 плиты. Если остаток не 0, сумма доходит до следующего кратного 4 или переходит через него: (5 + 3) // 4 = 8 // 4 = 2. Но сумма меньше кратного после него: n меньше следующего кратного 4, а прибавка 3 меньше 4. При n = 7 сумма 7 + 3 = 10 не меньше 8 и меньше 12, поэтому 10 // 4 = 8 // 4 = 2.

Правило. n / a с округлением вверх равно (n + a - 1) // a.

Почему меньше 4 плит не хватит. Левая сторона площади имеет длину 6. Одна плита закрывает из неё не больше 4 метров, поэтому левой стороны касаются не меньше 2 плит. Правой стороны тоже касаются не меньше 2 плит. Между левой и правой сторонами 6 метров, а ширина плиты 4, поэтому ни одна плита не касается обеих сторон. Значит, плит не меньше 2 + 2 = 4.

В общем случае проведите cols отрезков параллельно стороне n: первый по одной стороне площади, последний по противоположной, остальные на равных расстояниях между ними. В примере это левая и правая стороны. При cols = 1 отрезок один. Каждый отрезок имеет длину n, и одна плита закрывает из него не больше a метров. Число rows наименьшее, для которого rows · a ≥ n, поэтому (rows − 1) · a < n: в примере (2 − 1) · 4 = 4 < 6. Значит, rows − 1 плит не закрывают отрезок, и каждого отрезка касаются не меньше rows плит. По той же причине (cols − 1) · a < m, и соседние отрезки стоят на расстоянии m / (cols − 1), больше a. Поэтому одна плита касается не больше одного отрезка, и всего плит не меньше rows · cols.

n, m, a = map(int, input().split())
rows = (n + a - 1) // a  # плит вдоль стороны n
cols = (m + a - 1) // a  # плит вдоль стороны m
print(rows * cols)

Время: два деления нацело и одно умножение, O(1). Дополнительная память: переменные rows и cols, O(1). Ответ доходит до 109 · 109 = 1018 при n = m = 109 и a = 1. Целые числа Python не переполняются.

Что не подходит

Brute Force добавляет плиты вдоль стороны по одной: while rows * a < n: rows += 1. Это rows + cols шагов цикла для двух сторон. При n = m = 109 и a = 1 это 2 · 109 шагов: слишком долго.

Типичные ошибки

  • Деление без округления вверх. В примере 6 // 4 = 1, и ответ 1 · 1 = 1 вместо 4. Полоса шириной 2 метра вдоль двух сторон площади остаётся открытой.
  • Лишняя плита при делении без остатка: n // a + 1. При n = m = 8 и a = 4 это (2 + 1) · (2 + 1) = 9 плит вместо 2 · 2 = 4.
  • Деление площадей. В примере 36 / 16 = 2,25, и округление вверх даёт 3 вместо 4. Плиты у края выходят за площадь: 4 плиты занимают 4 · 16 = 64 квадратных метра, и 64 − 36 = 28 из них лежат вне площади. Эти части нельзя отрезать и положить в другое место.
