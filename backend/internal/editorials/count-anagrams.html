У слова hot на первое место можно выбрать любую из трёх букв, на второе останутся две, на третье одна. Получаем 3 · 2 · 1 = 6 слов. Если пронумеровать все буквы слова длины n и выписать все порядки, получится n! записей длины n. На их запись уйдёт O(n · n!) времени в худшем случае. При n = 105 перебор сделает 100000! записей ещё до удаления повторов. В числе 100000! ровно 456 574 цифры.

Решение 1. Таблицы Factorial

В слове too обозначим одинаковые буквы как o1 и o2. На первое из двух мест для o можно поставить любую из них. У каждого слова без номеров есть ровно два варианта с номерами. Поэтому разных слов 3! / 2! = 3.

В каждом слове из букв aabb номера двух букв a можно расставить двумя способами. Для каждого из них есть два порядка номеров букв b. На одно слово приходится 2 · 2 = 4 записи с номерами, поэтому разных слов 4! / (2! · 2!) = 6. Если буква встречается c раз, её номера можно расставить по её местам c! способами. Порядок номеров одной буквы не ограничивает порядок номеров другой. Поэтому для слова длины L берём L! и делим на c! для каждой буквы. В строке too hot к каждому из трёх вариантов первого слова подходят все шесть вариантов второго. Пары дают разные строки, поэтому answer = 3 · 6 = 18.

Для too нужно разделить 6 на 2. По модулю 5 от числителя остаётся 1, а 1 // 2 в Python даёт 0. У числа 2 есть обратный элемент x = 3, так как 2 · 3 = 6 даёт остаток 1. Пусть q = 6 / 2 = 3. Из равенства 6 = q · 2 получаем 6 · x = q · (2 · x). Множитель 2 · x даёт остаток 1, поэтому произведение даёт тот же остаток, что и q. Умножаем остаток числителя на x и получаем 1 · 3 = 3.

В коде mod хранит простой модуль M = 109 + 7. Длина строки n ≤ 105 < M, поэтому ни один из множителей от 1 до n не делится на M. Их произведение тоже не делится на M. Если хранить в fact остатки по модулю 5, получим fact[2] = 2, а затем fact[3] = (2 · 3) % 5 = 1. При заполнении fact слева направо умножаем fact[i − 1] на i и записываем остаток в fact[i]. По модулю 5 степень 24 = 16 даёт остаток 1, а 23 = 8 даёт остаток 3, обратный элемент числа 2. По малой теореме Ферма для a = fact[n] степень aM − 1 даёт остаток 1. Значит, aM − 2 при умножении на a даёт остаток 1. Поэтому вызов pow(fact[n], mod - 2, mod) даёт обратный элемент для n!.

По модулю 5 число 3! даёт остаток 1, поэтому inv_fact[3] = 1. Умножаем это значение на 3 и получаем inv_fact[2] = 3. Это обратный элемент для 2!, так как 2! · 3 = 6 даёт остаток 1. Для любого шага обратного цикла (i − 1)! · (i · inv_fact[i]) = i! · inv_fact[i], и правая часть даёт остаток 1. Поэтому в inv_fact[i − 1] записываем остаток произведения i · inv_fact[i] по модулю M. Подсчитав частоты всех букв слова в freq, записываем в ways значение fact[len(word)]. Для каждой частоты c умножаем ways на inv_fact[c] и берём остаток. Отсутствующая буква даёт множитель 1, так как 0! = 1.

class Solution:
    def countAnagrams(self, s: str) -> int:
        mod = 1_000_000_007
        n = len(s)
        fact = [1] * (n + 1)
        for i in range(1, n + 1):
            fact[i] = fact[i - 1] * i % mod

        inv_fact = [1] * (n + 1)
        inv_fact[n] = pow(fact[n], mod - 2, mod)
        for i in range(n, 0, -1):
            inv_fact[i - 1] = inv_fact[i] * i % mod

        answer = 1
        words = s.split()
        for word in words:
            freq = [0] * 26
            for letter in word:
                freq[ord(letter) - ord('a')] += 1
            ways = fact[len(word)]
            for c in freq:
                ways = ways * inv_fact[c] % mod
            answer = answer * ways % mod
        return answer

Время: O(n + log M) в худшем случае. Таблицы fact и inv_fact строим за два прохода и один вызов pow. Читаем все буквы и перебираем 26 частот на слово. Дополнительная память: O(n) в худшем случае для таблиц и результата s.split().

Решение 2. Один проход по буквам

Для too в числитель по очереди входят номера мест 1, 2, 3. В знаменатель входят числа 1, 1, 2: буква t встретилась впервые, а затем буква o встретилась дважды. При каждом появлении буквы берём её новую частоту. Так буква с частотой c даёт в знаменателе произведение от 1 до c. Длина слова растёт от 1 до L и даёт в числителе L!.

После too дробь равна 6 / 2. На пробеле сбрасываем длину и частоты, а произведения сохраняем. В начале hot буква h получает номер 1. Буква o даёт в знаменателе множитель 1, ведь обе прежние o остались в другом слове. В итоге numerator = 36, denominator = 2, и 36 / 2 = 18.

После увеличения частоты получаем 1 ≤ freq[index] ≤ n < M. Простое число M не делит ни один такой множитель, поэтому не делит и их произведение. Значит, denominator хранит ненулевой остаток и имеет обратный элемент. Код хранит остатки обоих произведений и в конце один раз умножает на обратный элемент знаменателя.

class Solution:
    def countAnagrams(self, s: str) -> int:
        mod = 1_000_000_007
        numerator = 1
        denominator = 1
        length = 0
        freq = [0] * 26
        for letter in s:
            if letter == ' ':
                length = 0
                freq = [0] * 26
                continue
            length += 1
            index = ord(letter) - ord('a')
            freq[index] += 1
            numerator = numerator * length % mod
            denominator = denominator * freq[index] % mod
        return numerator * pow(denominator, mod - 2, mod) % mod

Время: O(n + log M) в худшем случае для одного прохода по строке и одного вызова pow. Дополнительная память: O(1) в худшем случае: список хранит 26 частот при любой длине строки.
