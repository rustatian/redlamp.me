В задаче две части. Сначала для каждой температуры нужно число рецептов, которые её советуют. Потом для каждого вопроса нужно число температур от a до b, у которых рецептов не меньше k. Первую часть решает Difference Array, вторую Prefix Sum.

Решение 1. Difference Array и Prefix Sum

Первый пример: рецепты [91, 94], [92, 97] и [97, 99], k = 2. Прямой подсчёт прибавляет 1 к каждой температуре каждого рецепта: 4 + 6 + 3 = 13 прибавлений. В худшем случае каждый из n = 200 000 рецептов равен [1, 200 000]. Тогда прибавлений 200 000 · 200 000 = 4 · 1010: слишком долго. Время такого подсчёта O(n · T), где T = 200 000 - наибольшая возможная температура.

Difference Array ставит для рецепта [l, r] две отметки: d[l] += 1 и d[r + 1] -= 1. Рецепт [91, 94] даёт d[91] = 1 и d[95] = −1. Рецепт [92, 97] даёт d[92] = 1 и d[98] = −1. Рецепт [97, 99] даёт d[97] = 1 и d[100] = −1. Остальные числа d равны 0.

Prefix Sum по d даёт число рецептов для каждой температуры: cnt[t] = cnt[t − 1] + d[t]. Для температур от 90 до 100 получается 0, 1, 2, 2, 2, 1, 1, 2, 1, 1, 0. Проверим температуру 97: её советуют второй и третий рецепты, и cnt[97] = 2.

Две отметки заменяют весь отрезок, потому что cnt[t] = d[1] + d[2] + ... + d[t]. Отметка +1 из d[91] входит в эту сумму при t ≥ 91. Отметка −1 из d[95] входит в неё при t ≥ 95. Поэтому рецепт [91, 94] прибавляет 1 к cnt[91], cnt[92], cnt[93] и cnt[94], а с температуры 95 он прибавляет 1 − 1 = 0.

Температура t допустима, если cnt[t] ≥ k. При k = 2 это 92, 93, 94 и 97. Вопрос [a, b] можно решить циклом по температурам от a до b. Вопрос [1, 200 000] стоит 200 000 проверок. Если таких вопросов q = 200 000, проверок 200 000 · 200 000 = 4 · 1010: слишком долго. Время такого цикла O(q · T).

Вторая Prefix Sum считает допустимые температуры один раз: c[t] - число допустимых температур от 1 до t. Для допустимой температуры c[t] = c[t − 1] + 1, для остальных c[t] = c[t − 1]. В примере c[91] = 0, c[92] = 1, c[93] = 2, c[94] = 3, c[95] = c[96] = 3 и c[97] = 4. Выше температуры 97 допустимых температур нет, и c остаётся равным 4.

Вопрос [93, 97]. От 1 до 97 лежат c[97] = 4 допустимые температуры. Из них c[92] = 1 лежит левее вопроса: это температура 92. Ответ 4 − 1 = 3: температуры 93, 94 и 97. Вопрос [95, 96]: c[96] − c[94] = 3 − 3 = 0. Вопрос [90, 100]: c[100] − c[89] = 4 − 0 = 4.

Правило. Число допустимых температур от a до b равно c[b] − c[a − 1].

Номер места в каждом списке равен температуре: d[t], cnt[t] и c[t] относятся к температуре t. Списки cnt и c имеют длину T + 1, их места идут от 0 до T. Место 0 хранит c[0] = 0, поэтому вопрос с a = 1 считает c[b] − c[0] без отдельного if. Список d имеет длину T + 2: рецепт с r = 200 000 ставит отметку в d[200 001].

Вход содержит до 3 + 2 · 200 000 + 2 · 200 000 = 800 003 чисел. Программа читает его одним вызовом sys.stdin.buffer.read().split() и печатает все ответы одним print.

import sys

data = sys.stdin.buffer.read().split()
n, k, q = int(data[0]), int(data[1]), int(data[2])
T = 200000
d = [0] * (T + 2)
pos = 3
for _ in range(n):
    l, r = int(data[pos]), int(data[pos + 1])
    pos += 2
    # +1 в начале отрезка, -1 сразу после его конца
    d[l] += 1
    d[r + 1] -= 1
# cnt[t] - число рецептов для температуры t
cnt = [0] * (T + 1)
for t in range(1, T + 1):
    cnt[t] = cnt[t - 1] + d[t]
# c[t] - число допустимых температур от 1 до t
c = [0] * (T + 1)
for t in range(1, T + 1):
    c[t] = c[t - 1] + (1 if cnt[t] >= k else 0)
out = []
for _ in range(q):
    a, b = int(data[pos]), int(data[pos + 1])
    pos += 2
    out.append(str(c[b] - c[a - 1]))
print("\n".join(out))

Время: O(n + T + q) в худшем случае: 2 отметки на рецепт, по T сложений в каждой из двух Prefix Sum и одно вычитание на вопрос. При n = q = T = 200 000 это 400 000 отметок, 400 000 сложений и 200 000 вычитаний. Дополнительная память: O(T + n + q). Списки d, cnt и c хранят 3T + 4 = 600 004 числа: это O(T). Список data хранит все 3 + 2n + 2q чисел входа: это O(n + q). Ответ отдельно: q строк в out.

Типичные ошибки

  • Список d длины T + 1. Второй пример содержит рецепт [200 000, 200 000]. Строка d[r + 1] -= 1 пишет в d[200 001], а в таком списке есть только места от 0 до 200 000: IndexError.
  • Отметка −1 в d[r] вместо d[r + 1]. Тогда рецепт [91, 94] не считается для температуры 94, и cnt[94] = 1. По той же причине рецепт [92, 97] не считается для температуры 97, и cnt[97] = 1. Допустимы только 92 и 93, и вопрос [92, 94] даёт 2 вместо 3.
  • Формула c[b] − c[a] вместо c[b] − c[a − 1] теряет температуру a. Вопрос [92, 94] даёт c[94] − c[92] = 3 − 1 = 2 вместо 3.
  • Сравнение cnt[t] > k вместо cnt[t] ≥ k. В первом примере наибольшее число рецептов для одной температуры равно 2. При k = 2 допустимых температур не останется, и все четыре ответа будут 0.
