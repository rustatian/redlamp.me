Для n = 8 подходят размеры 1 × 8 и 2 × 4. У первой пары разность 8 − 1 = 7, у второй 4 − 2 = 2. Поэтому выбираем 2 × 4.

Проверим все возможные значения одной стороны. Такой полный перебор называют Brute Force. Начнём с пары a = 1, b = 8 для n = 8: её произведение равно 1 · 8 = 8, а разность b − a = 7. Переберём числа i от 1 до 8. При i = 1 вторая сторона равна j = 8 // 1 = 8, и модуль разности |1 − 8| = 7 не меньше 7, поэтому остаётся (1, 8). При i = 2 число 8 делится на 2 без остатка, и j = 8 // 2 = 4. Разность 2 − 4 = −2 отрицательна, поэтому берём модуль разности |2 − 4| = 2. Так как 2 < 7, обновляем a = min(2, 4) = 2 и b = max(2, 4) = 4. Число i = 3 не делит 8 без остатка, поэтому шаг пропускаем. При i = 4 получаем j = 8 // 4 = 2, где i > j, и модуль разности равен |4 − 2| = 2. Проверка 2 < 2 неверна, поэтому пара (2, 4) сохраняется. Числа 5, 6 и 7 не делят 8, а при i = 8 получаем j = 1 и модуль разности |8 − 1| = 7, что не меньше 2.

Запишем общее правило для любого n. Начнём с допустимой пары a = 1, b = n: здесь 1 · n = n и a ≤ b. Переберём числа i от 1 до n включительно. Если n делится на i без остатка, вычислим вторую сторону j = n // i и сравним abs(i - j) с разностью b − a. Если abs(i - j) < b - a, запишем a, b = min(i, j), max(i, j), чтобы условие a ≤ b выполнялось и при i > j (для i = 4 и j = 2 получилось бы a = 2, b = 4).

Начальная пара a = 1, b = n уже задаёт допустимый прямоугольник и остаётся ответом, если меньшей разности нет: например, при n = 1 (b − a = 0) или при n = 5 (b − a = 4, а на шагах i = 1 и i = 5 проверка 4 < 4 неверна). У каждого допустимого прямоугольника число строк делит n и лежит от 1 до n, поэтому перебор проверит и пару с наименьшей разностью: для n = 8 делитель i = 2 проверяет j = 4 с разностью 2 < 7 и сохраняет a = 2, b = 4. Для любого n после нахождения наименьшей разности нет допустимой пары с ещё меньшей разностью, поэтому строгое сравнение abs(i - j) < b - a не даёт следующим делителям перезаписать (a, b): например, для n = 8 на шаге i = 4 проверка 2 < 2 неверна, а на шаге i = 8 проверка 7 < 2 неверна.

Для n = 1 единственная пара равна (1, 1). В примере с n = 64 ответ тоже квадрат: 8 × 8 = 64, а разность равна 0. Условие a ≤ b разрешает равные стороны.

n = int(input())
a, b = 1, n
for i in range(1, n + 1):
    if n % i == 0:
        j = n // i
        if abs(i - j) < b - a:
            a, b = min(i, j), max(i, j)
print(a, b)

Время: O(n) в худшем случае: цикл проверяет каждое число от 1 до n. Дополнительная память: O(1) в худшем случае при заданном пределе n ≤ 106. Входная строка содержит до семи цифр. Функция print выводит два числа через пробел и завершает строку. В файле один случай, поэтому эти оценки относятся и ко всей программе.
