В примере с главой 2 все пятеро подчинённых узнают новость одновременно, через одну минуту. Ответ равен времени, когда новость получит последний сотрудник.

В цепочке с manager = [-1, 0, 1, 2] пути к главе имеют длины 0, 1, 2 и 3. Если от каждого сотрудника идти к главе по manager, получится 0 + 1 + 2 + 3 = 6 переходов. От сотрудника 3 поднимемся к начальникам 2, 1 и 0. При informTime = [1, 2, 4, 0] сумма их задержек равна 4 + 2 + 1 = 7 минутам. На каждом переходе прибавляем задержку того начальника, к которому пришли. Так мы найдём время для каждого сотрудника, но общую часть путей пройдём несколько раз. Для цепочки из n сотрудников такой Brute Force сделает n · (n − 1) / 2 переходов. При n = 100 000 это 4 999 950 000 переходов. Время O(n2) в худшем случае.

Решение 1. DFS со Stack от главы

Возьмём manager = [4, 4, 3, -1, 3] и informTime = [0, 0, 0, 2, 4]. Глава 3 передаёт новость сотрудникам 2 и 4 за две минуты. Затем сотрудник 4 передаёт её сотрудникам 0 и 1 ещё за четыре минуты. Оба узнают новость через 2 + 4 = 6 минут от начала.

Запись manager[0] = 4 говорит, что сотрудник 0 подчиняется сотруднику 4. Добавим номер 0 в reports[4]. Так соберём для каждого начальника список его прямых подчинённых. У главы manager[headID] = -1, поэтому его номер ни в один список не добавляем.

Положим в Stack пару (3, 0). Её первое число обозначает сотрудника, а второе показывает, сколько минут прошло до получения новости. Снимем пару (employee, minutes) и добавим в Stack пары для подчинённых сотрудника employee. Для каждого из них возьмём время minutes + informTime[employee]. К каждому сотруднику ведёт единственный путь от главы, поэтому время в его паре равно сумме задержек его начальников на этом пути.

Сотрудник 4 попадает в Stack из reports[3], а сотрудник 0 - из reports[4]. Так обход от главы доходит до всех сотрудников. Каждый подчинённый попадает в Stack ровно один раз, ведь его номер есть только в списке прямого начальника.

В нашем примере pop() снимает пару (1, 6) раньше пары (2, 2). Поэтому после каждой снятой пары обновляем наибольшее время latest. Когда Stack опустеет, в latest останется максимум по всем сотрудникам.

class Solution:
    def numOfMinutes(
        self, n: int, headID: int, manager: list[int], informTime: list[int]
    ) -> int:
        reports = [[] for _ in range(n)]
        for employee, boss in enumerate(manager):
            if boss != -1:
                reports[boss].append(employee)

        stack = [(headID, 0)]
        latest = 0
        while stack:
            employee, minutes = stack.pop()
            latest = max(latest, minutes)
            for child in reports[employee]:
                stack.append((child, minutes + informTime[employee]))
        return latest

Время: O(n) в худшем случае. Построение списков требует одного прохода по manager. При обходе каждый из n сотрудников один раз входит в Stack и один раз выходит из него. Дополнительная память: O(n) в худшем случае. В n списках хранятся n − 1 номеров подчинённых, а в Stack одновременно лежит не более n пар.

Решение 2. Подъём по manager с сохранением времени

У сотрудников 0 и 1 общий начальник 4. Если при подъёме от 0 сохранить время сотрудника 4, то для сотрудника 1 хватит одного перехода к начальнику. Список arrived хранит время получения новости. Сначала ставим главе 0 минут, а остальным записываем -1. По этой отметке код отличает неизвестное время от нулевого.

От сотрудника 0 поднимемся через 4 к главе 3. В path запишем номера с неизвестным временем, здесь это [0, 4]. Подъём всегда заканчивается, ведь время главы известно с самого начала. Теперь снимем номера с конца, сначала 4, потом 0. При разборе пути с конца мы уже знаем время начальника, когда вычисляем время подчинённого.

Подъём от сотрудника 1 остановится на записи arrived[4] = 2. Прибавим informTime[4] = 4 и получим arrived[1] = 6. После прохода по всем номерам в arrived лежат времена [6, 6, 2, 0, 2]. Их максимум равен 6.

class Solution:
    def numOfMinutes(
        self, n: int, headID: int, manager: list[int], informTime: list[int]
    ) -> int:
        arrived = [-1] * n
        arrived[headID] = 0
        for employee in range(n):
            node = employee
            path = []
            while arrived[node] == -1:
                path.append(node)
                node = manager[node]

            while path:
                node = path.pop()
                boss = manager[node]
                arrived[node] = arrived[boss] + informTime[boss]
        return max(arrived)

Время: O(n) в худшем случае. В path попадают лишь сотрудники с неизвестным временем. При снятии записываем время, поэтому каждый номер попадает туда не более одного раза за весь проход. Поиск максимума также занимает O(n). Дополнительная память: O(n) в худшем случае. В arrived ровно n записей, а в path не более n − 1 номеров.
