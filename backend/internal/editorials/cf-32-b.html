Решение 1. Linear Scan

В записи .-.-- точка на позиции 0 означает ноль. Точка на позиции 2 уже входит в код единицы -. и отдельно не читается. Чтобы различить эти случаи, будем хранить в i позицию первого непрочитанного знака.

Только код нуля начинается с точки, поэтому добавляем в список digits цифру 0 и сдвигаем i на одну позицию. При i = 1 видим тире, а за ним точку. Добавляем 1 и переходим сразу к i = 3. Здесь два тире подряд дают 2. После начального тире всегда можно прочитать второй знак, потому что по условию запись верна.

После трёх шагов i = 5, а в строке как раз пять знаков. После добавления цифры i сдвигается на длину её кода. Поэтому следующий шаг начинается на границе кодов.

В списке digits лежат строки ["0", "1", "2"]. Вызов "".join(digits) соединяет их без пробелов и сохраняет ноль в начале ответа 012.

code = input()
digits = []
i = 0
while i < len(code):
    if code[i] == ".":
        digits.append("0")
        i += 1
    else:
        if code[i + 1] == ".":
            digits.append("1")
        else:
            digits.append("2")
        i += 2

print("".join(digits))

В примере цикл прочитал пять знаков, а join соединил три цифры. Пусть n обозначает длину входной строки. Время: O(n) в худшем случае. Цикл читает каждый знак один раз, а join соединяет не более n цифр. Например, четыре точки дают четыре нуля в списке digits. Для n точек в нём будет n цифр. Дополнительная память: O(n) в худшем случае.

Решение 2. Замена кодов в строке

В записи --. первые два тире дают двойку, а точка даёт ноль. Если сначала заменить -. на 1, получится -1. Такая замена заберёт второе тире из кода двойки.

В строке ---.. сначала заменим -- на 2 и получим 2-... После замены -. на 1 останется строка 21. с точкой в конце. Заменим эту точку на 0. Ответ равен 210.

Оба кода с точкой, . и -., на ней заканчиваются. Поэтому группа тире после точки начинается с новой цифры, как и группа в начале строки. Пока подряд идут хотя бы два тире, первые два из них образуют код двойки. Вызов replace("--", "2") заменяет такие пары слева направо. Если в группе осталось одно тире, оно начинает код следующей цифры. Запись верна по условию, значит, за этим тире есть второй знак. Это точка, потому что группа тире закончилась. Вторая замена превращает каждую такую пару в единицу. Теперь каждая оставшаяся точка сама образует код нуля. Третья замена записывает эти нули на своих местах.

code = input()
code = code.replace("--", "2")
code = code.replace("-.", "1")
print(code.replace(".", "0"))

В примере ---.. замены обрабатывают строки длиной 5, 4 и 3. Время: O(n) в худшем случае. Каждый из трёх вызовов replace обрабатывает строку длиной не более n и ищет образец длиной не более двух знаков. Когда второй вызов replace создаёт строку 21., code ещё указывает на 2-... До присваивания результата обе строки находятся в памяти и вместе содержат 4 + 3 = 7 знаков. В двух промежуточных строках вместе не больше 2n знаков. Если -- встречается один раз, первая замена создаёт промежуточную строку длиной n − 1. Дополнительная память: O(n) в худшем случае.
