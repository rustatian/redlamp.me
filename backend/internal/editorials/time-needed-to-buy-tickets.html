Нужна секунда, на которой человек k купит последний билет.

Решение 1. Simulation на Deque

Возьмите пример 1: tickets = [2, 3, 2], k = 2. Deque q хранит номера людей в порядке очереди, сначала q = [0, 1, 2]. Один шаг цикла - одна продажа и одна секунда. На секунде 1 q.popleft() даёт p = 0, и tickets[0] становится 2 − 1 = 1. Человеку 0 нужен ещё билет, поэтому q.append(0) в ту же секунду ставит его в конец: q = [1, 2, 0].

На секунде 4 человек 0 покупает второй билет, и tickets[0] = 0. Код не ставит номер 0 в конец: человек 0 ушёл. На секунде 6 p = 2 = k и tickets[2] = 0. Человек k купил все билеты, и код возвращает 6.

Правило. Возьмите номер из начала q и продайте этому человеку один билет. Если ему нужны ещё билеты, поставьте номер в конец. Остановитесь, когда p == k и tickets[p] == 0.

Числа билетов в q не подходят: по ним не видно, где человек k. В примере 1 у людей 0 и 2 по 2 билета, а k = 2. Номер p показывает, кто купил билет, и проверка p == k находит нужного человека.

Время: пусть b - число продаж до ответа. Одна продажа идёт 1 секунду, поэтому b равно ответу: в примере 1 b = 6. Создание q стоит O(n), каждый из b шагов цикла стоит O(1): O(n + b) в худшем случае. Все люди вместе хотят не больше n · 100 ≤ 104 билетов, поэтому b ≤ 104. При n = 100, всех tickets[i] = 100 и k = 99 код делает ровно 10 000 продаж. Дополнительная память: q хранит не больше n номеров, O(n). В примере 1 пик 3 номера. Код уменьшает числа в tickets, поэтому после вызова вход изменён.

from collections import deque


class Solution:
    def timeRequiredToBuy(self, tickets: list[int], k: int) -> int:
        q = deque(range(len(tickets)))  # номера людей в порядке очереди
        time = 0
        while True:
            p = q.popleft()
            tickets[p] -= 1
            time += 1
            if p == k and tickets[p] == 0:
                return time
            if tickets[p] > 0:
                q.append(p)  # человеку нужны ещё билеты: в конец

Решение 2. Linear Scan

В решении 1 люди уходят, но никто никого не обгоняет. popleft и append переносят первого человека в конец, а уход только убирает номер. В примере 1 перед секундой 4 снова q = [0, 1, 2]. Поэтому продажи идут кругами: в каждом круге каждый, кто ещё стоит, покупает один билет, по порядку номеров. Человек k покупает последний билет в круге T = tickets[k].

Возьмите те же tickets = [2, 3, 2], но k = 0. Здесь T = 2. В круге 1 билет покупают люди 0, 1 и 2, это секунды 1, 2 и 3. Круг 2 начинает человек 0. На секунде 4 он покупает второй билет, и ответ 4. Люди 1 и 2 стоят после k, поэтому в круге 2 они не успевают купить билет.

Правило. Человек i ≤ k до ответа покупает min(tickets[i], T) билетов. Человек i > k покупает min(tickets[i], T − 1) билетов. Ответ - сумма этих n чисел.

Человек i покупает один билет за круг и уходит после tickets[i] билетов. Человек i ≤ k в круге T стоит до k или это сам k, поэтому он покупает в кругах с 1 по T. Человек i > k в круге T стоит после k, поэтому он покупает только в кругах с 1 по T − 1. Одна продажа - одна секунда, поэтому сумма покупок равна ответу.

Для k = 0 сумма 2 + min(3, 1) + min(2, 1) = 2 + 1 + 1 = 4. В примере 1 k = 2, и все трое стоят не позже k: min(2, 2) + min(3, 2) + min(2, 2) = 6. Человек 1 хочет 3 билета, но до ответа покупает только 2. В примере 2 T = 5, и сумма 5 + 1 + 1 + 1 = 8.

Время: один проход по n числам, O(n) в худшем случае. При n = 100 это 100 слагаемых, а решение 1 делает до 104 продаж. Дополнительная память: T, time, i и t, O(1). Вход код не меняет.

class Solution:
    def timeRequiredToBuy(self, tickets: list[int], k: int) -> int:
        T = tickets[k]
        time = 0
        for i, t in enumerate(tickets):
            if i <= k:
                time += min(t, T)  # стоит не позже k: покупает и в круге T
            else:
                time += min(t, T - 1)  # стоит после k: круг T не успевает
        return time

Типичные ошибки

  • Остановиться, когда билеты кончились у любого человека, без проверки p == k. В примере 1 человек 0 уходит на секунде 4, и такой код вернёт 4 вместо 6.
  • Считать min(tickets[i], T) для всех i. Для tickets = [2, 3, 2], k = 0 это даст 2 + 2 + 2 = 6 вместо 4: люди 1 и 2 после k получают лишний круг.
  • Написать i < k вместо i <= k. Тогда для самого k код берёт min(T, T − 1) = T − 1, и в примере 1 ответ 2 + 2 + 1 = 5 вместо 6.
