При n = 9 вариантов 9! = 362 880. Решение 1 по номеру k находит цифры ответа по одной, слева направо: n шагов цикла. Решение 2 проходит варианты по порядку от первого до k-го.

Решение 1. Блоки Factorial

Рисунок показывает все 4! = 24 варианта при n = 4. Каждая строка это блок вариантов с одной первой цифрой. Остальные 3 цифры стоят в блоке во всех порядках, поэтому в блоке 3! = 6 вариантов. Вариант с номером 9 из примера 2 стоит во второй строке: номера от 1 до 6 занимает блок цифры 1.

Код считает номера с нуля: после k -= 1 в примере 2 получаем k = 8. Список digits = [1, 2, 3, 4] хранит свободные цифры по возрастанию. Блок 0 занимает номера от 0 до 5, блок 1 номера от 6 до 11: целое деление номера на 6 даёт номер блока. Номер блока 8 // 6 = 1, поэтому первая цифра digits[1] = 2. Остаток 8 % 6 = 2 это номер внутри блока: 2134 имеет номер 0, 2143 номер 1, 2314 номер 2.

В блоке цифры 2 остальные цифры 1, 3, 4 тоже стоят во всех порядках и в Lexicographic Order. Значит, дальше та же задача: вариант с номером 2 из цифр [1, 3, 4]. Блок теперь 2! = 2. Номер 2 // 2 = 1 даёт цифру 3, остаток 2 % 2 = 0. Из [1, 4] при блоке 1! = 1 номер 0 даёт цифру 1. Последней остаётся 4, ответ 2314.

Номер блока можно брать как индекс в digits. Список digits всегда возрастает, и блоки тоже идут по возрастанию первой цифры. После pop(1) список [1, 2, 3, 4] становится [1, 3, 4], и digits[1] = 3 это вторая свободная цифра в порядке возрастания.

Время: n - число цифр, F(s) - стоимость вызова factorial(s). Цикл делает n шагов и n вызовов factorial. Вызов pop(i) сдвигает влево все цифры правее i. В примере 2 это 2 + 1 + 1 + 0 = 4 сдвига. Больше всего сдвигов при k = 1: каждый pop(0) сдвигает весь остаток списка. При n = 4 это 3 + 2 + 1 + 0 = 6, при n = 9 это n(n − 1)/2 = 36. Команда out += ... в худшем случае копирует out целиком: всего до 0 + 1 + ... + (n − 1) = n(n − 1)/2 символов. Итого O(n²) + Σ F(s), s = 0…n − 1, в худшем случае. Дополнительная память: O(n): digits хранит до n цифр. Ответ out занимает n символов.

from math import factorial


class Solution:
    def getPermutation(self, n: int, k: int) -> str:
        digits = list(range(1, n + 1))
        k -= 1  # номер с нуля
        out = ""
        for size in range(n - 1, -1, -1):
            block = factorial(size)  # вариантов в одном блоке
            out += str(digits.pop(k // block))
            k %= block
        return out

Решение 2. Next Permutation

Первый вариант: цифры от 1 до n по возрастанию. Next Permutation из главы делает из варианта следующий. После k − 1 шагов в a лежит вариант с номером k. В примере 1 два шага ведут от 123 через 132 к 213.

Шаг на числах. Пусть a = [1, 3, 4, 2]. Код идёт справа налево и ищет первое i, где a[i] < a[i + 1]. Пара 4 и 2 не подходит, пара 3 и 4 подходит: i = 1. Самое правое число больше 3 это 4 на месте j = 2. Обмен даёт [1, 4, 3, 2], разворот хвоста [3, 2] даёт [1, 4, 2, 3]. Рисунок показывает все 8 шагов примера 2. Первые 6 вариантов начинаются с 1: решение 2 проходит их по одному, а решение 1 пропускает их одним делением 8 // 6.

Код не проверяет i >= 0. Место i не находится только в последнем варианте, где все цифры убывают, например 4321. Перед шагом 1 в a лежит вариант 1, перед шагом 2 вариант 2, и так далее. Шагов k − 1 ≤ n! − 1, поэтому вариант n! перед шагом не встречается. При n = 3 и k = 6 код делает 5 шагов. Перед шагом 5 в a лежит вариант 5, это 312, и пара 1 < 2 даёт i = 1. Вариант 321 появляется только после последнего шага. Все цифры в a разные, поэтому сравнения не встречают равных чисел: знаки > и < дают то же, что >= и <= в коде главы.

Время: один шаг проверяет до n − 1 пар для i, до n − 1 чисел для j и разворачивает до n − 1 чисел: O(n). Шагов k − 1, поэтому всего O(k · n): это верхняя оценка. Длинный хвост бывает редко: на рисунке хвост из 3 чисел разворачивает только шаг 6. При k = 720 код выполняет 6575 строк и при n = 6, и при n = 9. При n = 9 и k = 9! = 362 880 код делает 362 879 шагов и выполняет 3 322 085 строк. Решение 1 на том же входе выполняет 45 строк. Решение 2 тоже проходит тесты: на нашем компьютере Python в браузере (Pyodide) выполняет его на этом входе примерно за 0,1 с. Дополнительная память: a хранит n чисел. Срез a[i + 1:] и разворот [::-1] создают две временные копии хвоста, в каждой до n − 1 чисел: O(n). Ответ занимает n символов.

class Solution:
    def getPermutation(self, n: int, k: int) -> str:
        a = list(range(1, n + 1))
        for _ in range(k - 1):
            # самое правое i, где a[i] < a[i + 1]
            i = n - 2
            while a[i] > a[i + 1]:
                i -= 1
            # самое правое j, где a[j] > a[i]
            j = n - 1
            while a[j] < a[i]:
                j -= 1
            a[i], a[j] = a[j], a[i]
            a[i + 1:] = a[i + 1:][::-1]
        return "".join(map(str, a))

Типичные ошибки

  • Номер без k -= 1. При n = 3 и k = 2 код берёт блок 2 // 2 = 1 и возвращает 213 вместо 132. При k = 6 номер блока 6 // 2 = 3, и digits.pop(3) на списке из 3 цифр падает с IndexError.
  • digits[k // block] без pop. Взятая цифра остаётся в списке и повторяется: при n = 3 и k = 3 код вернёт 211.
