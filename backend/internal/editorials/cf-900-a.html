В первом примере у точек (1, 1) и (2, -1) координата x положительная: обе точки справа от оси OY. Только точка (-1, -1) лежит слева. Удалим её, и обе оставшиеся точки будут справа. Сторону определяет знак x, а высота y может быть любой.

В третьем примере все точки уже справа: их координаты x равны 1, 2 и 4. Можно удалить любую из них. По условию точек хотя бы две, поэтому после удаления хотя бы одна останется.

Во втором примере с каждой стороны по две точки. Если с обеих сторон хотя бы по две точки, одно удаление не опустошит ни одну сторону.

Посчитаем число точек слева в left. Остальные точки справа, их число равно n − left. Ответ Yes, если меньшее из двух чисел равно нулю или единице.

import sys

read = sys.stdin.readline
n = int(read())
left = 0
for _ in range(n):
    x, y = map(int, read().split())
    if x < 0:
        left += 1

right = n - left
print("Yes" if min(left, right) <= 1 else "No")

Время: O(n) в худшем случае для всего ввода: программа обрабатывает один набор из n точек. Дополнительная память: O(1) в худшем случае для набора и всей программы. При чтении точки Python хранит строку, а при её разбиении создаёт список из двух коротких строк. Программа сразу печатает одно слово и перевод строки.
