Linear Scan

В первом примере два дня подряд доход равен 2. Оба дня входят в один отрезок: при равенстве доход не падает. Затем доход падает с 2 до 1. Любой отрезок, который включает оба этих дня, содержит спад. Поэтому с третьего дня начинаем новый отрезок: 1, 3, 4.

В переменной run храним длину самого длинного подходящего отрезка, который заканчивается сегодня. У каждого отрезка есть последний день, поэтому наибольшее из всех значений run даёт ответ. Переменная best хранит эту длину за все просмотренные дни. Первый день (a[0]) сам образует подходящий отрезок длины 1, поэтому сначала run = best = 1. Цикл идёт со второго дня (i = 1) и при n = 1 делает 0 шагов, поэтому ответ равен 1. Если доход вырос или остался прежним, добавляем день к этому отрезку. Все прежние пары в этом отрезке уже не убывают (в первом примере для 1, 3 это 1 ≤ 3), поэтому для 1, 3, 4 достаточно проверить последнюю пару (3 ≤ 4). Более длинный подходящий отрезок с концом сегодня не может пропустить вчерашний день, поэтому без сегодняшнего дня он дал бы вчера отрезок длиннее прежнего run. При спаде остаётся только сегодняшний день, поэтому run = 1.

В первом примере после последнего спада run = 1, но best = 3. Если вывести run в конце программы, получится 1 вместо 3. Во втором примере 2, 2, 9 спадов нет, а отрезок достигает длины 3 в последний день. Если обновлять best только при спаде, переменная best останется равной 1. Поэтому обновляем best сразу после каждого сравнения.

import sys

n = int(sys.stdin.readline())
a = list(map(int, sys.stdin.readline().split()))
run = best = 1
for i in range(1, n):
    if a[i] >= a[i - 1]:
        run += 1
    else:
        run = 1
    best = max(best, run)
print(best)

Время: O(n) в худшем случае для всей программы: во входе один набор из n дней. Цикл сравнивает соседей n − 1 раз. Дополнительная память: O(n) в худшем случае для этого набора и всей программы. При чтении Python хранит строку с доходами, а split() создаёт список из n частей. Пока list собирает числа в a, список частей ещё занимает память. В цикле хватает O(1) дополнительной памяти. Команда print выводит одно число длиной до шести цифр и перевод строки.
