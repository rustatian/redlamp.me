Решение. Greedy

Для суммы 125 = 100 + 20 + 5 хватит трёх купюр. Greedy сначала берёт сотню, затем набирает остаток 25 с самой крупной купюры, которая в него помещается.

Пять купюр по 1 можно заменить одной купюрой в 5. Две по 5 дают одну в 10, две по 10 дают одну в 20, а пять по 20 дают одну в 100. Каждый обмен сохраняет сумму и уменьшает число купюр.

В наборе с наименьшим числом купюр ни один такой обмен уже невозможен. Значит, мелкие купюры вместе дают не больше 4 · 1 + 1 · 5 + 1 · 10 + 4 · 20 = 99 долларов. Поэтому нужно взять столько сотен, сколько помещается в сумму: иначе останется хотя бы 100 долларов на мелкие купюры.

После сотен берём как можно больше купюр по 20: более мелкие вместе дают не больше 4 + 5 + 10 = 19. По той же причине берём все возможные десятки, затем пятёрки: купюры меньше десятки дают не больше 4 + 5 = 9, а единицы дают не больше 4. Остаток выдаём единицами.

Для суммы 43 = 2 · 20 + 3 · 1 получаем пять купюр. Переменная remaining хранит оставшуюся сумму. В начале remaining = n. При remaining = 43 для номинала 100 получаем 43 // 100 = 0 купюр и остаток 43 % 100 = 43. Для 20 получаем 43 // 20 = 2 купюры и новый остаток 43 % 20 = 3. Для 10 и 5 получаем по 0 купюр и прежний остаток 3: 3 // 10 = 0, 3 % 10 = 3 и 3 // 5 = 0, 3 % 5 = 3. Для 1 получаем 3 // 1 = 3 купюры и остаток 3 % 1 = 0. Для каждого номинала value выражение remaining // value даёт число купюр. После каждого шага в remaining записываем остаток remaining % value.

remaining = int(input())
notes = 0
for value in (100, 20, 10, 5, 1):
    notes += remaining // value
    remaining %= value
print(notes)

Время: O(1) в худшем случае для одной суммы и всей программы: во входе одна сумма, цикл проверяет пять номиналов. Дополнительная память: O(1) в худшем случае для одной суммы и всей программы. При n ≤ 109 временная строка из input() содержит до десяти цифр. Цикл хранит пять номиналов, остаток и счётчик купюр. print(notes) выводит одно число длиной до восьми цифр и перевод строки.
