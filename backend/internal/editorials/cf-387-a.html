Вычитание в минутах

В 05:50 с полуночи прошло 5 · 60 + 50 = 350 минут. Сон длился 5 · 60 + 44 = 344 минуты. Джордж лёг через 350 − 344 = 6 минут после полуночи, в 00:06.

Если сейчас полночь, а сон длился час, разность равна 0 − 60 = −60. В сутках 24 · 60 = 1440 минут. Отсчитаем те же минуты от предыдущей полуночи: 1440 − 60 = 1380. Это 23:00.

Джордж проснулся в 00:05. Если он спал четыре, пять или шесть минут, то разность в минутах равна соответственно 1, 0 или −1. Ноль означает полночь, а −1 означает минуту до неё.

Джордж спал меньше суток, поэтому при отрицательной разности достаточно прибавить 1440 минут. В Python 6 % 1440 даёт 6, а (-60) % 1440 даёт 1380, потому что −60 = (−1) · 1440 + 1380. Остаток от деления на 1440 в Python не бывает отрицательным: оператор % 1440 прибавляет 1440 к такой отрицательной разности и сохраняет разность от 0 до 1439.

Назовём полученное число минут от полуночи bed. При bed = 6 число часов 6 // 60 равно 0, а число минут 6 % 60 равно 6. Формат 02d даёт 00 и 06, то есть 00:06 вместо неверного 0:6. При bed = 1380 число часов 1380 // 60 равно 23, а число минут 1380 % 60 равно 0. Формат 02d оставляет 23 без изменений и дополняет 0 до 00: получается 23:00. Целая часть от деления bed на 60 даёт часы, а остаток даёт минуты. Формат 02d дополняет однозначное число нулём слева.

def read_minutes():
    hours, minutes = input().split(":")
    return int(hours) * 60 + int(minutes)


now = read_minutes()
sleep = read_minutes()
bed = (now - sleep) % (24 * 60)
print(f"{bed // 60:02d}:{bed % 60:02d}")

Время: O(1) в худшем случае для всей программы: она читает один случай, две строки по пять символов. Дополнительная память: O(1) в худшем случае. При разборе каждой строки split создаёт список из двух строк по два символа. Для вывода программа строит строку из пяти символов, а print добавляет перевод строки.
