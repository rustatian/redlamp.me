Для [3, 2, 3] пары шаров с номерами (1, 2), (1, 3) и (2, 3) дают произведения 6, 9 и 6. У каждой пары одна и та же вероятность, поэтому математическое ожидание равно 21 / 3 = 7.

Brute Force умножает значения для каждой пары отдельно. При n = 200 000 это n · (n − 1) / 2 = 19 999 900 000 умножений. Такой перебор занимает O(n2) времени в худшем случае.

Решение 1. Квадрат суммы

В примере сумма значений равна total = 3 + 2 + 3 = 8. В произведении (3 + 2 + 3) · (3 + 2 + 3) умножаем каждое число из первой скобки на каждое число из второй. В таблице строка задаёт первый шар, а столбец задаёт второй.

В каждой клетке на диагонали оба множителя относятся к одному шару. Сумма квадратов равна squares = 9 + 4 + 9 = 22. После вычитания остаётся 82 − 22 = 42. Обе клетки для пары троек остаются, потому что у этих шаров разные номера. В этой сумме каждая пара разных шаров встречается дважды, по одному разу для каждого порядка выбора. В примере таких вариантов 3 · 2 = 6, поэтому среднее равно 42 / 6 = 7.

Для первого шара есть n вариантов, а для второго остаётся n − 1. Получаем дробь (total2 − squares) / (n · (n − 1)).

Для [1, 1, 2] сумма произведений трёх пар без учёта порядка равна 1 + 2 + 2 = 5. Код учитывает оба порядка каждой пары, поэтому среднее равно (2 · 5) / (2 · 3) = 10 / 6 = 5 / 3. Целочисленное деление 5 // 3 отбросит остаток и даст 1. По модулю M = 109 + 7 у тройки есть обратный элемент 333333336, поскольку 3 · 333333336 = M + 1. Умножаем числитель на этот обратный элемент и получаем остаток 5 · 333333336 % M = 666666673.

При n = 4 знаменатель равен 4 · 3 = 12. Возьмём для примера модуль M = 7 и найдём остаток 12 % 7 = 5. При показателе 7 − 2 = 5 вызовы pow(12, 5, 7) и pow(5, 5, 7) дают один и тот же остаток 3. Замена основания его остатком сохраняет остаток каждого умножения, а значит, и всей степени. Это обратный элемент исходного знаменателя, потому что 12 · 3 % 7 = 1.

В коде знаменатель denominator равен n · (n − 1). Оба множителя лежат между 1 и 200 000 включительно. Модуль M простой и больше каждого множителя, поэтому их произведение на M не делится. По малой теореме Ферма остаток от denominatorM − 1 при делении на M равен 1. Умножение denominatorM − 2 на знаменатель увеличивает показатель до M − 1. Поэтому pow(denominator % MOD, MOD - 2, MOD) даёт обратный элемент знаменателя.

import sys

MOD = 1_000_000_007
read = sys.stdin.readline
answers = []

for _ in range(int(read())):
    n = int(read())
    values = read().split()
    total = 0
    squares = 0
    for x in map(int, values):
        total += x
        squares += x * x

    numerator = total * total - squares
    denominator = n * (n - 1)
    inverse = pow(denominator % MOD, MOD - 2, MOD)
    answers.append(str(numerator * inverse % MOD))

print("\n".join(answers))

Время: O(N + t · log M) в худшем случае за весь запуск, где N - общее число шаров, а t - число наборов. Для каждого шара код создаёт запись в values, читает её один раз в цикле и освобождает вместе со списком. В каждом наборе pow выполняет O(log M) умножений. Дополнительная память: O(nmax + t) в худшем случае, где nmax - число шаров в самом большом наборе. Если после набора из 64 чисел идёт набор из 2, то values хранит все 64 части предыдущей строки, пока split() делит новую строку. Пока join строит строку вывода, в answers остаются t строк длиной до 10 цифр каждая. Для самих сумм достаточно O(1) памяти.

Решение 2. Prefix Sum

В [3, 2, 3] у первого шара слева нет соседа. У второго шара слева только тройка, поэтому добавляем 3 · 2 = 6. Если сначала прибавить двойку к prefix, получится (3 + 2) · 2 = 10. Так второй шар образует пару с самим собой и даёт лишнее слагаемое 2 · 2 = 4. Для последней тройки вклад обеих пар равен (3 + 2) · 3 = 15. Сумма произведений всех пар равна 6 + 15 = 21.

Перед обработкой x в prefix лежит сумма всех значений слева. Прибавляя prefix · x к products, учитываем все пары, в которых текущий шар стоит справа. В таблице это клетки над диагональю в столбце текущего шара. Каждая пара попадает в сумму ровно раз, когда проход доходит до правого шара. Само число x добавляем в prefix только после умножения, иначе в сумму попадёт ещё и x2.

Для трёх шаров число пар без учёта порядка равно 3 · 2 / 2 = 3. Код вычисляет pairs = n * (n - 1) // 2 до перехода к остаткам. Здесь деление на 2 точное, потому что одно из двух соседних чисел обязательно чётное. Если бы pairs делилось на M, то и произведение 2 · pairs = n · (n − 1) делилось бы на M. В решении 1 мы показали, что это произведение на M не делится, поэтому у pairs есть обратный элемент. Для ответа умножаем products на обратный элемент числа pairs по модулю M и берём остаток.

import sys

MOD = 1_000_000_007
read = sys.stdin.readline
answers = []

for _ in range(int(read())):
    n = int(read())
    values = read().split()
    prefix = 0
    products = 0
    for x in map(int, values):
        products += prefix * x
        prefix += x

    pairs = n * (n - 1) // 2
    inverse = pow(pairs % MOD, MOD - 2, MOD)
    answers.append(str(products * inverse % MOD))

print("\n".join(answers))

Время: O(N + t · log M) в худшем случае за весь запуск. Дополнительная память: O(nmax + t) в худшем случае. Для prefix и products достаточно O(1) памяти.
