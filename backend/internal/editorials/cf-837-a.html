В тексте A a первое слово даёт 1 заглавную букву, а второе даёт 0. Если на пробеле забыть результат первого слова, в конце получится 0 вместо 1. Поэтому храним два числа: current считает заглавные буквы текущего слова, а best хранит наибольший счёт с начала текста.

Заглавная буква увеличивает current на 1, а строчная оставляет его прежним. На пробеле обнуляем current, чтобы начать счёт для следующего слова.

В слове NonZERO счёт растёт на буквах N, Z, E, R и O и достигает 5 на последней букве. Если обновлять best только на пробеле, программа не учтёт последнее слово, потому что после него нет пробела. Тогда NonZERO даст 0 вместо 5, а Harbour Space UniversitY даст 1 вместо 2. Поэтому после каждого символа берём большее из best и current. К концу каждого слова его полный счёт уже учтён в best.

Внутри слова счёт только растёт или остаётся прежним, поэтому ни один промежуточный счёт не превышает полный. В конце best равен наибольшему объёму слова.

n = int(input())
text = input()
current = 0
best = 0
for ch in text:
    if ch == " ":
        current = 0
    elif ch.isupper():
        current += 1
    best = max(best, current)
print(best)

Время: O(n) в худшем случае: программа читает текст длины n и проверяет каждый символ один раз. Дополнительная память: O(1) в худшем случае сверх входной строки: кроме неё программа хранит только число n, два счётчика current, best и текущий символ ch. Входная строка text из n символов занимает O(n) памяти, а программа сразу печатает одно число длиной до трёх цифр: объём не больше 200. Во входе один текст, поэтому и для всей программы время равно O(n), а дополнительная память сверх входа равна O(1).
