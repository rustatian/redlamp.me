Числа, не равные val, должны оказаться в первых k ячейках nums, где k это их количество.

Решение 1. Two Pointers

Возьмите пример 2: nums = [0, 1, 2, 2, 3, 0, 4, 2], val = 2. Указатель read проходит все ячейки слева направо. Указатель write показывает ячейку, куда встанет следующее число, не равное 2. Сначала write = 0.

Числа 0 и 1 в ячейках 0 и 1 не равны 2. Код пишет их в ячейки 0 и 1, то есть на те же места, и write становится 2. В ячейках 2 и 3 стоят двойки. Код их пропускает, и write остаётся 2. При read = 4 число 3 встаёт в ячейку 2. Потом 0 из ячейки 5 встаёт в ячейку 3, а 4 из ячейки 6 в ячейку 4. Двойку в ячейке 7 код пропускает. Ответ k = 5, в начале nums лежат 0, 1, 3, 0 и 4.

Запись не портит числа, которые read ещё не прочитал. За один шаг read растёт на 1, а write на 1 или на 0. Оба начинают с 0, поэтому всегда write ≤ read. При read = 4 запись идёт в ячейку write = 2. Двойку из этой ячейки read уже прочитал при read = 2. Каждое число, не равное val, код пишет в ячейку write и сдвигает write вправо. Следующие записи идут правее, поэтому записанные числа не пропадают. После последнего шага в ячейках от 0 до write − 1 лежат все числа, не равные val, и ответ равен write.

Время: n это длина nums. Код делает n проверок nums[read] != val и k записей: O(n). В примере 2 это 8 проверок и 5 записей. Дополнительная память: read и write, O(1). Ответ лежит в самом nums.

class Solution:
    def removeElement(self, nums: list[int], val: int) -> int:
        write = 0
        for read in range(len(nums)):
            if nums[read] != val:
                nums[write] = nums[read]  # write ≤ read: эту ячейку read уже прочитал
                write += 1
        return write

Решение 2. Two Pointers с двух концов

Возьмите пример 1: nums = [3, 2, 2, 3], val = 3. Указатель i показывает ячейку, которую код проверяет. Сначала i = 0 и end = 4: end стоит сразу за последней ячейкой.

В ячейке 0 стоит 3. Код делает end -= 1, и end становится 3. Затем код пишет в ячейку 0 число из ячейки 3. Это число ещё не проверено, поэтому i остаётся 0. Следующий шаг снова проверяет ячейку 0: там 3. Теперь end = 2, и в ячейку 0 встаёт 2 из ячейки 2. Двойки в ячейках 0 и 1 не равны 3, и i доходит до end = 2. Ответ k = 2, в начале [2, 2].

Порядок чисел в ответе может быть любым. Поэтому число val можно заменить последним непроверенным числом. Ячейки от i до end − 1 ещё не проверены: после первой замены это ячейки от 0 до 2. Левее i лежат проверенные числа, не равные val: при i = 1 это двойка в ячейке 0.

Каждый шаг делает i += 1 или end -= 1. Сначала end − i равно n, и каждый шаг уменьшает эту разность на 1. В примере 1 разность равна 4, 3, 2, 1 и 0. Поэтому шагов ровно n, и цикл заканчивается при i = end.

Замена уменьшает end на 1 и убирает одно число val из ячеек от 0 до end − 1. После первой замены end = 3, и в ячейках 0, 1 и 2 лежат 3, 2 и 2: одна тройка ушла, двойки остались. Число из ячейки end не пропадает: теперь оно стоит в ячейке i и проходит проверку на следующем шаге. Так при второй замене двойка из ячейки 2 встаёт в ячейку 0. Числа, не равные val, не пропадают никогда. В конце i = end, и левее i лежат только такие числа. Поэтому ячейки от 0 до end − 1 хранят все числа, не равные val, и ответ равен end.

В примере 2 код делает 8 шагов и 3 записи. В начале nums лежат 0, 1, 4, 0 и 3.

Время: n проверок nums[i] == val и n − k записей, по одной на каждое число val: O(n). Решение 2 пишет меньше, когда чисел val меньше половины. Для 100 чисел, где только одно равно val, решение 1 делает 99 записей, а решение 2 одну. Дополнительная память: i и end, O(1).

class Solution:
    def removeElement(self, nums: list[int], val: int) -> int:
        i, end = 0, len(nums)
        while i < end:
            if nums[i] == val:
                end -= 1
                nums[i] = nums[end]  # число с конца ещё не проверено, поэтому i остаётся
            else:
                i += 1
        return end

Другие способы

Новый list из чисел, не равных val, тоже даёт ответ за O(n). Но его k чисел нужно ещё переписать в nums, например строкой nums[:] = [x for x in nums if x != val], а сам новый list занимает O(k) дополнительной памяти.

Вызов nums.remove(val) удаляет одно число и сдвигает влево все числа правее него. Если все 100 чисел равны val, удаления сдвигают 99 + 98 + … + 1 = 4 950 чисел, а решения 1 и 2 делают по 100 проверок. Время такого способа O(n²) в худшем случае.

Типичные ошибки

  • Удаление внутри цикла for x in nums. Для nums = [2, 2, 3] и val = 2 первое удаление даёт [2, 3]. Цикл переходит к ячейке 1, где теперь стоит 3, и вторую двойку не проверяет. Код возвращает len(nums), то есть 2, а верный ответ 1.
  • Строка nums = [x for x in nums if x != val] и затем return len(nums). После этой строки имя nums внутри метода указывает на новый list, а list, который передал тест, не меняется. В примере 1 код возвращает 2, и тест читает первые 2 числа своего list: [3, 2] вместо [2, 2].
  • Ход i += 1 после замены в решении 2. В примере 1 тройка из ячейки 3 встаёт в ячейку 0 и остаётся без проверки. Код возвращает 3, в начале [3, 2, 2].
