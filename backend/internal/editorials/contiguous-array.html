Нужен самый длинный Subarray, в котором нулей столько же, сколько единиц. Оба решения следят за одним числом: балансом, то есть разностью между числом единиц и числом нулей.

Решение 1. Prefix Sum + Hash Table

Возьмите пример 3: nums = [0, 1, 1, 1, 1, 1, 0, 0, 0]. Идите по числам слева направо и считайте баланс b: единица прибавляет к нему 1, ноль отнимает 1. Позиция i значит «после первых i чисел», поэтому на позиции 0 баланс равен 0. Балансы на позициях от 0 до 9: 0, −1, 0, 1, 2, 3, 4, 3, 2, 1. Баланс на позиции i - это Prefix Sum первых i чисел, если каждый 0 заменить на −1.

Баланс равен 1 на позиции 3 и снова на позиции 9. Между этими позициями стоят числа от nums[3] до nums[8]: [1, 1, 1, 0, 0, 0]. Они не изменили баланс, значит, единиц среди них столько же, сколько нулей: 3 и 3. Длина этого Subarray равна 9 − 3 = 6.

Верно и обратное. В Subarray [0, 1] из первых двух чисел примера 3 один ноль и одна единица. Поэтому баланс после него такой же, как до него: 0 на позиции 0 и 0 на позиции 2.

Правило. Среди чисел от nums[j] до nums[i - 1] нулей и единиц поровну ровно тогда, когда балансы на позициях j и i равны. Длина этого Subarray равна i - j.

Теперь задача такая: найти две позиции с равным балансом как можно дальше друг от друга. Возьмите nums = [1, 1, 0, 0, 1, 0]. Балансы на позициях от 0 до 6: 0, 1, 2, 1, 0, 1, 0. Баланс 0 стоит на позициях 0, 4 и 6. Позиция 6 даёт две длины: 6 − 0 = 6 и 6 − 4 = 2. Более ранняя позиция даёт более длинный Subarray. Поэтому Hash Table first хранит для каждого баланса только первую позицию и не меняет её.

До цикла first = {0: 0}: это баланс 0 на позиции 0. На шаге i решение сначала считает новый баланс b. Если b уже есть в first, оно записывает в best большую из двух длин: best и i - first[b]. Если b нет, оно записывает first[b] = i.

В примере 3 цикл делает 9 шагов. На шагах 1, 3, 4, 5 и 6 баланс новый, и first получает запись. На шагах 2, 7, 8 и 9 баланс уже был, длины равны 2, 2, 4 и 6. Ответ 6.

class Solution:
    def findMaxLength(self, nums: list[int]) -> int:
        first = {0: 0}  # first[b] - первая позиция с балансом b
        b = 0
        best = 0
        for i, x in enumerate(nums, 1):
            b += 1 if x == 1 else -1
            if b in first:
                best = max(best, i - first[b])  # между позициями first[b] и i нулей и единиц поровну
            else:
                first[b] = i
        return best

Время: n - длина nums. Цикл делает n шагов. Каждый шаг делает одну проверку b in first и ещё одно чтение или одну запись в Hash Table. Каждая такая операция стоит ожидаемое O(1). Всего ожидаемое O(n). Дополнительная память: first хранит не больше n + 1 записей: одна есть до цикла, и каждый шаг добавляет не больше одной. Это O(n). Ровно n + 1 записей даёт Array из одних единиц: для [1, 1, 1, 1, 1] это балансы 0, 1, 2, 3, 4, 5. В примере 3 записей 6. Ответ - одно число.

Решение 2. Prefix Sum + Array со сдвигом

Чтение и запись в list по индексу стоят O(1) в худшем случае. Поэтому Hash Table можно заменить на list, если знать границы баланса.

Возьмите пример 2: nums = [0, 1, 0], n = 3. Каждое число меняет баланс на 1, поэтому после i чисел он лежит от −i до i. Для любого Array из 3 чисел все балансы лежат от −3 до 3: [1, 1, 1] даёт 3, [0, 0, 0] даёт −3. Это 2 · 3 + 1 = 7 значений. В общем случае значений 2n + 1. list first из 2n + 1 мест хранит первую позицию баланса b в first[b + n]. Сдвиг на n переводит балансы от −n до n в индексы от 0 до 2n: баланс −3 лежит в first[0], баланс 0 в first[3], баланс 3 в first[6]. Число −1 в first значит, что такого баланса ещё не было: позиция не бывает отрицательной. Число 0 для этого не подходит: баланс 0 стоит на позиции 0.

В примере 2 на шаге 1 баланс −1 новый: first[2] = 1. На шагах 2 и 3 баланс уже был, длины равны 2 − 0 = 2 и 3 − 1 = 2. Ответ 2.

class Solution:
    def findMaxLength(self, nums: list[int]) -> int:
        n = len(nums)
        first = [-1] * (2 * n + 1)  # first[b + n] - первая позиция с балансом b; значение -1: такого баланса ещё не было
        first[n] = 0
        b = 0
        best = 0
        for i, x in enumerate(nums, 1):
            b += 1 if x == 1 else -1
            if first[b + n] != -1:
                best = max(best, i - first[b + n])
            else:
                first[b + n] = i
        return best

Время: создание list из 2n + 1 мест стоит O(n). Цикл делает n шагов, каждый шаг стоит O(1). Всего O(n) в худшем случае. Дополнительная память: first занимает 2n + 1 мест: O(n). При n = 105 это 200 001 место. Ответ - одно число.

Что не подходит

Brute Force проверяет каждый Subarray. У Array длины n их n(n + 1)/2: в примере 2 это 3 · 4 / 2 = 6. Если для каждого начала идти вправо и обновлять баланс, получится один шаг на каждый Subarray: O(n²). При n = 105 это 5 000 050 000 шагов: слишком долго.

Типичные ошибки

  • Записывать позицию при каждой встрече баланса. Для [1, 1, 0, 0, 1, 0] на позиции 4 такой код найдёт длину 4 − 0 = 4 и заменит first[0] на 4. На позиции 6 получится только 6 − 4 = 2, и ответ будет 4 вместо 6.
  • Начинать с пустого first. Для [0, 1] баланс 0 на позиции 2 окажется новым, и ответ будет 0 вместо 2.
  • Считать шаги с 0, то есть написать enumerate(nums) и оставить first = {0: 0}. Для [0, 1] ответ будет 1 вместо 2. При счёте с 0 нужна запись first = {0: -1}.
  • В решении 2 создать list из 2n мест. Для [1] это 2 места, баланс 1 попадает в first[2], и Python даёт IndexError.
