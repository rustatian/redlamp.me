Для каждого рейса нужна сумма мест всех бронирований, в отрезок которых он входит.

Возьмите пример 1: 5 рейсов и бронирования [1, 2, 10], [2, 3, 20], [2, 5, 25]. Brute Force прибавляет seats к каждому рейсу отрезка: 2 + 2 + 4 = 8 прибавлений. В худшем случае каждое бронирование покрывает все рейсы, и получается n · b прибавлений, где n - число рейсов, b - число бронирований. При n = b = 2 · 104 это 4 · 108 прибавлений: слишком долго. Время Brute Force: O(n · b).

Решение 1. Difference Array

Посмотрите на одно бронирование [2, 3, 20] без остальных. Рейсы получают 0, 20, 20, 0 и 0 мест. От рейса 1 к рейсу 5 число мест меняется только два раза: на рейсе 2 растёт на 20, на рейсе 4 падает на 20. Код записывает только эти два изменения в список d из нулей. Рейсы пронумерованы с 1, а индексы списка идут с 0, поэтому изменение на рейсе f лежит в d[f - 1]: плюс 20 в d[1], минус 20 в d[3]. Получается d = [0, 20, 0, -20, 0, 0].

Теперь для каждого рейса сложите числа d от начала списка до числа этого рейса. Для рейса 1 это d[0] = 0: сумма не дошла до плюса. Для рейсов 2 и 3 в сумме есть плюс, но нет минуса: 20. Для рейсов 4 и 5 есть плюс и минус: 20 − 20 = 0. Получились те же 0, 20, 20, 0 и 0. Число мест на рейсе f равно сумме чисел от d[0] до d[f - 1]. Это Prefix Sum по d.

Для бронирования [first, last, seats] плюс стоит на рейсе first, минус на рейсе last + 1, сразу после отрезка. В коде это d[first - 1] += seats и d[last] -= seats: рейс last + 1 лежит в d[last]. Код ставит эти две отметки каждого бронирования в один список d. В примере 1 вначале в d стоят 6 нулей. После [1, 2, 10]: d = [10, 0, -10, 0, 0, 0]. После [2, 3, 20]: d = [10, 20, -10, -20, 0, 0]. После [2, 5, 25]: d = [10, 45, -10, -20, 0, -25]. В d[1] сложились плюсы двух бронирований: 20 + 25 = 45. Всего 6 изменений: по 2 на бронирование.

Затем код идёт по d слева направо и копит сумму s: 10, 10 + 45 = 55, 55 − 10 = 45, 45 − 20 = 25, 25 + 0 = 25. Ответ [10, 55, 45, 25, 25].

Для рейса 4 сумма равна 10 + 45 − 10 − 20 = 25. Бронирование [1, 2, 10] вошло в неё с плюсом и с минусом: 10 − 10 = 0. Бронирование [2, 3, 20] тоже: 20 − 20 = 0. От [2, 5, 25] вошёл только плюс 25, потому что рейс 4 лежит в его отрезке. Так для любого рейса. Бронирование, которое кончилось раньше рейса, даёт 0. Бронирование, в отрезок которого рейс входит, даёт seats. Бронирование, которое начинается позже, в сумму ещё не вошло.

Бронирование [2, 5, 25] кончается на последнем рейсе: last = 5 = n, и минус идёт в d[5]. Поэтому длина d равна n + 1 = 6. Цикл Prefix Sum читает только числа от d[0] до d[4], и число d[5] = -25 в ответ не входит.

class Solution:
    def corpFlightBookings(self, bookings: list[list[int]], n: int) -> list[int]:
        d = [0] * (n + 1)
        for first, last, seats in bookings:
            d[first - 1] += seats  # плюс на рейсе first
            d[last] -= seats  # минус на рейсе last + 1
        answer = []
        s = 0
        for i in range(n):
            s += d[i]
            answer.append(s)  # s - число мест на рейсе i + 1
        return answer

Время: 2 изменения d на бронирование при любой длине отрезка и n сложений Prefix Sum: O(n + b) в худшем случае. При n = b = 2 · 104 это 4 · 104 изменений и 2 · 104 сложений вместо 4 · 108 прибавлений. Дополнительная память: список d из n + 1 чисел, O(n). Ответ из n чисел считается отдельно.

Типичные ошибки

  • Список d длины n. В примере 2 n = 2, и оба бронирования кончаются на рейсе 2. Строка d[last] -= seats пишет в d[2], а в списке длины 2 есть только индексы 0 и 1: Python останавливает программу с IndexError.
  • Минус в d[last - 1]. Тогда рейс last не получает свои места. В примере 2 выходит d = [10, -10, 0] и ответ [10, 0] вместо [10, 25].
  • Отметки d[first] += seats и d[last + 1] -= seats, как для номеров с 0. Все отметки сдвигаются на один индекс вправо. В примере 2 со списком длины n + 1 = 3 строка d[last + 1] -= seats пишет в d[3], и Python останавливает программу с IndexError. Со списком длины n + 2 = 4 выходит d = [0, 10, 15, -25], и Prefix Sum первых двух чисел даёт [0, 10] вместо [10, 25].
