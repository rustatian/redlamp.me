В примере с 14 днями есть две полные недели: 14 = 2 · 7. В любых семи днях подряд суббота и воскресенье встречаются по одному разу. Поэтому минимум и максимум совпадают: 2 · 2 = 4.

В двухдневном году с понедельника будет 0 выходных, а с субботы будет 2. Если дней шесть, с понедельника в год попадёт только суббота, а с субботы попадут оба выходных.

Функция divmod(n, 7) даёт число полных недель weeks и остаток rest. Полные недели дают base = 2 · weeks выходных, а остаток начинается в тот же день недели, что и год.

Для минимума начнём с понедельника: первые пять мест в неделе занимают рабочие дни. В остатке не может быть больше пяти рабочих дней, поэтому минимум выходных в нём равен max(0, rest − 5). Для максимума начнём с субботы: тогда выходные идут первыми. Их число ограничено и длиной остатка, и двумя выходными в неделе, поэтому максимум равен min(rest, 2).

n = int(input())
weeks, rest = divmod(n, 7)
base = 2 * weeks
low = base + max(0, rest - 5)
high = base + min(rest, 2)
print(low, high)

Время: O(1) в худшем случае для всего запуска: программа читает одно число длиной до семи цифр и выполняет одно деление с остатком. Дополнительная память: O(1) в худшем случае. Сюда входят временная строка ввода, пара чисел от divmod и числа для расчёта. Программа сразу печатает два числа длиной до шести цифр каждое, пробел и перевод строки.
