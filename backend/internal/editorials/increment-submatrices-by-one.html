Нужно выполнить q прибавлений 1 на прямоугольниках Matrix n × n и вернуть результат. Здесь n - размер Matrix, q - число запросов. Brute Force прибавляет 1 в каждой клетке каждого запроса: в примере 1 это 4 + 4 = 8 прибавлений. В худшем случае каждый запрос покрывает всю Matrix, и получается q · n2 прибавлений. При n = 500 и q = 104 это 2,5 · 109 прибавлений: слишком долго. Время Brute Force: O(q · n2).

Решение 1. Двумерный Difference Array

Код заводит таблицу D из нулей размера (n + 1) × (n + 1). Её строки и столбцы от 0 до n − 1 в конце станут ответом. Строка n и столбец n нужны только для отметок: зачем, видно ниже на примере 1. Для каждого запроса код меняет в D четыре числа: к двум прибавляет 1, из двух вычитает 1. Такое изменение одного числа ниже называется отметкой. Потом код считает Prefix Sum в каждой строке, а затем Prefix Sum в каждом столбце.

Сначала посмотрите на одну отметку. Пусть n = 3, и в D стоит одна отметка: D[0][0] = 1. Prefix Sum в строке 0 даёт [1, 1, 1] в столбцах 0..2, в строках 1 и 2 остаются нули. Prefix Sum в столбцах прибавляет к строке 1 строку 0, а потом к строке 2 новую строку 1. Теперь в строках 0..2 и столбцах 0..2 все 9 чисел равны 1.

Так работает любая отметка. Возьмите клетку (i, j) Matrix. После Prefix Sum в строках D[i][j] равно сумме отметок строки i в столбцах от 0 до j. Prefix Sum в столбцах складывает эти суммы по строкам от 0 до i. В конце D[i][j] равно сумме всех отметок в строках 0..i и столбцах 0..j. Отметка в клетке (r, c) входит в эту сумму, когда r ≤ i и c ≤ j. Поэтому отметка меняет все клетки (i, j), где i ≥ r и j ≥ c: это прямоугольник от клетки (r, c) до правого нижнего угла Matrix.

Теперь второй запрос примера 1: [0, 0, 1, 1] при n = 3. Нужно прибавить 1 к четырём клеткам: (0, 0), (0, 1), (1, 0) и (1, 1). Отметка + 1 в (0, 0) прибавляет 1 ко всем 9 клеткам. Лишние 5 клеток стоят в столбце 2 и в строке 2. Отметка − 1 в (0, 2) убирает единицу из столбца 2, отметка − 1 в (2, 0) убирает её из строки 2. Клетка (2, 2) стоит и в столбце 2, и в строке 2: она получила 1 − 1 − 1 = −1. Четвёртая отметка + 1 в (2, 2) возвращает её к 0. Получилось [[1, 1, 0], [1, 1, 0], [0, 0, 0]].

Запрос [r1, c1, r2, c2] ставит + 1 в (r1, c1), − 1 в (r1, c2 + 1), − 1 в (r2 + 1, c1) и + 1 в (r2 + 1, c2 + 1). Минусы стоят в первом столбце правее прямоугольника и в первой строке ниже него. Клетка внутри прямоугольника получает только первый плюс: 1. Клетка правее прямоугольника в его строках получает плюс и первый минус: 1 − 1 = 0. Клетка ниже прямоугольника в его столбцах получает плюс и второй минус: тоже 0. Клетка правее и ниже получает все четыре отметки: 1 − 1 − 1 + 1 = 0. Клетка выше строки r1 или левее столбца c1 не получает ни одной отметки.

Отметки всех запросов код складывает в одной D. Сумма отметок в строках 0..i и столбцах 0..j тогда складывает вклады всех запросов: каждый запрос даёт 1 клеткам своего прямоугольника и 0 остальным. В примере 1 первый запрос [1, 1, 2, 2] ставит + 1 в D[1][1], − 1 в D[1][3], − 1 в D[3][1] и + 1 в D[3][3]. Три отметки из четырёх стоят в строке 3 или в столбце 3. Такая отметка должна менять клетки от строки 3 или от столбца 3, а в Matrix 3 × 3 их нет. Код ставит эти отметки без проверок: для них в D размера 4 × 4 есть строка 3 и столбец 3. Prefix Sum идёт только по строкам и столбцам от 0 до n − 1, поэтому числа строки n и столбца n в ответ не входят.

После двух запросов строки 0, 1 и 2 в столбцах 0..2 равны [1, 0, −1], [0, 1, 0] и [−1, 0, 1]. Prefix Sum в строках даёт [1, 1, 0], [0, 1, 1] и [−1, −1, 0]. Prefix Sum в столбцах прибавляет к строке 1 строку 0: из [0, 1, 1] и [1, 1, 0] получается [1, 2, 1]. Затем к строке 2 прибавляется новая строка 1: из [−1, −1, 0] и [1, 2, 1] получается [0, 1, 1]. Ответ [[1, 1, 0], [1, 2, 1], [0, 1, 1]]. Клетка (1, 1) лежит в обоих прямоугольниках и получила 2.

class Solution:
    def rangeAddQueries(self, n: int, queries: list[list[int]]) -> list[list[int]]:
        # строка n и столбец n хранят только отметки
        D = [[0] * (n + 1) for _ in range(n + 1)]
        for r1, c1, r2, c2 in queries:
            D[r1][c1] += 1
            D[r1][c2 + 1] -= 1  # первый столбец правее прямоугольника
            D[r2 + 1][c1] -= 1  # первая строка ниже прямоугольника
            D[r2 + 1][c2 + 1] += 1  # клетки правее и ниже получили оба минуса
        for i in range(n):
            for j in range(1, n):
                D[i][j] += D[i][j - 1]  # Prefix Sum в строке i
        for i in range(1, n):
            for j in range(n):
                D[i][j] += D[i - 1][j]  # Prefix Sum в столбце j
        return [D[i][:n] for i in range(n)]

Время: 4 изменения D на запрос и 2n(n − 1) сложений в двух Prefix Sum: O(q + n2). Эти числа не зависят от размеров прямоугольников, поэтому оценка верна для любого входа. В примере 1 это 8 изменений и 12 сложений. При n = 500 и q = 104 это 40 000 изменений и 499 000 сложений, всего 539 000 действий. Создание D и копия ответа в return тоже стоят O(n2). Дополнительная память: D из (n + 1)2 чисел, O(n2). При n = 500 это 251 001 число. Ответ из n2 чисел считается отдельно: его создают срезы в return.

Другие способы

Одномерный Difference Array из главы 3 можно завести в каждой строке. Тогда запрос ставит 2 отметки в каждой строке своего прямоугольника: до 2n отметок на запрос. Затем нужна Prefix Sum в каждой строке. Время O(q · n + n2) в худшем случае. При n = 500 и q = 104 это до 107 отметок и 249 500 сложений в Prefix Sum. Всего до 10 249 500 действий: примерно в 19 раз больше, чем 539 000 в решении 1. Такой код тоже проходит тесты. На входе с n = 500, где каждый из 104 запросов покрывает всю Matrix, Python в браузере (Pyodide) на нашем компьютере выполняет его меньше чем за 1 с, а лимит скрытого теста равен 3 с.

Типичные ошибки

  • Таблица D размера n × n. В примере 1 первый запрос пишет в D[1][3], а в строке длины 3 есть только индексы 0, 1 и 2: Python останавливает программу с IndexError.
  • Отметки в столбце c2 и в строке r2 вместо столбца c2 + 1 и строки r2 + 1. Тогда все четыре отметки стоят внутри прямоугольника. Для n = 3 и запроса [0, 0, 1, 1] это клетки (0, 0), (0, 1), (1, 0) и (1, 1), и ответ равен [[1, 0, 0], [0, 0, 0], [0, 0, 0]]: единицу получила одна клетка из четырёх.
  • Создание D = [[0] * (n + 1)] * (n + 1). Тогда все строки D - это один и тот же list, и отметка в одной строке видна во всех. В примере 2 четыре отметки попадают в один list и дают [0, 0, 0]. Ответ получается [[0, 0], [0, 0]] вместо [[1, 1], [1, 1]].
