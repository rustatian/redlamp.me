Буквы s нужно найти в t слева направо: каждую букву на своём месте t, правее места предыдущей буквы.

Решение 1. Two Pointers

Возьмите пример 1: s = "abc", t = "ahbgdc". Указатель i стоит на букве s, которую код ищет. Указатель j стоит на месте t, которое код смотрит. Сначала i = 0 и j = 0.

На месте 0 стоит a, это s[0]. Буква a нашлась, и i становится 1. Теперь код ищет b. На месте 1 стоит h, а на месте 2 стоит b: i становится 2. На местах 3 и 4 стоят g и d, это не c. На месте 5 стоит c, и i становится 3.

Правило. Сравните s[i] и t[j]. При совпадении сдвиньте i. Указатель j сдвигайте на каждом шаге. Ответ True, когда i дошёл до n = len(s).

В примере 1 код делает 6 сравнений и находит 3 совпадения. Теперь i = 3 = n, ответ True. В примере 2 s = "axc". Буква a нашлась на месте 0, а буквы x в t нет. Цикл заканчивается при j = 6 = m = len(t), и i = 1 меньше n = 3. Ответ False.

Цикл останавливается и при i = n: остаток t уже не нужен. Для s = "ah" и t из примера 1 код делает 2 сравнения. Для пустой s цикл не делает ни одного шага, и i == n даёт True.

Код берёт для каждой буквы s самое левое место, которое ещё можно взять. Это не мешает следующим буквам. Пример: s = "ab", t = "aabb". Буквы s можно взять на местах 1 и 3. Код ищет a с места j = 0 и находит её на месте 0, а 0 не правее 1. После этого j = 1, и место 3 буквы b не левее j. Код находит b на месте 2, а 2 не правее 3.

Так в каждом случае. Пусть буквы s можно взять на местах p0 < p1 < p2 и так далее. Перед поиском s[i] верно j ≤ pi: сначала j = 0. Место pi не левее j, и на нём стоит s[i]. Поэтому код находит s[i] на месте не правее pi. После этого j на 1 больше этого места, поэтому j ≤ pi + 1 ≤ pi + 1. Значит, код найдёт все буквы и вернёт True. Если код вернул False, таких мест нет.

Время: каждый шаг цикла делает одно сравнение и сдвигает j на 1. Цикл идёт, пока j < m, поэтому сравнений не больше m = len(t): O(m) в худшем случае. При m = 104 это не больше 104 сравнений. Дополнительная память: n, m, i и j, O(1) для любого входа.

class Solution:
    def isSubsequence(self, s: str, t: str) -> bool:
        n, m = len(s), len(t)
        i = j = 0
        while i < n and j < m:
            if s[i] == t[j]:
                i += 1  # буква s[i] нашлась на месте j
            j += 1
        return i == n

Решение 2. Binary Search по местам букв

Это ответ на дополнительный вопрос: одна t и очень много s. Решение 1 для каждой s проходит t заново, до m = 104 сравнений. При 109 запросах это до 1013 сравнений.

Запишите для каждой буквы t её места по порядку. Это Hash Table places: ключ это буква, значение это list её мест. Пример: t = "abcabcab". Тогда places["a"] = [0, 3, 6], places["b"] = [1, 4, 7], places["c"] = [2, 5].

Binary Search делает функция bisect_left(row, j) из модуля bisect. Например, bisect_left([2, 5], 3) = 1: число 2 меньше 3, а число 5 с индексом 1 не меньше 3. Функция возвращает индекс k первого числа в list row, которое не меньше j. Если такого числа нет, k = len(row).

Возьмите s = "cbac". j это первое место t, которое ещё можно взять, сначала j = 0. Для c Binary Search в [2, 5] находит первое место не левее 0, это 2. Теперь j = 3. Для b в [1, 4, 7] первое место не левее 3 это 4, и j = 5. Для a в [0, 3, 6] это 6, и j = 7. Для c в [2, 5] места не левее 7 нет, и k = 2 = len(row). Ответ False.

Решение 2 берёт те же места, что и решение 1: самое левое место буквы не левее j. Поэтому довод решения 1 верен и здесь.

Время: ожидаемое для Hash Table. places строится за m добавлений, O(m). Каждая буква s делает один Binary Search в list длины не больше m. При m = 104 это не больше 14 шагов. Итого O(m + n log(m + 1)). В дополнительном вопросе places строится один раз, а каждый запрос стоит O(n log(m + 1)). При n = 100 это не больше 100 · 14 = 1400 шагов вместо 104 сравнений решения 1. Для одного запроса решение 2 не быстрее решения 1: оно тоже читает всю t. Дополнительная память: places хранит ровно m мест, не больше чем в 26 list: O(m) для любого входа.

from bisect import bisect_left


class Solution:
    def isSubsequence(self, s: str, t: str) -> bool:
        places = {}
        for p, c in enumerate(t):
            places.setdefault(c, []).append(p)
        j = 0  # первое место t, которое ещё можно взять
        for c in s:
            row = places.get(c, [])
            k = bisect_left(row, j)  # первое место буквы c не левее j
            if k == len(row):
                return False
            j = row[k] + 1
        return True

Что не подходит

Brute Force перебирает все наборы из n мест t и сравнивает буквы s с буквами на этих местах. C(m, n) это число способов выбрать n мест из m. Если ответ False, Brute Force проверяет все C(m, n) наборов. В примере 2 это C(6, 3) = 20 наборов. При m = 104 и n = 100 наборов больше 10241: слишком долго.

Типичные ошибки

  • Проверить только, что каждая буква s есть в t, например через c in t. Для s = "ba" и t = "ab" обе буквы есть, но b стоит правее a. Такой код вернёт True, а ответ False.
  • Не сдвигать j при совпадении. Тогда одно место t служит двум буквам s. Для s = "aa" и t = "a" такой код вернёт True, а ответ False. В решении 2 та же ошибка: j = row[k] без + 1.
