Ответ - наибольшее ожидание зелёного среди мест строки s, где стоит цвет c. Ожидание места - число секунд до ближайшей g, если идти вперёд по кругу. У места g оно равно 0. Места нумеруем с 0, как в коде.

Пример: s = "rggry", c = r. Цвет r стоит на местах 0 и 3. У места 0 ожидание равно 1: место 1 - это g. От места 3 идём вперёд: место 4 (y), потом строка начинается снова, место 0 (r) и место 1 (g). Это 3 шага, поэтому ожидание места 3 равно 3. Мы не знаем, на каком из двух мест стоим, и гарантия - большее ожидание: max(1, 3) = 3.

Brute Force идёт от каждого места с цветом c вперёд по кругу до первой g. Если g одна и стоит в конце строки, а остальные n − 1 мест имеют цвет c, ожидания равны n − 1, n − 2, ..., 1. Всего n(n − 1)/2 шагов. При n = 2 · 105 это около 2 · 1010 шагов: слишком долго.

Решение 1. Linear Scan по удвоенной строке

У места 3 справа в s нет g: путь уходит за конец строки. Допишем копию строки: d = s + s. Для s = "rggry" получаем d = "rggryrggry". В d ближайшая g справа от места 3 стоит на месте 6, и до неё 6 − 3 = 3 шага. Это тот же путь по кругу: место 6 строки d повторяет место 1 строки s, потому что 6 − 5 = 1.

Пример: n = 5, i = 4. Номера 4, 5, 6, 7, 8 строки d - это места 4, 0, 1, 2, 3: все 5 мест круга по одному разу. Среди них есть g, поэтому путь от места 4 доходит до g не позже номера 8. Последний номер строки d равен 2n − 1 = 9, поэтому номер 8 лежит в d. Для любого места i < n номера i, i + 1, ..., i + n − 1 в d дают все n мест круга по одному разу. Среди этих мест есть g. Поэтому путь не длиннее n − 1 шага. Номер i + n − 1 не больше 2n − 2, поэтому путь целиком лежит в d.

Ожидание места i равно nxt − i, где nxt - номер ближайшей g справа от места i в d. Если d[i] - это g, то nxt = i. Цикл идёт справа налево по i и хранит nxt. В d = "rggryrggry" цикл находит g на местах 7, 6, 2, 1 именно в таком порядке. На месте 3 последняя найденная g имеет номер 6, а g на месте 7 дальше. Последняя найденная g стоит левее всех найденных, поэтому она ближайшая справа от места i.

В ответ входят только места i < n. Места 5, 6, 7, 8, 9 повторяют места 0, 1, 2, 3, 4. У места 8 (r) справа в d нет g, поэтому его ожидание нельзя посчитать. Каждое место строки s входит в ответ один раз.

Ветка elif пропускает места g: ожидание места g равно 0, а best = 0 уже записано. Если c = g, цикл не меняет best, и ответ 0.

Рисунок показывает 10 шагов цикла для s = "rggry". Место 3 даёт best = 3, место 0 даёт только 1.

import sys


def main():
    data = sys.stdin.read().split()
    t = int(data[0])
    out = []
    for k in range(t):
        n = int(data[1 + 3 * k])
        c = data[2 + 3 * k]
        s = data[3 + 3 * k]
        # d - строка, записанная дважды: путь вправо от места i < n в d идёт по кругу
        d = s + s
        nxt = -1
        best = 0
        for i in range(2 * n - 1, -1, -1):
            if d[i] == "g":
                nxt = i
            elif i < n and d[i] == c:
                best = max(best, nxt - i)
        out.append(best)
    print("\n".join(map(str, out)))


main()

Время: цикл делает 2n шагов по O(1), и построение d тоже O(n). В худшем случае это O(n) на набор и O(Σn) на весь вход, где Σn - сумма n по всем наборам. При Σn = 2 · 105 цикл делает 4 · 105 шагов. Дополнительная память: строка d из 2n символов, в худшем случае O(n). При n = 2 · 105 это 4 · 105 символов. Список data - вход, список out - ответ.

Типичные ошибки

  • Проход только по s, без копии. Для s = "rgr" и c = r место 0 ждёт 1 секунду. Место 2 ждёт 2 секунды: через 1 секунду горит место 0 (r), через 2 секунды место 1 (g). Справа от места 2 в s нет g, и такой код отвечает 1 вместо 2.
  • Ожидание считают для каждого места, а не только для мест цвета c. Для s = "gyrrr" и c = r места 2, 3, 4 ждут 3, 2, 1 секунды, и ответ 3. Место 1 (y) ждёт 4 секунды: g стоит на месте 0 после конца строки. Такой код отвечает 4 вместо 3.
  • Проверка цвета c стоит до обновления nxt. Для s = "g" и c = g цикл сначала записывает nxt = 1 на месте 1 (это место копии). Потом на месте 0 он считает 1 − 0 = 1, а ожидание места g равно 0. Такой код отвечает 1 вместо 0.
