На пути из второго примера покрасим вершины 1, 2, 3, 4, 5 по порядку в цвета 0, 1, 0, 1, 0. Если выбрать одну из пяти вершин, а затем одну из четырёх остальных, получим 5 · 4 = 20 вариантов. Варианты (1, 2) и (2, 1) обозначают одно и то же ребро. Каждая пара встречается дважды, поэтому достаточно сравнить цвета 20 / 2 = 10 раз. Разные цвета у концов четырёх рёбер пути и ещё у двух пар, (1, 4) и (2, 5). Вычтем существующие рёбра и получим 6 − 4 = 2 новых ребра. При n = 100 000 Brute Force потребует 4 999 950 000 сравнений цветов. Для n вершин число сравнений равно n(n − 1) / 2, поэтому время перебора составляет O(n2).

Решение 1. BFS и подсчёт пар

В первом примере выберем вершину 1 корнем Tree и дадим ей цвет 0. BFS покрасит её соседей 2 и 3 в цвет 1. Раскраска по чётности номера дала бы концам ребра (1, 3) один цвет, ведь оба номера нечётные.

У корня глубина 0, у его соседей глубина 1. Глубина вершины равна числу рёбер на пути от корня. Цвет меняется на каждом ребре этого пути, поэтому вершины чётной глубины получают цвет 0, а нечётной глубины получают цвет 1. Вершина 1 - родитель вершины 2, а вершина 2 - ребёнок вершины 1. В Tree каждое ребро соединяет родителя с ребёнком, поэтому их глубины отличаются на 1. От корня до каждой вершины ведёт ровно один путь, и цвет корня задаёт цвета во всём Tree.

Дадим теперь вершине 1 цвет 1. Тогда на другом конце каждого из рёбер (1, 2) и (1, 3) нужен цвет 0. Если поменять цвет корня, цвета двух групп поменяются местами, а сами группы останутся теми же. В обеих раскрасках единственное недостающее ребро (2, 3) соединило бы вершины одного цвета. Поэтому в первом примере ответ равен 0.

После обработки вершины 1 в первом примере Deque содержит номера [2, 3]. BFS берёт вершину 2 слева, и в Deque остаётся вершина 3.

Во втором примере при обработке вершины 2 BFS сначала проверяет вершину 1. У неё уже есть цвет 0, поэтому BFS пропускает её. У вершины 3 в списке цветов стоит -1, то есть у неё ещё нет цвета. BFS даёт ей цвет 1 − 1 = 0 и добавляет её в Deque. BFS берёт вершину v с левого конца Deque и присваивает каждому неокрашенному соседу u цвет 1 − color[v]. При обработке вершины на пути от корня BFS добавляет в Deque следующую вершину пути, если у неё ещё нет цвета. Так BFS доходит до каждой вершины. Код отмечает соседа до вызова queue.append(u), поэтому каждая вершина попадает в Deque один раз.

Во втором примере цвет 0 получили вершины 1, 3 и 5, а цвет 1 получили вершины 2 и 4. Для каждой из трёх вершин первой группы есть два варианта во второй. Умножение 3 · 2 = 6 даёт те же шесть пар, что и перебор.

Оба найденных при переборе ребра можно добавить сразу и сохранить ту же раскраску. Если соединить все свободные пары между группами, каждое ребро по-прежнему будет соединять вершины разных цветов и Graph останется двудольным. Ребро внутри группы нарушит раскраску, потому что исходный путь между его концами задаёт им один цвет.

Код записывает в a число вершин цвета 0 и находит число вершин цвета 1 по формуле b = n − a. Всего между группами a · b пар, и каждое из n − 1 рёбер занимает одну такую пару. Вычтем уже занятые пары, как в примере с путём, и получим формулу a · b − (n − 1). Для одной вершины формула тоже даёт 1 · 0 − 0 = 0.

import sys
from collections import deque


def main():
    read = sys.stdin.buffer.readline
    n = int(read())
    adj = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        u, v = map(int, read().split())
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * (n + 1)
    color[1] = 0
    queue = deque([1])
    while queue:
        v = queue.popleft()
        for u in adj[v]:
            if color[u] == -1:
                color[u] = 1 - color[v]
                queue.append(u)

    a = color.count(0)
    b = n - a
    print(a * b - (n - 1))


if __name__ == "__main__":
    main()

Для пути из 5 вершин BFS читает 8 записей в списках соседей. Каждое из n − 1 рёбер даёт две записи, а color.count(0) просматривает список цветов один раз. Время: O(n) в худшем случае. На пути из второго примера в adj шесть списков соседей, а в color шесть ячеек для цветов. В каждом из этих двух списков n + 1 элементов, так как индекс 0 свободен. Если вершина 1 соединена со всеми остальными, после её обработки в Deque ждут все n − 1 соседей, как вершины 2 и 3 в первом примере. Каждая вершина попадает туда один раз, поэтому в Deque одновременно не больше n вершин. Дополнительная память: O(n) в худшем случае для списков соседей, цветов и Deque.
