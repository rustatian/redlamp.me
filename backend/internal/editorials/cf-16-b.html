Greedy: какие коробки взять первыми

В первом примере в рюкзак помещаются 7 коробков, а коробков по 10 спичек всего 5. Берём все пять, затем ещё два коробка по 6 спичек: 5 · 10 + 2 · 6 = 62. Если взять коробок с 5 спичками, пока на складе есть коробок с 6, то обмен даст ещё 6 − 5 = 1 спичку. Такой обмен выгоден всякий раз, когда в рюкзаке меньше спичек в коробке, чем в оставленном коробке. Поэтому сначала берём самые полные коробки, а к следующему виду переходим, только если ещё есть место.

На складе два коробка по 3 спички и два по 7. Если место одно, выгоднее взять коробок с 7 спичками. На три места берём оба коробка по 7 спичек и один по 3: 7 + 7 + 3 = 17. При пяти местах помещается весь запас: 17 + 3 = 20 спичек.

Во втором примере берём один коробок с 3 спичками и оба коробка с 2 спичками: 1 · 3 + 2 · 2 = 7. В коробке от 1 до 10 спичек, поэтому для каждого значения matches достаточно хранить число коробков boxes[matches]. Если два контейнера содержат коробки одного вида, складываем их количества. В одном контейнере бывает до 108 коробков, а в рюкзаке до 2 · 108 мест. Брать по одному коробку слишком долго: понадобится до 2 · 108 шагов, поэтому для каждого числа спичек берём все нужные коробки за один шаг. Для каждого вида берём меньшее из двух чисел: запас коробков и число свободных мест. Если коробки кончатся раньше, выведем число спичек во всех взятых коробках.

remaining, m = map(int, input().split())
boxes = [0] * 11
for _ in range(m):
    amount, matches = map(int, input().split())
    boxes[matches] += amount

total = 0
for matches in range(10, 0, -1):
    take = min(remaining, boxes[matches])
    total += take * matches
    remaining -= take
    if remaining == 0:
        break
print(total)

Время: O(m) в худшем случае для всего ввода: в нём один случай, программа читает m строк контейнеров и проверяет до 10 видов коробков. Дополнительная память: O(1) в худшем случае для всей программы. В списке 11 ячеек, ячейка с номером 0 содержит 0. При чтении одной строки split() создаёт список из двух частей. Для вывода print преобразует один ответ в строку длиной до 10 цифр.
