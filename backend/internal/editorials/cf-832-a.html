При n = 10 и k = 4 после хода Саши останется 10 − 4 = 6 палочек, какой бы конец он ни выбрал. После хода Лены останется 6 − 4 = 2, а для следующего хода нужны четыре. Вышло ровно 2 хода: из 10 палочек получаются две полные группы по 4 и остаток 2, поэтому 10 // 4 = 2.

Вычитать k в цикле шаг за шагом слишком долго: такой цикл делает n // k шагов и занимает O(n / k) времени в худшем случае, а при n = 1018 и k = 1 он выполнит 1018 шагов.

С любого конца игрок убирает ровно k палочек, поэтому выбор конца не меняет ни остаток после хода, ни число следующих ходов. Операция n // k находит число полных групп по k палочек и поэтому даёт общее число ходов turns = n // k.

В примере с десятью палочками Саша и Лена сделали по ходу, поэтому ответ NO. При n = 1 и k = 1 единственный ход делает Саша, поэтому ответ YES. В каждой паре ходов первый делает Саша, второй делает Лена. При чётном turns все ходы образуют пары, а при нечётном у Саши есть ещё один ход.

Если за ход убирают четыре палочки, то и при 10, и при 11 палочках Лена делает второй и последний ход, поэтому ответ NO. При 12 палочках Саша делает третий ход и выигрывает, поэтому ответ YES.

Обычное деление 10 / 4 даёт дробь 2.5 типа float, а тип float хранит целые числа точно только до 253 = 9007199254740992. Для больших чисел до 1018 такое округление может изменить чётность: при n = 1018 − 1 и k = 1 выражение int((10**18 - 1) / 1) даёт чётное число 1000000000000000000 и неверный ответ NO вместо 999999999999999999 и YES. Поэтому нужно целочисленное деление //, которое точно вычисляет число полных групп для всех целых чисел до 1018.

В условии if turns % 2 остаток turns % 2 равен 1 для нечётного turns и 0 для чётного: например, 1 % 2 равен 1, 3 % 2 равен 1, а 2 % 2 равен 0. В Python число 1 считается истинным и даёт ветку YES, а 0 считается ложным и даёт ветку NO.

n, k = map(int, input().split())
turns = n // k
print("YES" if turns % 2 else "NO")

Время: O(1) в худшем случае для всей программы: при 1 ≤ k ≤ n ≤ 1018 оба числа содержат не больше 19 цифр, поэтому программа читает два числа ограниченного размера, делит их нацело и проверяет чётность частного за постоянное число действий. Дополнительная память: O(1) в худшем случае для всей программы: входную строку и ответ считаем отдельно, метод split() создаёт временный список из двух коротких строк не длиннее 19 цифр каждая, а переменные n, k и turns занимают постоянный объём памяти.
