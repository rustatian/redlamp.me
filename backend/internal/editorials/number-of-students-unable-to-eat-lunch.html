Нужно найти, сколько учеников останутся в очереди, когда верхний бутерброд стопки не хочет никто.

Решение 1. Simulation на Deque

Deque q хранит очередь учеников. Вызов q.popleft() забирает ученика из начала, а q.append(s) ставит его в конец. Бутерброды код не удаляет: верхний бутерброд - это sandwiches[top], а выдача делает top += 1. Вызов sandwiches.pop(0) сдвигал бы влево все остальные бутерброды. Счётчик refusals считает отказы подряд после последней выдачи.

Возьмите пример 2: students = [1, 1, 1, 0, 0, 1], sandwiches = [1, 0, 0, 0, 1, 1]. Первый ученик хочет 1 и берёт бутерброд вида 1. Верхним становится бутерброд вида 0. Два ученика с желанием 1 отказываются и встают в конец: refusals = 2, q = [0, 0, 1, 1, 1]. Затем два ученика с желанием 0 берут по бутерброду вида 0. Остаётся q = [1, 1, 1], а верхний бутерброд опять вида 0.

Проверки 6, 7 и 8 дают три отказа подряд, и refusals = 3 равно len(q). Каждый из трёх учеников побывал в начале с этим бутербродом и отказался. После трёх отказов q снова равен [1, 1, 1], и верхний бутерброд тот же. Дальше эти три отказа повторялись бы без конца, поэтому условие refusals < len(q) останавливает цикл. Ответ len(q) = 3.

С любыми данными то же самое. Между двумя выдачами в q стоят те же ученики, меняется только их порядок по кругу. Если хотя бы один из них хочет верхний бутерброд, он окажется в начале меньше чем через len(q) отказов. Значит, refusals доходит до len(q), только когда верхний бутерброд не хочет никто. А если его не хочет никто, цикл заканчивается через len(q) отказов. После выдачи верхним становится новый бутерброд, поэтому код обнуляет refusals: прошлые отказы были от другого бутерброда.

from collections import deque


class Solution:
    def countStudents(self, students: list[int], sandwiches: list[int]) -> int:
        q = deque(students)
        top = 0  # индекс верхнего бутерброда в sandwiches
        refusals = 0  # отказы подряд после последней выдачи
        while q and refusals < len(q):
            s = q.popleft()
            if s == sandwiches[top]:
                top += 1  # ученик берёт бутерброд и уходит
                refusals = 0
            else:
                q.append(s)  # ученик встаёт в конец
                refusals += 1
        return len(q)

Время: n - длина students. Один шаг цикла - одна проверка: popleft, сравнение и, может быть, append, всё за O(1). Выдач не больше n. Пока верхний бутерброд не меняется, отказов подряд не больше len(q), поэтому каждый ученик отказывается от каждого бутерброда не больше одного раза. Отказов не больше n · n, а вместе с выдачами проверок не больше n + n · n, при n = 100 это 10 100: O(n²) в худшем случае. Такой рост бывает. Пусть в students сначала n / 2 нулей, потом n / 2 единиц, а sandwiches = [1, 0, 1, 0, ...]. При n = 50 цикл делает 675 проверок, при n = 100 уже 2600: вдвое больше учеников дают почти вчетверо больше проверок. Дополнительная память: deque(students) копирует всех n учеников: O(n). Остальные переменные занимают O(1).

Решение 2. Counting

В примере 2 два ученика хотят вид 0, а четыре хотят вид 1: want = [2, 4]. Из решения 1 следует: если верхний бутерброд вида t хочет хотя бы один ученик, этот бутерброд кто-то возьмёт. Какой именно ученик, неважно: после выдачи в очереди на одного ученика с желанием t меньше. Следующий бутерброд тоже возьмут, если его вид хочет хотя бы один ученик, при любом порядке очереди. Поэтому хватит двух чисел: want[0] и want[1], сколько учеников в очереди хотят вид 0 и вид 1. Если верхний бутерброд имеет вид t и want[t] = 0, выдача заканчивается.

Бутерброд i = 0 вида 1: want[1] = 4, его берут, и want[1] становится 3. Бутерброды i = 1 и i = 2 вида 0 уменьшают want[0] до 1, потом до 0. Бутерброд i = 3 вида 0: want[0] = 0, его не хочет никто. Выданы 3 бутерброда, без обеда остаются 6 − 3 = 3 ученика. Решение 1 получило тот же ответ за 8 проверок, здесь их 4.

Код возвращает len(sandwiches) - i: бутерброды от 0 до i − 1 выданы, а учеников и бутербродов было поровну. Если цикл выдал все бутерброды, ответ 0.

class Solution:
    def countStudents(self, students: list[int], sandwiches: list[int]) -> int:
        want = [0, 0]  # want[t]: сколько учеников в очереди хотят вид t
        for s in students:
            want[s] += 1
        for i, t in enumerate(sandwiches):
            if want[t] == 0:
                return len(sandwiches) - i  # бутерброд i никто не хочет
            want[t] -= 1
        return 0

Время: первый цикл делает n прибавлений, второй не больше n проверок: O(n) в худшем случае. Дополнительная память: want хранит 2 числа, ещё есть s, i и t: O(1). Вход не меняется.

Типичные ошибки

  • Цикл while q: без счётчика отказов. В примере 2 три ученика с желанием 1 и бутерброд вида 0 остаются навсегда: программа не заканчивается.
  • Нет refusals = 0 после выдачи. В примере 1 первые два ученика отказываются, третий берёт бутерброд, а refusals остаётся 2. Следующий отказ даёт refusals = 3, это len(q), и код возвращает 3 вместо 0.
  • Ответ как разность чисел нулей в sandwiches и в students. Для students = [1, 1, 0, 0] и sandwiches = [0, 0, 0, 1] это 3 − 2 = 1. Верный ответ 2: третий бутерброд вида 0 не хочет никто, и два ученика с желанием 1 не доходят до бутерброда вида 1 под ним.
  • Сравнение students[i] и sandwiches[i] на одних местах. В примере 1 места 0 и 3 различаются, но ответ 0: ученики меняют места в очереди.
