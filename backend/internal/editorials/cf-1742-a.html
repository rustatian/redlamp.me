Решение 1. Проверяем пары

В тройке 1 4 3 первые два числа дают 1 + 4 = 5. На третьем месте стоит 3, поэтому эта пара не подходит. Зато первое и третье числа дают 1 + 3 = 4. Значит, ответ для этой тройки YES.

Выберем число, с которым будем сравнивать сумму. Если это c, складываем a и b. Для b берём a + c, а для a берём b + c. Других позиций в тройке нет. В коде or соединяет эти три равенства и останавливает проверку при первом совпадении.

Для 2 5 8 ни одна пара не подходит, поэтому ответ NO. Для 0 0 0 подходят все три пары, а для ответа YES достаточно одной.

import sys

read = sys.stdin.readline
t = int(read())
answers = []
for _ in range(t):
    a, b, c = map(int, read().split())
    matches = a + b == c or a + c == b or b + c == a
    answers.append("YES" if matches else "NO")

print("\n".join(answers))

На тройке 2 5 8 код выполняет все три сравнения. Время: O(1) на тройку и O(t) на все t троек в худшем случае. При t = 7 в списке answers семь ответов. Когда join собирает из них строку для печати, список ещё хранится в памяти. Дополнительная память: O(1) для проверки одной тройки и O(t) для всей программы в худшем случае.

Решение 2. Находим наибольшее число

Для 15 7 8 общая сумма равна 30. Вычтем из неё наибольшее число 15. Получим 30 − 15 = 15, то есть 7 + 8.

Все числа по условию неотрицательны, поэтому сумма двух чисел не меньше каждого слагаемого. Значит, если подходящая пара есть, её сумма равна наибольшему числу largest. После вычитания largest в rest остаётся сумма двух других чисел. Если rest == largest, эти два числа образуют нужную пару.

В тройке 0 4 4 наибольшее число встречается дважды. Код вычитает одну четвёрку из общей суммы 8, и остаётся 0 + 4 = 4.

import sys

read = sys.stdin.readline
t = int(read())
answers = []
for _ in range(t):
    a, b, c = map(int, read().split())
    largest = max(a, b, c)
    rest = a + b + c - largest
    answers.append("YES" if rest == largest else "NO")

print("\n".join(answers))

Для каждой тройки max просматривает три числа, затем код проверяет одно равенство. Время: O(1) на тройку и O(t) на весь ввод в худшем случае. Код хранит ответы так же, как в примере из первого решения при t = 7. Дополнительная память: O(1) для вычисления largest и rest, O(t) для всей программы в худшем случае.
