У звезды с 4 вершинами 3 ребра. Для каждой вершины можно заново пройти все рёбра и посчитать, во скольких она встречается. Центром будет вершина, которая встретилась во всех трёх рёбрах. Полный подсчёт даёт 4 · 3 = 12 проверок. Для n вершин это n · (n − 1) проверок и O(n2) времени в худшем случае. При максимальном n = 100 000 получится 9 999 900 000 проверок.

Решение 1. Общая вершина двух рёбер

Первое ребро [1, 2] даёт два возможных ответа, a = 1 и b = 2. Проверим, есть ли a в следующем ребре [2, 3]. Вершины 1 там нет, поэтому остаётся b = 2.

Центр есть в каждом ребре звезды. От любой другой вершины идёт только одно ребро, поэтому общим концом двух разных рёбер может быть только центр. Даже в самой маленькой звезде из 3 вершин для такой проверки есть два ребра.

Во втором примере за ребром [1, 2] идёт [5, 1]. Если сравнить только первые концы, получатся разные числа, 1 и 5. Проверка a in edges[1] находит a на второй позиции, и код возвращает 1.

class Solution:
    def findCenter(self, edges: list[list[int]]) -> int:
        a, b = edges[0]
        if a in edges[1]:
            return a
        return b

Время: O(1) в худшем случае. Во втором ребре всего два числа для сравнения с a. Дополнительная память: O(1) в худшем случае для a и b.

Решение 2. Подсчёт степеней

У ребра [1, 2] два конца, поэтому прибавим по единице к счётчикам degree[1] и degree[2]. После рёбер [2, 3] и [4, 2] получим 3 у вершины 2 и по 1 у остальных. В каждом счётчике теперь записана степень вершины, то есть число рёбер у неё.

После последнего ребра получаем degree = [0, 1, 3, 1, 1]. Ячейка degree[0] остаётся равной 0, потому что номера вершин начинаются с 1. Здесь n − 1 = 3, и degree.index(3) возвращает индекс 2, то есть номер центра.

У центра по одному ребру к каждой из остальных n − 1 вершин. Поэтому только у центра степень равна n − 1, а у любой другой вершины она равна 1. Код хранит степень каждой вершины по её номеру, поэтому degree.index(n - 1) вернёт номер центра.

class Solution:
    def findCenter(self, edges: list[list[int]]) -> int:
        n = len(edges) + 1
        degree = [0] * (n + 1)
        for a, b in edges:
            degree[a] += 1
            degree[b] += 1
        return degree.index(n - 1)

Время: O(n) в худшем случае. Код проходит по всем рёбрам, затем ищет нужную степень в списке. Дополнительная память: O(n) в худшем случае. Список degree содержит n + 1 ячеек.
