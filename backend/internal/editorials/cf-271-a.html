Решение 1. Brute Force по годам

После 2011 года проверим 2012. В строке "2012" цифра 2 встречается дважды. Команда different = set(digits) собирает цифры в множество. Оно хранит каждую цифру один раз, поэтому в нём всего три элемента. У следующего года, 2013, в множестве уже четыре элемента. Значит, все четыре цифры разные.

Если на входе сам 2013, первая проверка даёт 2014. Поэтому начинаем с year = y + 1, даже если в y все цифры разные. После каждой неудачной проверки увеличиваем year на единицу. К моменту успешной проверки цикл уже отклонил все годы между y и year. Поэтому year и есть наименьший подходящий год.

Число 9012 больше любого допустимого y, так как y ≤ 9000. В числе 9012 все цифры разные, поэтому поиск закончится не позже этого года. По условию y ≥ 1000, так что у каждого проверяемого года ровно четыре цифры.

y = int(input())
year = y + 1

while True:
    digits = str(year)
    different = set(digits)
    if len(different) == 4:
        print(year)
        break
    year += 1

После 1987 года цикл сделает 2013 − 1987 = 26 проверок. Обозначим число проверок через k = ответ − y. Из границ для входа и ответа получаем k ≤ 9012 − 1000 = 8012. За одну проверку код обрабатывает четыре символа. Время: ожидаемое O(k). Дополнительная память: O(1) в худшем случае. В строке digits четыре символа, а в different не больше четырёх элементов.

Решение 2. Greedy по цифрам

Попробуем увеличить последнюю цифру в 1987. Больше 7 только 8 и 9, а обе уже стоят в начале 198. Если сохранить 19, увеличить 8 можно только до 9, которая повторится. Если сохранить одну лишь 1, увеличить следующую 9 уже нельзя. Остаётся увеличить первую цифру с 1 до 2.

Для y = 2013 сравним ответ 2014 с другим подходящим годом, 2031. В числе 2014 цифра десятков осталась равна 1, а в числе 2031 она выросла до 3. Поэтому 2014 меньше 2031, хотя в единицах 4 > 1. Если год больше y, то в первом слева разряде, где они различаются, его цифра больше. Вариант с первым изменением правее сохраняет меньшую цифру там, где другой вариант её увеличивает. Поэтому пробуем позиции pos справа налево. Срез prefix = year[:pos] сохраняет первые pos цифр.

При pos = 2 в числе 1111 получаем prefix = "11". В множестве одна цифра, поэтому условие len(set(prefix)) != pos здесь означает 1 != 2. Если в prefix есть повтор, он останется при любом продолжении, поэтому переходим на позицию левее. Иначе пробуем цифры больше year[pos] по возрастанию и берём первую, которой нет в prefix. Если такой цифры нет, пробуем увеличить цифру левее.

После замены 1 на 2 в числе 1987 заполним три места справа. Берём 0, затем 1, пропускаем занятую 2 и берём 3. Так получается 2013. На каждое место ставим наименьшую свободную цифру. Любая большая цифра на том же месте даст больший год независимо от продолжения. Свободных цифр хватит на все места, потому что из десяти цифр ответ использует только четыре.

def next_year(year):
    for pos in range(3, -1, -1):
        prefix = year[:pos]
        if len(set(prefix)) != pos:
            continue

        for value in range(int(year[pos]) + 1, 10):
            digit = str(value)
            if digit in prefix:
                continue

            answer = prefix + digit
            for extra in "0123456789":
                if len(answer) == 4:
                    break
                if extra not in answer:
                    answer += extra
            return answer


print(next_year(str(int(input()))))

Для 1987 код пробует все четыре позиции. На каждой позиции код пробует для замены не больше девяти цифр. Чтобы дописать конец ответа, код проверяет до десяти цифр. Время: ожидаемое O(1). Дополнительная память: O(1) в худшем случае. В prefix и во временном множестве не больше трёх элементов. В промежуточной строке answer не больше трёх символов. Четыре символа готового ответа считаем отдельно.
