Ответ собирается из букв двух слов через одну, а в конце стоит остаток более длинного слова.

Решение 1. Two Pointers

Возьмите пример 2: word1 = "ab" и word2 = "pqrs", длины n = 2 и m = 4. Указатель i стоит на следующей букве word1, указатель j на следующей букве word2. Сначала i = 0 и j = 0. Буквы ответа код кладёт в list out. Один шаг цикла кладёт в out букву word1[i], если i < n, и потом букву word2[j], если j < m.

Шаг 1 кладёт в out буквы a и p, теперь i = 1 и j = 1. Шаг 2 кладёт b и q, теперь i = 2 и j = 2. В word1 только 2 буквы, поэтому на шагах 3 и 4 проверка i < n не проходит. Эти шаги кладут только r и s. Цикл заканчивается при i = 2 = n и j = 4 = m. В out лежат 6 букв, и "".join(out) даёт apbqrs.

Пока в word1 есть буквы, каждый шаг сдвигает i на 1. Пока в word2 есть буквы, каждый шаг сдвигает j на 1. Поэтому, пока в обоих словах есть буквы, i = j, и шаг кладёт букву word1[i], а сразу за ней букву word2[i]. Так буквы идут через одну, и первой идёт буква word1.

Когда одно слово кончилось, шаги кладут только буквы другого слова, по порядку. В примере 3 word1 = "abcd" длиннее word2 = "pq". После шага 2 j = 2 = m, и шаги 3 и 4 кладут только c и d. Ответ apbqcd. Цикл идёт, пока i < n или j < m, а после каждой буквы её указатель сдвигается на 1. Поэтому код берёт каждую букву ровно один раз: i проходит все места от 0 до n − 1, а j все места от 0 до m − 1.

Время: код берёт каждую букву один раз, поэтому добавлений ровно n + m. Шагов цикла max(n, m): в примере 2 это 4 шага и 6 добавлений. Потом join копирует n + m букв в итоговую String. Итого O(n + m) в худшем случае. При n = m = 100 это 100 шагов и 200 добавлений. Дополнительная память: list out хранит n + m букв, O(n + m). Кроме него код хранит только n, m, i и j. Итоговая String это ответ, её n + m букв считаются отдельно.

class Solution:
    def mergeAlternately(self, word1: str, word2: str) -> str:
        n, m = len(word1), len(word2)
        out = []
        i = j = 0
        while i < n or j < m:
            if i < n:
                out.append(word1[i])
                i += 1
            if j < m:
                out.append(word2[j])  # в одном шаге буква word2 идёт после буквы word1
                j += 1
        return "".join(out)

Другие способы

Сложение String вместо list: out = out + word1[i] и out = out + word2[j] вместо out.append. String в Python нельзя изменить. Документация Python говорит, что такое сложение каждый раз создаёт новую String. Тогда k-е сложение может копировать k букв, и всего копий букв до 1 + 2 + … + (n + m) = (n + m)(n + m + 1) / 2. В примере 2 эта сумма равна 21, а join копирует 6 букв. При n = m = 100 сумма равна 20 100, а join копирует 200 букв: время O((n + m)²) в худшем случае. Python этого сайта часто дописывает букву без копии, но документация этого не гарантирует. При n, m ≤ 100 такой код тоже проходит тесты.

Типичные ошибки

  • Цикл только по парам букв, например for a, b in zip(word1, word2) или while i < n and j < m. Такой цикл останавливается, когда кончается короткое слово, и теряет остаток длинного. В примере 2 код вернёт apbq вместо apbqrs. В примере 1 длины равны, и ответ apbqcr верный, поэтому этот пример ошибку не покажет.
  • Цикл for k in range(max(n, m)) без проверки k < n перед word1[k]. В примере 2 при k = 2 код читает word1[2], а в word1 только 2 буквы. Python остановит код с ошибкой IndexError.
