В ряду [8, 15, 3, 7] Серёжа сравнивает 8 и 7. Он берёт 8, хотя этим ходом открывает Диме карточку с числом 15. Правило игры задаёт выбор на каждом ходу, поэтому перебирать продолжения игры не нужно.

В ряду [4, 3, 2, 1] можно удалить первую карточку командой cards.pop(0). Тогда Python сдвинет влево три оставшихся элемента списка. Сложим числа сдвигов за четыре хода (3, 2, 1, 0) с теми же числами в обратном порядке. В каждой из четырёх пар сумма равна 3 (3 + 0, 2 + 1, 1 + 2, 0 + 3). Мы учли каждый ход дважды, поэтому за игру получается 4 · 3 / 2 = 6 сдвигов. Если карточки лежат в порядке убывания, игрок каждый раз берёт крайнюю слева. Число сдвигов убывает от n − 1 до 0. Получаем n пар с суммой n − 1 в каждой, а за одну игру выходит n · (n − 1) / 2 сдвигов. При n = 1000 это 499 500 сдвигов. Время игры с таким удалением в худшем случае равно O(n · n).

Решение. Two Pointers

В примере [4, 1, 2, 10] индексы крайних карточек равны left = 0 и right = 3. Серёжа берёт 10 справа. Достаточно уменьшить right с 3 до 2, чтобы Дима сравнил 4 с 2. Дима берёт 4 слева, и left увеличивается с 0 до 1.

Теперь от left до right лежат карточки [1, 2]. Сдвиг границы исключает из игры ровно ту карточку, которую взял игрок. Все остальные сохраняют свои места внутри новых границ. Поэтому при следующем сравнении cards[left] и cards[right] дают числа на концах оставшегося ряда.

После того как Серёжа берёт 2, обе границы указывают на карточку с числом 1. Теперь cards[left] > cards[right] ложно, и Дима получает эту карточку в ветке else. Это последний из n ходов цикла, поэтому код прибавляет её число к счёту только один раз.

Ходы с номерами turn = 0 и turn = 2 дают Серёже 10 + 2 = 12 очков. На ходах 1 и 3 Дима набирает 4 + 1 = 5 очков. Остаток turn % 2 равен 0 на ходах Серёжи и 1 на ходах Димы. По этому индексу код прибавляет число к счёту игрока в списке scores. При scores = [12, 5] звёздочка в print(*scores) передаёт оба числа по порядку, как в print(12, 5). Между числами print ставит пробел, поэтому в ответе получаем 12 5.

n = int(input())
cards = input().split()
cards = list(map(int, cards))
left = 0
right = n - 1
scores = [0, 0]

for turn in range(n):
    if cards[left] > cards[right]:
        card = cards[left]
        left += 1
    else:
        card = cards[right]
        right -= 1
    scores[turn % 2] += card

print(*scores)

В примере split() разбивает строку 4 1 2 10 на четыре части. Каждую из них int преобразует в число. Затем цикл делает четыре сравнения. Каждое число на карточке содержит не больше четырёх цифр, поэтому чтение строки, её разбиение и преобразование всех n чисел занимают O(n) времени. На каждом из n ходов код один раз сравнивает числа и один раз сдвигает границу. Время: O(n) в худшем случае. Дополнительная память: O(n) в худшем случае с учётом чтения, так как временный список содержит n строк. После чтения для игры достаточно O(1) памяти сверх списка карточек. Код хранит две суммы и несколько целых переменных.
