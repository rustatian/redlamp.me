Числа надо переставить внутри самого nums: сначала все 0, потом все 1, потом все 2.

Решение 1. Two Pointers: Dutch National Flag

Возьмите пример 1: nums = [2, 0, 2, 1, 1, 0], n = 6. Код хранит три индекса. Индекс mid читает числа, а low и high показывают, куда код ставит следующий 0 и следующую 2. Сначала low = 0, mid = 0 и high = 5. Ячейки от mid до high код ещё не проверил: сейчас это все 6 ячеек. На каждом шаге код смотрит на число nums[mid]:

  • 0: обмен ячеек low и mid, затем low += 1 и mid += 1;
  • 1: только mid += 1;
  • 2: обмен ячеек mid и high, затем high -= 1, а mid не меняется.

Шаг 1: nums[0] = 2. Обмен ячеек 0 и 5 даёт [0, 0, 2, 1, 1, 2] и high = 4. Шаги 2 и 3: в ячейках 0 и 1 стоит 0, и low = mid. Каждый из этих обменов меняет ячейку саму с собой. После шага 3 low = mid = 2. Шаг 4: nums[2] = 2. Обмен ячеек 2 и 4 даёт [0, 0, 1, 1, 2, 2] и high = 3. Шаги 5 и 6: в ячейках 2 и 3 стоит 1, и mid растёт до 4. Теперь mid = 4 больше high = 3, и цикл кончается. Это ответ.

После шага 4 low = 2, mid = 2 и high = 3. Ячейки 0 и 1 хранят нули. Часть единиц от low до mid − 1 пока пустая. Ячейки 2 и 3 код ещё не проверил. Ячейки 4 и 5 хранят двойки.

Инвариант. Перед каждым шагом ячейки от 0 до low − 1 хранят 0, ячейки от low до mid − 1 хранят 1, ячейки от mid до high не проверены, а ячейки от high + 1 до n − 1 хранят 2.

Каждый шаг сохраняет эти четыре части.

  • Число 2. Обмен ставит 2 в ячейку high, и после high -= 1 эта ячейка входит в часть двоек. В ячейку mid приходит число из ячейки high. Код его ещё не проверил, поэтому mid не растёт. На шаге 1 в ячейку 0 пришёл 0 из ячейки 5, и его проверил только шаг 2.
  • Число 0 при low < mid. В ячейке low стоит 1: это первая ячейка части единиц. Обмен ставит 0 в ячейку low, а 1 в ячейку mid. После low += 1 и mid += 1 обе части снова верны. В [1, 0] шаг 1 даёт mid = 1. Шаг 2 меняет ячейки 0 и 1: [0, 1], low = 1, mid = 2.
  • Число 0 при low = mid. Часть единиц пустая, и обмен меняет ячейку саму с собой, как на шагах 2 и 3 примера 1.
  • Число 1 стоит в ячейке mid, сразу после части единиц, поэтому хватает mid += 1.

Каждый шаг делает ровно одно из двух: mid += 1 или high -= 1. Поэтому число непроверенных ячеек high − mid + 1 уменьшается ровно на 1. В примере 1 оно идёт 6, 5, 4, 3, 2, 1, 0. Цикл кончается при mid = high + 1, когда непроверенных ячеек нет. Тогда nums состоит из нулей, единиц и двоек в этом порядке. Обмен только меняет два числа местами, поэтому ни одно число не пропадает.

Время: n это длина nums. Цикл делает ровно n шагов. На каждом шаге код делает не больше двух сравнений nums[mid] (с 0 и с 1) и не больше одного обмена: O(n). В примере 1 это 6 шагов, 10 сравнений nums[mid] и 4 обмена, из них 2 обмена ячейки с самой собой. Код проходит nums один раз, как просит дополнительный вопрос. Дополнительная память: low, mid, high и два числа на время обмена, O(1). Ответ лежит в самом nums.

class Solution:
    def sortColors(self, nums: list[int]) -> None:
        low, mid, high = 0, 0, len(nums) - 1
        while mid <= high:
            if nums[mid] == 0:
                # в ячейке low стоит 1, или low == mid
                nums[low], nums[mid] = nums[mid], nums[low]
                low += 1
                mid += 1
            elif nums[mid] == 1:
                mid += 1
            else:
                # число из ячейки high ещё не проверено, поэтому mid не растёт
                nums[mid], nums[high] = nums[high], nums[mid]
                high -= 1

Решение 2. Counting Sort

Ответ зависит только от количества нулей, единиц и двоек. Первый цикл считает их в list count. Для примера 1 получается count = [2, 2, 2]. Второй цикл пишет в nums слева направо count[0] нулей, потом count[1] единиц, потом count[2] двоек. В примере 1 код пишет 0 в ячейки 0 и 1, 1 в ячейки 2 и 3, 2 в ячейки 4 и 5.

Второй цикл стирает старые числа, но они уже не нужны: первый цикл прочитал все n чисел до первой записи. Всего код пишет count[0] + count[1] + count[2] = n чисел, поэтому каждая ячейка получает ровно одну запись.

Время: n добавлений в count и n записей в nums: O(n). В примере 1 это 6 добавлений и 6 записей. Код проходит nums два раза, а решение 1 один раз. Дополнительная память: count из 3 чисел и переменные x, i, color и _, O(1).

class Solution:
    def sortColors(self, nums: list[int]) -> None:
        count = [0, 0, 0]
        for x in nums:
            count[x] += 1
        i = 0
        for color in range(3):
            for _ in range(count[color]):
                nums[i] = color
                i += 1

Типичные ошибки

  • mid += 1 после обмена с high. Примеры 1 и 2 такой код проходит, а [1, 2, 0] даёт [1, 0, 2]. Шаг 1 видит 1, и mid = 1. Шаг 2 меняет ячейки 1 и 2: [1, 0, 2], high = 1, но mid = 2. Цикл кончается, и 0 в ячейке 1 остаётся без проверки.
  • Условие while mid < high. Ячейка mid = high тоже не проверена, а цикл её пропускает. Пример 2 даёт [1, 0, 2]: после двух шагов mid = high = 1, и 0 в ячейке 1 остаётся на месте.
  • nums = [0] * nums.count(0) + [1] * nums.count(1) + [2] * nums.count(2). Эта строка создаёт новый list, и имя nums внутри метода указывает на него. Старый list, который передал тест, не меняется: для примера 1 тест получает [2, 0, 2, 1, 1, 0]. Запись по индексу, как nums[i] = color в решении 2, меняет сам старый list.
