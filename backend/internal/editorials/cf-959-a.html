Выигрышный ход

При n = 2 Махмуд вычитает 2. Эхаб получает ноль и проигрывает: вычитать можно только положительные числа. Так Махмуд выигрывает при любом чётном n: он вычитает само n.

При n = 1 Махмуд сразу проигрывает: наименьший разрешённый ему ход равен 2. При n = 7 он может вычесть 2, 4 или 6. Эхабу останется соответственно 5, 3 или 1.

Из нечётного числа Махмуд может вычесть только меньшее чётное число. Разность положительна и нечётна. Эхаб вычитает всю разность и оставляет Махмуду ноль.

В числе 17 = 10 + 7 десяток чётный, поэтому 17 нечётно, как и 7. Любое целое число десятков чётно, поэтому чётность числа определяет его последняя цифра. Код убирает пробелы по краям строки, берёт последнюю цифру и проверяет остаток от деления на 2.

digits = input().strip()
last = int(digits[-1])
winner = "Mahmoud" if last % 2 == 0 else "Ehab"
print(winner)

Пусть L обозначает длину всей входной строки, включая пробелы и перевод строки. Время: O(L) в худшем случае для всей программы: чтение строки и удаление пробелов занимают O(L) времени. Дополнительная память: O(L) в худшем случае: исходная строка и результат strip() занимают не более L символов каждый. Для проверки нужна одна цифра, а print выводит одно имя без списка ответов. По условию n ≤ 109, поэтому в строке не больше 10 цифр.
