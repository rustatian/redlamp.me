При n = 37 можно перебрать все 37 чисел и для каждого вычислить g(x). Например, g(2) = g(3) = 1. Чтобы получить ответ, считаем единицу и каждое другое значение только один раз. На каждый x придётся одно деление, всего n делений. При наибольшем допустимом n = 10100 − 1 это 10100 − 1 делений на один набор, поэтому даже без учёта разворотов перебор займёт слишком много времени.

Что остаётся после двух разворотов

Возьмём x = 10200. Если прочитать его справа налево, получится запись 00201, то есть число 201. После второго разворота получим 102. Нуль между единицей и двойкой остался, а два нуля в конце исчезли. Поэтому g(10200) = 10200 / 102 = 100.

Пусть в конце числа x стоят ровно k нулей. После первого разворота эти нули оказываются в начале записи, и функция f их удаляет. В конце теперь стоит первая цифра числа x, а она отлична от нуля. Поэтому при втором развороте все оставшиеся цифры возвращаются в исходный порядок без потерь. Чтобы из f(f(x)) снова получить x, надо приписать справа k нулей. Это умножение на 10k, поэтому частное g(x) равно 10k.

Когда появляется новое значение

При n = 37 число x = 1 даёт g(x) = 1, а x = 10 даёт g(x) = 10. Если убрать два конечных нуля, останется число не меньше 1. Поэтому наименьшее число с двумя нулями на конце равно 1 · 100 = 100, что больше 37. Для k конечных нулей тот же расчёт даёт наименьшее x = 1 · 10k. Значит, значение 10k впервые появляется при x = 10k.

При n = 9 встречается только значение 1. От n = 10 до n = 99 ответ остаётся равным 2. При n = 100 к значениям 1 и 10 добавляется 100, и ответ вырастает до 3.

Число 37 двузначное: двузначные числа начинаются с 10, а трёхзначные с 100. Наименьшее число из d цифр состоит из единицы и d − 1 нулей. Если приписать ещё один нуль, получится наименьшее число из d + 1 цифр. Поэтому для числа n из d цифр верны границы 10d − 1 ≤ n < 10d. Значит, подходят показатели степени от 0 до d − 1 включительно. Их ровно d: показатель 0 тоже входит в счёт, поскольку 100 = 1.

Для строки "37\n" метод strip() убирает перевод строки и оставляет "37". По условию первая цифра n отлична от нуля, поэтому len(n) даёт нужное число цифр.

import sys

t = int(sys.stdin.readline())
for _ in range(t):
    n = sys.stdin.readline().strip()
    print(len(n))

Для чисел 100 и 37 программа читает всего 3 + 2 = 5 цифр, а в самой длинной строке их 3. Обозначим через S общее число цифр во всех t числах, а через D число цифр в самой длинной записи. Время: O(d) на набор и O(S) на весь ввод в худшем случае с учётом чтения. Пока программа читает строку с числом 37 и вызывает strip(), в n ещё хранится строка "100". При удалении перевода строки strip() может скопировать цифры в новую строку. Ответ для каждого числа программа печатает сразу. Дополнительная память: в худшем случае O(d) для одного набора при отдельном запуске и O(D) для всего ввода.
