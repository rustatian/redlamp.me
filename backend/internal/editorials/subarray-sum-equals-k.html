n - длина nums, места считаем с 0. Нужно посчитать Subarray с суммой k. Решение читает nums один раз и для каждого правого конца считает подходящие начала.

Решение 1. Prefix Sum и Hash Table

Prefix Sum p[i] - это сумма первых i чисел, p[0] = 0. В примере 2 nums = [1, 2, 3] и p = [0, 1, 3, 6]. Subarray [2, 3] занимает места 1 и 2. p[3] = 1 + 2 + 3: это сумма чисел на местах 0, 1 и 2. p[1] = 1: это число на месте 0. Разность p[3] − p[1] = 6 − 1 = 5 оставляет места 1 и 2: это 2 + 3. Так для любых мест: сумма чисел с места l по место r равна p[r + 1] − p[l]. Она равна k, когда p[l] = p[r + 1] − k.

В примере 2 k = 3. Правый конец 0: p[1] = 1, нужен более ранний префикс 1 − 3 = −2, такого нет. Правый конец 1: p[2] = 3, нужен префикс 0, это p[0]: Subarray [1, 2]. Правый конец 2: p[3] = 6, нужен префикс 3, это p[2]: Subarray [3]. Ответ 2.

Возьмите nums = [1, -1, 1, 1, -1], k = 1: префиксы равны 0, 1, 0, 1, 2, 1. Значение 0 встретилось 2 раза, значение 1 встретилось 3 раза. Для p[5] = 1 нужен префикс 0, и подходят оба: p[0] и p[2]. Это два Subarray: с места 0 по место 4 и с места 2 по место 4. Поэтому Hash Table cnt хранит для каждого значения префикса число встреч.

Код не хранит весь список p. В начале cnt = {0: 1}: это p[0] = 0. На шаге места r код читает x = nums[r] и делает три действия. Сначала s += x: теперь s равно p[r + 1]. Потом ans += cnt.get(s - k, 0): столько более ранних префиксов равно s − k. Потом cnt[s] растёт на 1.

В строке p отмечены более ранние префиксы, равные s − k: их номера - это начала новых Subarray. Строки «ключ» и cnt показывают Hash Table в момент поиска, до записи cnt[s]. По шагам ответ растёт на 1, 0, 2, 2 и 2: всего 1 + 0 + 2 + 2 + 2 = 7. В конце cnt = {0: 2, 1: 3, 2: 1}.

Возьмите Subarray с места 2 по место 4. Это пара префиксов p[2] = 0 и p[5] = 1. Правый префикс p[5] попадает в s только на шаге места 4. В этот момент в cnt записаны p[0], ..., p[4], и p[2] среди них. Сам p[5] ещё не записан. Так для любого Subarray с суммой k с места l по место r: код считает пару p[l] и p[r + 1] один раз, на шаге места r. Префикс p[r + 1] в этот момент ещё не записан, поэтому при k = 0 код не считает пару p[r + 1] с самим собой, и пустой Subarray в ответ не попадает.

class Solution:
    def subarraySum(self, nums: list[int], k: int) -> int:
        cnt = {0: 1}  # cnt[v] - сколько раз уже встретился префикс v
        s = 0  # сумма прочитанных чисел
        ans = 0
        for x in nums:
            s += x
            ans += cnt.get(s - k, 0)  # каждый более ранний префикс s - k даёт один Subarray
            cnt[s] = cnt.get(s, 0) + 1
        return ans

Время: цикл делает n шагов. На каждом шаге два чтения и одна запись в cnt, каждая операция за ожидаемое O(1). Всего ожидаемое O(n). При n = 2 · 104 это 20 000 шагов. Дополнительная память: в cnt не больше n + 1 ключей, O(n) в худшем случае. Ровно n + 1 ключей получается, когда все префиксы разные: например, когда все числа положительные. Ответ - одно число не больше n(n + 1)/2. При n = 2 · 104 это 200 010 000: столько даёт nums из 20 000 нулей при k = 0.

Что не подходит

Brute Force берёт каждое начало l, двигает конец r от l до места n − 1 и прибавляет nums[r] к бегущей сумме. В примере 2 он получает 3 · 4 / 2 = 6 сумм: 1, 3, 6, 2, 5 и 3. Сумма 3 встретилась 2 раза. При длине n сумм n(n + 1)/2, на каждую идёт одно сложение: O(n²). При n = 2 · 104 это 200 010 000 сложений. Наш запуск такого перебора на тесте с n = 2 · 104 занял больше 8 секунд при лимите 3 секунды на скрытый тест: слишком долго.

Sliding Window сдвигает левый край, когда сумма окна больше k. Этот шаг верен, когда все числа положительные: тогда каждое новое число увеличивает сумму окна, и у каждого правого конца не больше одного подходящего начала. Здесь числа бывают отрицательными. В nums = [1, -1, 1, 1, -1] окно [1] имеет сумму 1, а более длинное окно [1, -1] имеет сумму 0. У правого конца 4 два подходящих начала: 0 и 2. Окно даёт не больше одного Subarray на каждый правый конец, то есть не больше 5, а ответ 7.

Типичные ошибки

  • Начать с пустого cnt = {}. Для Subarray, который начинается с места 0, нужен префикс p[0] = 0, а его в cnt нет. В примере 2 теряется [1, 2], и ответ 1 вместо 2.
  • Увеличить cnt[s] до поиска. При k = 0 код ищет s − 0 = s и находит префикс, который только что записал сам. Это пустой Subarray. Для nums = [0, 0, 0], k = 0 получится 9 вместо 6.
  • Хранить set префиксов без числа встреч. Тогда шаг прибавляет не больше 1. Для nums = [1, -1, 1, 1, -1], k = 1 получится 4 вместо 7.
