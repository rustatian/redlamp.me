Города на пути от столицы расположены в порядке 0, 1, 2, 3. Чтобы узнать, сколько людей проедет по каждой дороге, можно пройти путь каждого представителя до столицы и прибавить единицу к счётчику каждой пройденной дороги. На этом пути получится 1 + 2 + 3 = 6 шагов. Если столица находится на конце пути из n городов, число шагов равно n · (n − 1) / 2. При n = 100 000 получится 4 999 950 000 шагов, поэтому такой подсчёт за O(n2) слишком долог.

Решение 1. Размеры поддеревьев в обратном порядке BFS

Во втором примере путь из города 2 в столицу проходит через города 3 и 1. Если закрыть дорогу из 1 в 0, по другую сторону от столицы останутся города 1, 3, 2. Жители этих трёх городов должны проехать по этой дороге. При seats = 2 в одной машине для них мало мест, а двух машин хватает.

У каждого города, кроме столицы, есть родитель. Это следующий город на пути в столицу. Число людей, которым нужна дорога из 1 к родителю, равно размеру поддерева города 1, то есть size[1] = 3. Из любого такого поддерева есть только один выезд по дороге к родителю. Чтобы найти наименьшее число поездок по этой дороге, делим size[city] на seats и округляем вверх.

Для троих на дороге из 1 в 0 расчёт (3 + 2 - 1) // 2 даёт те же две машины. На дороге из 3 в 1 едут двое, и (2 + 2 - 1) // 2 даёт одну машину. Операция // округляет результат вниз. Если число людей делится на seats без остатка, прибавки seats - 1 не хватает до следующего кратного seats. Если есть остаток, этой прибавки хватает, и // даёт на единицу больше. Число машин для дороги к родителю равно (size[city] + seats - 1) // seats.

В городе 1 двое приезжих могут продолжить путь в своей машине, а местный представитель поедет в своей. Прибывших машин хватает для всех приезжих, а в городе есть ещё одна машина для местного жителя. При пересадке заполняем одну машину за другой, пока все не сядут. Лишние машины оставляем в городе. Если так поступать в каждом городе по пути к столице, число поездок на каждой дороге будет наименьшим. Каждая машина тратит на дорогу один литр, так что складываем число поездок по всем дорогам.

В примере BFS записывает города в order = [0, 1, 4, 5, 3, 6, 2]. Мы начинаем обход со столицы и дописываем соседей в конец order, пропуская родителя. При чтении с конца каждый ребёнок встретится раньше родителя.

Сначала ставим size[city] = 1, чтобы учесть местного жителя. К моменту подсчёта машин для города в size[city] уже учтены люди из поддеревьев всех его детей. После подсчёта прибавляем size[city] к size[parent[city]], чтобы учесть тех же людей в поддереве родителя. Для дороги из 1 в 0 получаем две машины, для остальных пяти дорог по одной, всего 7 литров. Если есть только город 0, цикл сразу останавливается и fuel остаётся равным нулю.

class Solution:
    def minimumFuelCost(self, roads: list[list[int]], seats: int) -> int:
        n = len(roads) + 1
        neighbors = [[] for _ in range(n)]
        for a, b in roads:
            neighbors[a].append(b)
            neighbors[b].append(a)

        parent = [-1] * n
        order = [0]
        for city in order:
            for neighbor in neighbors[city]:
                if neighbor != parent[city]:
                    parent[neighbor] = city
                    order.append(neighbor)

        size = [1] * n
        fuel = 0
        for city in reversed(order):
            if city == 0:
                break
            cars = (size[city] + seats - 1) // seats
            fuel += cars
            size[parent[city]] += size[city]
        return fuel

Время: O(n) в худшем случае, где n обозначает число городов. В списках соседей каждая дорога встречается дважды, а в обратном обходе для неё нужно одно деление. Дополнительная память: O(n) в худшем случае для списков соседей, parent, order и size.

Решение 2. Удаление листьев

Соединим город 1 со столицей 0 и с городами 2 и 3. В каждой машине три места. У каждого из городов 2 и 3 есть только одна дорога, и обе ведут в город 1. Теперь в городе 1 собираются трое и доезжают до столицы в одной машине. На три дороги уходит 1 + 1 + 1 = 3 литра.

Путь из другого города в столицу не проходит через город 3, потому что для въезда и выезда нужны две разные дороги. По той же причине удаление города вне столицы с одной оставшейся дорогой сохраняет пути остальных городов в столицу. Когда у города вне столицы остаётся один сосед, через этого соседа проходит единственный путь в столицу. Такой город называют листом и кладут в Stack leaves. К этому моменту остальные соседи уже передали листу всех людей со своей стороны. При удалении листа прибавляем к fuel число машин для people[city] человек. Затем прибавляем people[city] к числу людей у оставшегося соседа.

В degree[city] храним число оставшихся соседей города. Например, после удаления городов 3 и 2 значение degree[1] падает с трёх до одного, и город 1 сам попадает в leaves. Номера 2 и 3 остаются в neighbors[1], а нули в degree[2] и degree[3] показывают, что эти города уже удалены. При поиске цикл пропускает соседей с такой отметкой. У города 1 остаётся только сосед 0, к нему и едут люди. Столицу в Stack не кладём, потому что в ней поездки заканчиваются.

class Solution:
    def minimumFuelCost(self, roads: list[list[int]], seats: int) -> int:
        n = len(roads) + 1
        neighbors = [[] for _ in range(n)]
        for a, b in roads:
            neighbors[a].append(b)
            neighbors[b].append(a)

        degree = [len(row) for row in neighbors]
        leaves = [v for v in range(1, n) if degree[v] == 1]
        people = [1] * n
        fuel = 0
        while leaves:
            city = leaves.pop()
            degree[city] = 0
            for neighbor in neighbors[city]:
                if degree[neighbor] == 0:
                    continue
                fuel += (people[city] + seats - 1) // seats
                people[neighbor] += people[city]
                degree[neighbor] -= 1
                if neighbor != 0 and degree[neighbor] == 1:
                    leaves.append(neighbor)
                break
        return fuel

Время: O(n) в худшем случае. Каждый город вне столицы попадает в Stack один раз, поэтому суммарно цикл проверит не более 2 · (n − 1) записей о соседях. Дополнительная память: O(n) в худшем случае для списков соседей, degree, people и Stack.
