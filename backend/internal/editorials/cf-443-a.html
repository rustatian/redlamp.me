В строке {b, a, b, a} 12 символов: скобки { и }, три запятые ,, три пробела и четыре буквы b, a, b, a. Вызов set("{b, a, b, a}") без отбора даёт 6 разных символов вместо 2 букв, потому что скобки, запятая и пробел тоже попадают в множество. Считать нужно только буквы: сначала встречаются b и a, затем обе повторяются, поэтому ответ равен 2.

Будем хранить встреченные буквы в множестве seen. Перебираем строку по одному символу. Текущий символ обозначим ch. Для символов {, ,, пробела и } вызов ch.isalpha() возвращает False, а для букв b и a возвращает True. Метод ch.isalpha() даёт True только для букв, поэтому в множество seen попадают только буквы. При первом добавлении буквы размер seen растёт на 1. При повторном добавлении той же буквы размер остаётся прежним.

Так каждая буква из строки входит в seen ровно один раз, и len(seen) даёт ответ. В строке {} обе скобки не проходят проверку, поэтому программа печатает 0.

line = input()
seen = set()
for ch in line:
    if ch.isalpha():
        seen.add(ch)
print(len(seen))

Пусть n - длина входной строки. Время: ожидаемое O(n) для всей строки. В seen не больше 26 разных букв, поэтому даже в худшем случае одно добавление занимает O(1), а весь проход занимает O(n). Входная строка line занимает O(n) памяти. Дополнительная память: O(1) в худшем случае для множества и текущего символа.

Типичные ошибки

Код len(set(line[1:-1].split(", "))) ошибётся на входе {}. На строке {b, a, b, a} срез line[1:-1] убирает скобки и даёт "b, a, b, a". Вызов "b, a, b, a".split(", ") возвращает список ['b', 'a', 'b', 'a'], а len(set(['b', 'a', 'b', 'a'])) даёт верный ответ 2. На входе {} срез line[1:-1] равен пустой строке "". Вызов "".split(", ") возвращает список [''] из одного элемента, поэтому len(set([''])) даёт 1 вместо 0. Метод ch.isalpha() отбрасывает скобки, запятые и пробелы без разбиения строки.
