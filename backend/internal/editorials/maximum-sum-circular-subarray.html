Нужен Subarray с наибольшей суммой. Он может дойти до последнего места nums и продолжиться с места 0. В примере 2 так получается [5, 5]: последнее число 5 и первое число 5.

Brute Force берёт каждое начальное место и каждую длину от 1 до n. Здесь n - длина nums. Для одного начального места сумма следующей длины - это прошлая сумма плюс одно число, поэтому каждая пара даёт одно сложение. Всего n · n = n2 сложений. Это O(n2) сложений. При n = 3 · 104 это 9 · 108 сложений: слишком долго.

Решение 1. Prefix Sum и Monotonic Deque

Возьмите пример 2: nums = [5, -3, 5], n = 3. Допишите nums к самому себе: [5, -3, 5, 5, -3, 5]. Subarray [5, 5] стоит в длинном Array на местах 2 и 3. Любой Subarray круга длиной от 1 до n стоит в длинном Array как обычный Subarray. Subarray длины n + 1 = 4 запрещён: его первое и последнее место - это одно место круга, и число этого места вошло бы в сумму два раза. На местах 0..3 это число 5: место 3 длинного Array - это снова место 0 круга.

Prefix Sum даёт сумму любого куска за одно вычитание. Здесь p[0] = 0, а p[j] - сумма первых j чисел длинного Array. Для примера 2 получается p = [0, 5, 2, 7, 12, 9, 14]. Числа на местах от i до j − 1 дают сумму p[j] - p[i]. Для [5, 5] это i = 2, j = 4 и 12 − 2 = 10.

Зафиксируйте конец j. Начало i может быть любым номером от j − n до j − 1: тогда длина j − i от 1 до n. Эти номера называются окном. Число p[j] уже известно, поэтому лучшая сумма с концом j получается при наименьшем p[i] в окне. При j = 4 окно - это номера 1, 2 и 3 с p = 5, 2 и 7. Наименьшее p = 2 стоит на номере 2, и сумма равна 12 − 2 = 10.

При j = 1 окно - это номера от −2 до 0. Номеров меньше 0 нет, поэтому в окне только номер 0.

Наименьшее p окна находит Monotonic Deque. Он хранит номера окна так, что p растёт от начала к концу Deque. Поэтому наименьшее p стоит в начале.

Спереди: при j = 4 окно - это номера 1, 2 и 3, а в Deque стоит номер 0. Он вышел из окна: j − n = 4 − 3 = 1 и 0 < 1. Его убирают спереди. Окно за шаг сдвигается на 1 номер, поэтому спереди уходит не больше одного номера.

Сзади: при j = 2 в Deque стоят номера 0 и 1 с p = 0 и 5, а новый номер 2 имеет p[2] = 2. Число 2 меньше 5, поэтому начало 2 даёт большую сумму, чем начало 1, для любого конца. Для j = 3 это 7 − 2 = 5 против 7 − 5 = 2. Начало 2 к тому же уйдёт из окна позже: номер 1 вышел бы при j = 5, а номер 2 при j = 6. Поэтому номер 1 никогда не станет лучшим, и его убирают сзади.

Правило. На шаге j уберите спереди номер, который вышел из окна. Тогда лучшая сумма с концом j равна p[j] - p[dq[0]]. Потом уберите сзади номера с p не меньше p[j] и добавьте номер j.

Рисунок показывает все шаги j = 1..6 для примера 2. Переменная best хранит наибольшую из лучших сумм с концами от 1 до j. Значения best по шагам: 5, 5, 7, 10, 10, 10. Ответ 10.

Все Subarray круга учтены. Subarray с началом на месте s от 0 до n − 1 и длиной L от 1 до n - это i = s и j = s + L длинного Array. Здесь j не больше 2n − 1, а цикл доходит до 2n. Для [5, 5] из примера 2 это s = 2, L = 2, j = 4, и номер i = 2 лежит в окне 1..3. Каждая сумма p[j] - p[i] с началом i из окна - это сумма не больше n чисел подряд длинного Array. Это разные места круга, поэтому ни одно число не берётся два раза. Длина не меньше 1, поэтому Subarray непустой: для [-3, -2, -3] ответ −2 без особого случая.

from collections import deque


class Solution:
    def maxSubarraySumCircular(self, nums: list[int]) -> int:
        n = len(nums)
        p = [0]
        for x in nums + nums:
            p.append(p[-1] + x)
        dq = deque([0])  # номера с возрастающими p: впереди наименьший
        best = nums[0]
        for j in range(1, 2 * n + 1):
            if dq[0] < j - n:  # начало i вышло из окна j - n..j - 1
                dq.popleft()
            best = max(best, p[j] - p[dq[0]])  # лучшее начало даёт наименьший p в окне
            while dq and p[dq[-1]] >= p[j]:  # начало j не хуже и уйдёт из окна позже
                dq.pop()
            dq.append(j)
        return best

Время: цикл делает 2n шагов, при n = 3 · 104 это 6 · 104 шагов. Каждый номер входит в Deque один раз и выходит не больше одного раза, поэтому все операции с Deque вместе дают O(n) в худшем случае. В примере 2 вошли 7 номеров (1 при создании и 6 append), 2 ушли сзади и 2 спереди. Дополнительная память: новый список nums + nums из 2n чисел, p из 2n + 1 чисел и Deque до n + 1 номеров. Всего не больше 5n + 2 чисел: O(n) в худшем случае.

Решение 2. Kadane's Algorithm

Subarray на круге бывает двух видов. Первый не переходит через границу между последним местом и местом 0: это обычный Subarray. Второй переходит: он состоит из конца и начала nums и пропускает кусок посередине. Subarray из всех n чисел с началом не на месте 0 тоже переходит через границу, но ничего не пропускает. Его сумма равна сумме всего Array, а весь Array - Subarray первого вида.

Возьмите пример 2: nums = [5, -3, 5]. Сумма всех чисел total = 7. Subarray [5, 5] второго вида пропускает кусок [-3]. Его сумма равна 7 − (−3) = 10: это total минус сумма пропущенного куска. Число total не меняется, поэтому для второго вида нужен пропущенный кусок с наименьшей суммой.

Kadane's Algorithm находит за один проход наибольшую и наименьшую сумму обычного Subarray. Для каждого числа x он считает cur_max: наибольшую сумму Subarray, который заканчивается на x. В примере 2 на числе −3 заканчиваются [-3] с суммой −3 и [5, -3] с суммой 5 − 3 = 2. Здесь 5 равно прошлому cur_max. Наибольшая из двух сумм 2, поэтому cur_max = 2.

На следующем числе 5 заканчиваются три Subarray: [5], [-3, 5] и [5, -3, 5]. Два длинных получаются так: к [-3] и к [5, -3] дописывают число 5. Их суммы −3 + 5 = 2 и 2 + 5 = 7. Число 5 прибавляется к каждой прошлой сумме, поэтому наибольшая из новых сумм - это прошлый cur_max плюс 5, то есть 2 + 5 = 7. Короткий Subarray [5] даёт сумму 5. Поэтому cur_max = max(7, 5) = 7. Так на каждом числе cur_max - это большее из двух: x один или прошлый cur_max плюс x. Если прошлый cur_max отрицательный, он только уменьшает сумму, и лучше начать заново с x. Так же cur_min берёт меньшее из двух. Для примера 2 получается best = 7 и worst = -3, а ответ max(7, 7 − (−3)) = 10.

Кусок worst может стоять у края nums. Возьмите nums = [-5, 1, 2]: total = −2, а наименьшая сумма worst = −5 стоит на месте 0. Тогда total − worst = −2 − (−5) = 3. Это сумма остальных чисел [1, 2]. Остальные числа всегда идут подряд по кругу. Поэтому значение total − worst равно сумме настоящего Subarray, если worst не весь Array. Эта сумма не больше ответа. Она не меньше суммы любого Subarray второго вида, потому что worst не больше любого пропущенного куска.

Теперь возьмите nums = [-3, -2, -3]. Здесь total = −8 и worst = −8: самый плохой Subarray - весь Array. Тогда total − worst = 0. Это сумма пустого Subarray, в котором не осталось ни одного числа. Пустой Subarray запрещён, а верный ответ −2. Если best < 0, все числа отрицательные. Сумма нескольких отрицательных чисел меньше каждого из них, поэтому ответ - наибольшее число, то есть best. Если best ≥ 0, пустой Subarray с суммой 0 не больше best, и max его не выбирает.

class Solution:
    def maxSubarraySumCircular(self, nums: list[int]) -> int:
        total = 0
        cur_max = cur_min = 0
        best = worst = nums[0]
        for x in nums:
            cur_max = max(cur_max + x, x)  # лучшая сумма Subarray, который заканчивается на x
            best = max(best, cur_max)
            cur_min = min(cur_min + x, x)  # худшая сумма Subarray, который заканчивается на x
            worst = min(worst, cur_min)
            total += x
        if best < 0:  # все числа отрицательные: total - worst дало бы пустой Subarray
            return best
        return max(best, total - worst)

Время: один проход по n числам: O(n) в худшем случае. Дополнительная память: шесть переменных total, cur_max, cur_min, best, worst и x: O(1) в худшем случае. Ответ - одно число.

Типичные ошибки

  • Начальное значение best = 0 в решении 1. Для nums = [-3, -2, -3] код вернёт 0 вместо −2. Сумма пустого Subarray равна 0.
  • Решение 2 без проверки best < 0. Для nums = [-3, -2, -3] формула даёт max(−2, 0) = 0 вместо −2.
  • Окно из n + 1 номеров в решении 1. Для nums = [1, 1, 1] при j = 4 номер i = 0 даёт Subarray длины 4 на местах 0..3, который берёт первое число два раза. Код вернёт 4 вместо 3.
