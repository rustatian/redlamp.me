В первом наборе примера 1 дети вершины 3 имеют номера 4 и 5. У них нет детей, поэтому это листья. Яблоко из 3 может упасть с любого из них. Пока есть ребёнок, яблоко продолжает спуск. Из вершины v по детям можно дойти до любого листа её поддерева. Листья за пределами этого поддерева недостижимы.

Для запроса (3, 4) второе яблоко уже на листе, поэтому возможны пары (4, 4) и (5, 4). Для запроса (3, 3) получим 2 · 2 = 4 пары, ведь выбор второго яблока не зависит от выбора первого. Пары (4, 5) и (5, 4) различны, а пары с одинаковыми листьями тоже допустимы. Пусть leaves[v] хранит число листьев в поддереве v. Тогда ответ на запрос (x, y) равен leaves[x] · leaves[y].

Если искать листья заново для каждого яблока, запрос (1, 1) в первом Tree потребует двух обходов по 5 вершин. В худшем случае такой поиск занимает O(nq) времени. При n = q = 200 000 для запросов из корня получим 2 · n · q = 80 000 000 000 посещений.

Решение 1. Сложение счётчиков в обратном порядке BFS

Для первого Tree обход от корня даёт order = [1, 2, 3, 4, 5]. Когда цикл доходит из вершины 2 до вершины 3, он записывает parent[3] = 2 и добавляет 3 в order. При обработке вершины 3 цикл добавляет в order детей 4 и 5 и пропускает родителя 2. Цикл читает вершины из order по порядку и добавляет детей в конец того же списка. Чтобы найти детей v, достаточно пропустить в списке соседей её родителя parent[v]. При чтении order с конца дети всегда идут раньше родителя.

Начнём с нулей в leaves. Листья 5 и 4 добавят по единице к leaves[3], а вершина 3 передаст сумму 2 своему родителю 2.

Из вершины с детьми к каждому листу её поддерева ведёт единственный путь. Первый шаг пути ведёт к одному из детей, поэтому при сложении счётчиков лист войдёт в сумму ровно один раз. Каждый ребёнок добавляет хотя бы единицу, потому что от него можно спуститься до листа. Значит, ноль в leaves[v] к моменту обработки вершины v указывает на лист. В этом случае ставим leaves[v] = 1, считая саму вершину.

import sys


def solve_case(read):
    n = int(read())
    adj = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        u, v = map(int, read().split())
        adj[u].append(v)
        adj[v].append(u)

    parent = [0] * (n + 1)
    order = [1]
    for v in order:
        for u in adj[v]:
            if u != parent[v]:
                parent[u] = v
                order.append(u)

    leaves = [0] * (n + 1)
    for v in reversed(order):
        if leaves[v] == 0:
            leaves[v] = 1
        if parent[v] != 0:
            leaves[parent[v]] += leaves[v]

    q = int(read())
    answers = []
    for _ in range(q):
        x, y = map(int, read().split())
        answers.append(str(leaves[x] * leaves[y]))
    print("\n".join(answers))


read = sys.stdin.buffer.readline
for _ in range(int(read())):
    solve_case(read)

Время: O(n + q) в худшем случае на набор. BFS проверяет каждое ребро с обоих концов, а обратный проход обрабатывает каждую вершину один раз. На запрос нужно одно умножение. Дополнительная память: O(n + q) в худшем случае на набор. Списки соседей, порядок, родители и счётчики занимают O(n). Пока join собирает строку для печати, список answers занимает ещё O(q) памяти.

В первом наборе примера 1 всего 1 + 4 + 1 + 4 = 10 строк ввода. За строкой с n идут n − 1 строк с рёбрами, затем строка с q и q строк с запросами. Оба решения читают по одной строке и сразу обрабатывают каждый запрос. Списки соседей adj, построенные по рёбрам, входят в дополнительную память. В выводе для набора q строк, по одной на запрос.

Во втором наборе примера 1 ещё 1 + 2 + 1 + 3 = 7 строк ввода. Всего после строки с t каждое решение читает 10 + 7 = 17 строк. Пусть N - общее число вершин во всех наборах, а Q - общее число запросов. Тогда каждое решение обрабатывает весь ввод за O(N + Q) времени в худшем случае.

В том же примере для первого набора n + q = 5 + 4 = 9, а для второго n + q = 3 + 3 = 6. Функция solve_case печатает ответы и при возврате освобождает списки текущего набора. Поэтому для оценки памяти берём 9 из первого набора, где сумма больше. Пик дополнительной памяти в худшем случае равен O(maxi(ni + qi)), где i - номер набора.

Решение 2. Счётчик листьев в DFS

Возьмём другой Tree и введём его рёбра в порядке 1 3, 1 2, 3 5, 3 4. После обработки корня 1 в Stack снизу вверх лежат записи «выход из 1», «вход в 3», «вход в 2». Метод pop() берёт последнюю запись, поэтому DFS посещает лист 2 раньше вершины 3. При входе в лист 2 код сохраняет total = 0 в записи о выходе. Затем он считает сам лист и увеличивает total до 1. Детей у листа нет, поэтому код сразу обрабатывает выход и записывает leaves[2] = 1 − 0 = 1.

При входе в вершину 3 код сохраняет значение total, полученное на листе 2. К моменту выхода из 3 обход посетит ещё и листья 4 и 5, так что счётчик станет равен 3. Разность 3 − 1 = 2 даёт число листьев в поддереве вершины 3.

Код кладёт в Stack запись о выходе из v, а поверх неё добавляет записи о входе в детей. У записи о входе последнее поле равно None, у записи о выходе там хранится число листьев на момент входа. Пока DFS обходит детей и их потомков, запись о выходе остаётся под ними. Поэтому все прибавления к total между входом и выходом из v дают ровно число листьев её поддерева. При выходе читаем сохранённое значение before и записываем разность total − before в leaves[v].

В первом наборе примера 1 у корня 1 всего один сосед, вершина 2, но это его ребёнок. У каждой другой вершины один сосед - её родитель, а остальные - её дети. Код прибавляет единицу, только если у вершины один сосед и сама она не корень.

import sys


def solve_case(read):
    n = int(read())
    adj = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        u, v = map(int, read().split())
        adj[u].append(v)
        adj[v].append(u)

    leaves = [0] * (n + 1)
    total = 0
    stack = [(1, 0, None)]
    while stack:
        v, parent, before = stack.pop()
        if before is not None:
            leaves[v] = total - before
            continue

        stack.append((v, parent, total))
        if v != 1 and len(adj[v]) == 1:
            total += 1
        for u in adj[v]:
            if u != parent:
                stack.append((u, v, None))

    q = int(read())
    answers = []
    for _ in range(q):
        x, y = map(int, read().split())
        answers.append(str(leaves[x] * leaves[y]))
    print("\n".join(answers))


read = sys.stdin.buffer.readline
for _ in range(int(read())):
    solve_case(read)

Время: O(n + q) в худшем случае на набор. DFS просматривает соседей каждой вершины один раз и обрабатывает один выход из неё. Каждый запрос требует одного умножения. Дополнительная память: O(n + q) в худшем случае на набор. Списки соседей, Stack и счётчики занимают O(n). Пока join собирает строку для печати, список answers занимает ещё O(q) памяти.
