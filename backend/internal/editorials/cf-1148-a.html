При a = b = c = 1 из частей b, ab и a получается baba. Если выписывать строку по одной букве, то в примере с a = b = c = 109 потребуется 4 · 109 записей. В каждой из a + b + c частей одна или две буквы. Поэтому число записей не превышает 2 · (a + b + c). Такое построение занимает O(a + b + c) времени в худшем случае. Посчитаем длину по количеству частей.

Куда поставить одиночные буквы

При a = 2, b = 1, c = 2 две готовые части ab дают abab. На стыке после b идёт a, поэтому можно поставить подряд все c таких частей. Они дадут 2 · c букв.

Справа к abab допишем одиночные буквы a, b, a. Получится abababa длины 7. Так при a > b справа помещаются b пар из одиночных букв в порядке a, b и ещё одна a.

В примере 3 5 2 больше одиночных b. Поставим перед abab семь одиночных букв bababab. Последняя из них, b, окажется рядом с первой a готовой части. Длина равна 7 + 4 = 11. При b > a слева можно записать одну b, а за ней a пар из одиночных букв в порядке a, b.

В примере 2 2 1 после готовой части ab запишем одиночные a, b, a, b. Получим длину 6. При равных запасах все одиночные буквы входят в пары.

Почему длиннее не получится

Разобьём строку длины 11 из примера 3 5 2 на пары с левого края. Получим ba ba ba ba ba и последнюю b. При чередовании в каждой такой паре есть обе буквы. Без пары может остаться только последняя буква, поэтому количества a и b различаются не более чем на единицу. Каждая использованная часть ab добавила по одной букве каждого вида. Значит, та же разница получается, если считать только одиночные буквы.

Для 3 5 2 можно взять все три одиночные a и самое большее четыре одиночные b. Пятая дала бы разницу 5 − 3 = 2. Если взять только две одиночные a, то одиночных b поместится не больше трёх. В любой строке число одиночных букв из меньшего запаса не превышает pairs = min(a, b). Значит, одиночных букв другого вида в подходящей строке не больше pairs + 1, а в запасе их max(a, b). Меньшее из этих чисел код сохраняет в other. В каждом из трёх случаев мы нашли место для pairs букв одного вида, other букв другого вида и всех готовых частей. Поэтому наибольшая длина равна 2 · c + pairs + other.

a, b, c = map(int, input().split())
pairs = min(a, b)
other = min(max(a, b), pairs + 1)
length = 2 * c + pairs + other
print(length)

Время: O(1) в худшем случае. В первом примере 1 1 1 программа читает три числа по одной цифре и выводит число 4 из одной цифры. В пятом примере при a = b = c = 109 она читает три числа по десять цифр и выводит число 4000000000 из десяти цифр. Так как 1 ≤ a, b, c ≤ 109, программа читает три числа длиной не больше десяти цифр каждое и переводит их в int. Далее код делает одно и то же число сравнений и арифметических действий с ограниченными числами не больше 4 · 109. Значение length не больше суммарной длины всех частей a + b + 2 · c ≤ 4 · 109, поэтому print(length) выводит не больше десяти цифр. Дополнительная память: O(1) в худшем случае. При чтении split() создаёт временный список из трёх строк длиной до десяти цифр каждая. Затем для расчёта код хранит pairs и other. Входные числа и ответ length считаем отдельно.
