Решение. Greedy

Для пары [-1, 1] произведение равно −1. Если заменить второй множитель на −1, получим (−1) · (−1) = 1. Чтобы получить единицу, каждый целый множитель должен быть равен 1 или −1, а число минусов должно быть чётным.

В третьем примере путь от −5 до −1 стоит 4 монеты, а от 5 до 1 тоже стоит 4 монеты. Для положительного числа x нужно хотя бы x − 1 монет, для отрицательного хотя бы −1 − x. Программа прибавляет эти расстояния к coins и считает отрицательные числа в negative.

Когда мы платим x − 1 за каждое положительное x и −1 − x за каждое отрицательное, все ненулевые числа становятся равны 1 или −1. После этого остаются только числа −1, 0 и 1, и ровно negative из них равны −1.

В паре [-1, 0] заменим ноль на −1 за одну монету и получим два минуса. Каждый ноль требует одной монеты, и за неё можно выбрать любой знак. Если нули есть, сделаем все нули, кроме последнего, единицами. Последнему дадим минус при нечётном negative и плюс при чётном.

Если нулей нет и минусов нечётное число, хотя бы один множитель должен сменить знак. Для пары из первого примера переход от 1 через 0 к −1 стоит ещё 2 монеты. Обратный переход от −1 через 0 к 1 тоже стоит ещё 2 монеты: например, для [-2, -2, -2] получаем 3 + 2 = 5 монет. Для любого множителя переход к единице другого знака стоит на 2 монеты дороже, чем к ближайшей. Поэтому смена знака одного множителя даёт чётное число минусов ровно за 2 лишние монеты, и эта доплата минимальна. Если минусов уже чётное число, достаточно затрат на ближайшие единицы нужного знака.

Оставим первый множитель равным −2 и сравним три значения второго. Если второй множитель равен −1, достаточно прибавить единицу к первому за одну монету. Если второй равен нулю, приведём первый к −1 за 1 монету и заменим ноль на −1 ещё за 1 монету: всего 1 + 1 = 2 монеты. Если второй равен 1, можно получить пару (1, 1) за 3 + 0 = 3 монеты или пару (−1, −1) за 1 + 2 = 3 монеты. Для пары (−2, 1) оба способа получить единицу стоят по 3 монеты.

import sys

read = sys.stdin.readline
n = int(read())
tokens = read().split()
coins = 0
negative = 0
zeros = 0
for token in tokens:
    x = int(token)
    if x < 0:
        coins += -1 - x
        negative += 1
    elif x > 0:
        coins += x - 1
    else:
        coins += 1
        zeros += 1

if zeros == 0 and negative % 2 == 1:
    coins += 2
print(coins)

Время: O(n) в худшем случае для всего ввода: программа один раз обрабатывает каждое из n чисел единственного набора. Дополнительная память: O(n) в худшем случае для всего набора. При вызове split() в памяти находятся входная строка и список из n частей. Программа переводит в число по одной части и выводит один ответ. При данных ограничениях счётчики и строка для печати занимают O(1) памяти.
