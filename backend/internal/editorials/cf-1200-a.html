Решение 1. Array с отметками занятости

В первом примере запись начинается с LLRL. Гости по очереди занимают комнаты 0, 1, 9 и 2. Выпишем слева направо по единице для каждой занятой комнаты и по нулю для каждой свободной. Получится 1110000001. В программе за комнату i отвечает ячейка rooms[i]. В начале все десять ячеек содержат символ "0".

Следующее событие 1 освобождает комнату 1 между занятыми комнатами 0 и 2. Цифра в записи событий указывает номер комнаты, поэтому int(event) сразу даёт индекс для записи нуля. После записи нуля в rooms[1] команда continue переводит цикл к следующему событию.

Теперь приходит гость справа (R). Комната 9 занята, а комната 8 свободна, поэтому гость займёт комнату 8. Следующий гость приходит слева (L) и после занятой комнаты 0 находит свободную комнату 1.

Цикл for room in order проверяет комнаты по порядку от выбранного входа. Для правого входа range(9, -1, -1) доходит до комнаты 0 включительно. Когда цикл доходит до первого нуля, все комнаты ближе к этому входу уже проверены и заняты. Свободное место при заселении есть по условию. Программа ставит единицу и выходит из поиска по break, так что меняется ровно одна ячейка. Последняя цифра 1 в примере снова освобождает комнату 1, и "".join(rooms) даёт ответ 1010000011.

import sys

n = int(sys.stdin.readline())
rooms = ["0"] * 10

for _ in range(n):
    event = sys.stdin.read(1)
    if event.isdigit():
        rooms[int(event)] = "0"
        continue

    if event == "L":
        order = range(10)
    else:
        order = range(9, -1, -1)
    for room in order:
        if rooms[room] == "0":
            rooms[room] = "1"
            break

print("".join(rooms))

При заселении цикл проверяет не более 10 комнат, а при выезде сразу меняет одну ячейку. Время: O(n) в худшем случае для n событий. Программа читает по одному символу события и хранит 10 отметок. Дополнительная память: O(1) в худшем случае.

Решение 2. Список свободных комнат

Перед вторым R в первом примере список свободных комнат имеет вид free = [1, 3, 4, 5, 6, 7, 8]. Гость занимает комнату 8, и free.pop() удаляет её номер с конца списка.

Возьмём события LLL02L. После LLL в списке свободных комнат free остались номера от 3 до 9. При выезде из комнаты 0 её номер надо вернуть в начало списка, а при выезде из комнаты 2 число 2 должно встать между 0 и 3. Если дописывать номера в конец, то на последнее L программа выберет комнату 3, хотя свободна комната 0.

Функция insort(free, int(event)) вставляет освободившийся номер так, что числа по-прежнему идут по возрастанию. Тогда ближайшая свободная комната слева стоит первой, а ближайшая справа стоит последней. Для L вызов free.pop(0) удаляет первый номер, а для R вызов free.pop() удаляет последний.

После последнего L в списке остаются номера от 2 до 9. Чтобы получить ответ 1100000000, заполняем rooms единицами и записываем ноль по каждому индексу из free.

import sys
from bisect import insort

n = int(sys.stdin.readline())
free = list(range(10))

for _ in range(n):
    event = sys.stdin.read(1)
    if event == "L":
        free.pop(0)
    elif event == "R":
        free.pop()
    else:
        insort(free, int(event))

rooms = ["1"] * 10
for room in free:
    rooms[room] = "0"
print("".join(rooms))

В примере LLL02L перед вставкой числа 2 список free равен [0, 3, 4, 5, 6, 7, 8, 9]. Сначала функция insort берёт средний элемент 6 и проверяет 2 < 6. Так как 2 меньше 6, а числа в free идут по возрастанию, 6 и все числа правее (7, 8 и 9) больше 2. Поэтому 6 и правую часть убираем: из 8 чисел остаются 4 числа [0, 3, 4, 5]. Дальше 2 < 4 оставляет [0, 3], а 2 < 3 оставляет [0]. Последнее сравнение с 0 показывает, что 2 больше 0, поэтому место для 2 правее. Когда мы убираем 0 из области поиска, чисел для сравнения не остаётся. Так на этом примере область поиска сокращалась через 8, 4, 2, 1 и 0 чисел за четыре сравнения.

Перед вставкой в free не больше 9 номеров, потому что номера освободившейся комнаты там ещё нет. Поэтому новый номер не равен среднему элементу. Если он меньше среднего, то сам средний элемент и все числа правее больше него, поэтому их убираем. Если он больше среднего, то средний элемент и все числа левее меньше него, и их тоже убираем. В списке из 9 чисел слева и справа от среднего элемента (пятого по счёту) стоит по 4 числа, поэтому после первого сравнения остаётся не больше 4 чисел. Когда в области поиска от 1 до 4 чисел, средний элемент делит остальные на части не длиннее 2, поэтому одно сравнение оставляет не больше 2 чисел. Из не больше чем 2 чисел следующее сравнение оставляет не больше 1 числа, а ещё одно оставляет 0 и завершает поиск, так что всего нужно не больше четырёх сравнений.

Перед вызовом free.pop(0) в free не больше 10 номеров. Этот вызов удаляет элемент с индексом 0 и сдвигает влево не больше 9 остальных чисел. Когда свободны все 10 комнат, free.pop(0) убирает 0 и сдвигает влево 9 чисел от 1 до 9. При выезде insort вставляет освободившийся номер в список из не больше чем 9 чисел и сдвигает вправо не больше 9 чисел. Если занята только комната 0, вставка её номера в начало free сдвинет 9 чисел.

Время: O(n) в худшем случае для n событий. При выводе программа хранит список free и 10 ячеек rooms. Дополнительная память: O(1) в худшем случае.
