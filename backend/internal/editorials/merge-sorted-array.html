Числа обоих входов должны встать в nums1 по неубыванию. Решение 1 обходится без второго list.

Решение 1. Two Pointers с конца

Возьмите пример 1: nums1 = [1, 2, 3, 0, 0, 0], m = 3, nums2 = [2, 5, 6], n = 3. Merge слева направо, как в уроке, кладёт 1 и 2 из nums1 в ячейки 0 и 1. Третье число ответа это двойка из nums2, и её место в ячейке 2. Но там стоит число 3, которое Merge ещё не прочитал. Запись двойки затирает тройку, и такой Merge даёт [1, 2, 2, 2, 5, 6] без числа 3.

Свободные ячейки лежат справа. Поэтому заполняйте nums1 с конца, начиная с самого большого числа. В примере 1 последнее значимое число nums1 это 3, а последнее число nums2 это 6. Оба входа отсортированы, и 6 > 3, поэтому 6 не меньше всех остальных чисел, и его место в последней ячейке 5.

Три индекса идут влево. i показывает последнее непрочитанное число nums1, а j последнее непрочитанное число nums2. write показывает самую правую свободную ячейку. Сначала i = m − 1, j = n − 1, write = m + n − 1, в примере 1 это 2, 2 и 5. nums1[i] и nums2[j] самые большие из непрочитанных чисел своих входов. Большее из них не меньше всех непрочитанных чисел, и код ставит его в ячейку write. Потом его индекс и write уменьшаются на 1.

Шаги 1 и 2 ставят 6 и 5 из nums2 в ячейки 5 и 4. На шаге 3 тройка переходит из ячейки 2 в ячейку 3, потому что 3 > 2. На шаге 4 числа равны: 2 = 2. При равенстве код берёт двойку из nums2 и ставит её в ячейку 2. Теперь j = −1, и цикл останавливается после 4 шагов. Скобка на рисунке отмечает ячейки, которые цикл уже записал.

В примере 1 перед шагом 3 i = 2, j = 0, write = 3, и 3 = 2 + 0 + 1. Запись идёт в ячейку 3, правее непрочитанных ячеек от 0 до 2. Это верно на каждом шаге. Сначала write = m + n − 1 = i + j + 1. Каждый шаг уменьшает на 1 write и ещё один из индексов i и j, поэтому всегда write = i + j + 1. Пока j ≥ 0, из этого равенства write ≥ i + 1: запись не затирает непрочитанные числа nums1.

После шага 4 i = 1 и write = 1, а числа 1 и 2 в ячейках 0 и 1 не двигались. В общем случае при j = −1 все числа nums2 уже записаны, и write = i + j + 1 = i. Цикл уже записал все ячейки правее write, от i + 1 до m + n − 1, и свободных ячеек нет. Числа в ячейках от 0 до i отсортированы. Каждая запись брала самое большое из оставшихся чисел, поэтому числа в ячейках от 0 до i не больше записанных. Значит, они уже стоят на своих местах.

В примере 3 m = 0, поэтому сразу i = −1. Проверка i >= 0 ложна, и код идёт в ветку else: 1 из nums2 встаёт в ячейку 0. Если nums1 закончился раньше nums2, то i = −1 и write = i + j + 1 = j. Тогда каждое nums2[j] встаёт в ячейку j.

Время: каждый шаг пишет в новую ячейку и уменьшает write на 1. Ячеек m + n, поэтому шагов не больше m + n: O(m + n). В примере 1 шагов 4. В примере 2 n = 0, и цикл не делает ни одного шага. Дополнительная память: i, j и write, O(1). Ответ лежит в самом nums1.

class Solution:
    def merge(self, nums1: list[int], m: int, nums2: list[int], n: int) -> None:
        i, j, write = m - 1, n - 1, m + n - 1
        while j >= 0:  # при j = -1 ячейки от 0 до i уже на своих местах
            if i >= 0 and nums1[i] > nums2[j]:
                nums1[write] = nums1[i]
                i -= 1
            else:
                nums1[write] = nums2[j]
                j -= 1
            write -= 1

Другие способы

Можно сначала скопировать первые m чисел: first = nums1[:m]. Тогда Merge слева направо читает first и nums2 и пишет в nums1. Запись уже ничего не затирает: все числа nums1 лежат в копии. Время тоже O(m + n), но копия занимает m ячеек: O(m) дополнительной памяти. В примере 1 это 3 ячейки.

Строки nums1[m:] = nums2 и nums1.sort() тоже дают верный ответ. Это Sorting всех m + n чисел с общей оценкой O((m + n) log(m + n)) времени. Дополнительный вопрос просит O(m + n): это время Merge с конца.

Типичные ошибки

  • Строка nums1 = sorted(nums1[:m] + nums2). После этой строки имя nums1 внутри метода указывает на новый list, а list, который передал тест, не меняется. В примере 1 после вызова nums1 остаётся [1, 2, 3, 0, 0, 0]. Запись nums1[:] = sorted(nums1[:m] + nums2) меняет сам list.
  • Нет проверки i >= 0. Для nums1 = [2, 0], m = 1, nums2 = [1], n = 1 шаг 1 ставит 2 в ячейку 1, и i = −1. На шаге 2 выражение nums1[-1] не даёт ошибку: Python читает последнюю ячейку, где стоит 2. Число 2 больше 1, и код пишет 2 в ячейку 0. На шаге 3 nums1[-2] читает ячейку 0, и код снова пишет 2 в ячейку 1. Число 1 так и не попадает в nums1. На шаге 4 nums1[-3] нет в list из 2 ячеек, и код падает с IndexError.
  • Условие while i >= 0 and j >= 0. Цикл останавливается, когда закончился nums1, и остаток nums2 не попадает в ответ. В примере 3 сразу i = −1, цикл не делает ни одного шага, и nums1 остаётся [0].
