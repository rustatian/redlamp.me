Ответ зависит только от букв и цифр String s. Их сравнивают парами с двух концов, а заглавная буква равна своей строчной.

Решение 1. Two Pointers

Возьмите пример 2: s = "race a car", n = 10. Указатель l стоит на месте 0, указатель r на месте 9. Символы s[0] = "r" и s[9] = "r" равны, и оба указателя идут внутрь. Так же совпадают пары "a" на местах 1 и 8 и "c" на местах 2 и 7.

Теперь l = 3 и r = 6. Символ s[6] это пробел. Его нет в очищенной String "raceacar", поэтому r -= 1 без сравнения. На местах 3 и 5 стоят "e" и "a". Они разные, и ответ False.

Одной разной пары достаточно. Левее места 3 стоят 3 буквы "rac", правее места 5 тоже 3 буквы "car". Значит, "e" это буква номер 4 от начала String "raceacar", а "a" это буква номер 4 от конца. В Palindrome эти буквы равны.

Так на каждом шаге: левее l и правее r одинаковое число букв и цифр. Совпала пара: оба символа уходят из окна, и каждое число растёт на 1. Пропуск убирает символ, который не буква и не цифра, и числа не меняются. Поэтому, когда s[l] и s[r] буквы или цифры, у них один номер: у s[l] от начала очищенной String, у s[r] от конца.

Метод lower() заменяет заглавную букву на строчную. В примере 1 первая пара это s[0] = "A" и s[29] = "a". После lower() обе дают "a", и пара совпадает. Метод isalnum() даёт True для буквы или цифры. Среди 95 печатаемых символов ASCII таких 62: 26 заглавных букв, 26 строчных и 10 цифр.

Цикл заканчивается, когда l ≥ r: все пары проверены. В примере 1 после 19 шагов l = r = 17. Там стоит "c", середина String "amanaplanacanalpanama", и у неё нет пары. Ответ True. В примере 3 n = 1, l = r = 0, и цикл не делает ни одного шага.

Правило. s[l] не буква и не цифра: l += 1. s[r] не буква и не цифра: r -= 1. Иначе сравните s[l].lower() и s[r].lower(). Разные символы дают False, равные дают l += 1 и r -= 1.

На рисунке пробел показан знаком ␣.

class Solution:
    def isPalindrome(self, s: str) -> bool:
        l, r = 0, len(s) - 1
        while l < r:
            if not s[l].isalnum():
                l += 1  # этого символа нет в очищенной String
            elif not s[r].isalnum():
                r -= 1
            elif s[l].lower() != s[r].lower():
                return False
            else:
                l += 1  # пара совпала, идём внутрь
                r -= 1
        return True

Время: n - длина s. Сначала r - l равно n − 1. Пропуск уменьшает эту разность на 1, совпавшая пара на 2. Цикл идёт, только пока разность не меньше 1, поэтому шагов не больше n − 1: O(n) в худшем случае. В примере 1 n = 30, а шагов 19: 10 пар и 9 пропусков. Если в s нет букв и цифр, l идёт от 0 до n − 1, и шагов ровно n − 1. Дополнительная память: l и r, O(1). Ответ - одно значение True или False.

Решение 2. Очищенная копия и разворот

Можно построить очищенную String целиком. Array t получает каждую букву и цифру s по порядку, и заглавная буква попадает в t строчной. Для примера 2 в t 8 символов: r a c e a c a r. Срез t[::-1] даёт те же символы в обратном порядке: r a c a e c a r. Palindrome означает t == t[::-1]. Здесь t и t[::-1] различаются на месте 3: "e" и "a". Это та же пара, что нашло решение 1 на местах 3 и 5 String s.

class Solution:
    def isPalindrome(self, s: str) -> bool:
        t = [c.lower() for c in s if c.isalnum()]
        return t == t[::-1]

Время: построение t проходит n символов s. Срез и сравнение проходят не больше k символов, где k - число букв и цифр в s, k ≤ n. Всего O(n) в худшем случае. Дополнительная память: t и копия t[::-1] хранят по k символов, O(n). В примере 2 это 8 + 8 = 16 символов. При n = 2 · 105 и s только из букв это 4 · 105 символов.

Типичные ошибки

  • Сравнение без lower(). В примере 1 уже первая пара окажется разной, и ответ будет False вместо True.
  • isalpha() вместо isalnum(). Метод isalpha() даёт False для цифры. Для s = "0P" останется одна буква, и ответ будет True. Правильный ответ False: "0" и "p" разные символы.
  • Пропуск во внутреннем цикле без проверки l < r. Код while not s[l].isalnum(): l += 1 для s = ".," проходит места 0 и 1 и читает s[2]. Такого места нет, и Python даёт IndexError. В решении 1 каждый шаг делает один ход, и перед каждым шагом цикл проверяет l < r.
