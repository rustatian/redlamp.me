Нужна пара равных чисел, номера которых отличаются не больше чем на k.

Пусть n - длина nums. Brute Force берёт каждый номер i и сравнивает nums[i] с не более чем k следующими числами. Сравнений не больше n · k: O(nk) в худшем случае. В примере 3 (n = 6, k = 2) на расстоянии 1 стоят 6 − 1 = 5 пар, на расстоянии 2 стоят 6 − 2 = 4 пары: 5 + 4 = 9 сравнений. В общем случае на расстоянии d стоят n − d пар. При n = k = 105 подходят все пары, и сравнений (n − 1) + (n − 2) + ... + 1 = n(n − 1) / 2. Это 105 · (105 − 1) / 2 = 4 999 950 000: слишком долго.

Решение 1. Sliding Window и set

Возьмите пример 1: nums = [1, 2, 3, 1], k = 3. Для числа x = nums[i] важны только числа на расстоянии от 1 до k слева: nums[i − k..i − 1]. Код хранит их в set с именем window. Проверка x in window в среднем стоит O(1).

При i = 0, 1, 2 числа 1, 2, 3 не лежат в window, и код добавляет их: window = {1, 2, 3}. При i = 3 число x = 1 лежит в window. Это nums[0], и расстояние 3 − 0 = 3 не больше k = 3. Ответ True.

Теперь пример 3: nums = [1, 2, 3, 1, 2, 3], k = 2. При i = 2 после добавления в window три числа 1, 2, 3, а для шага i = 3 нужны только два последних: 2 и 3. Число nums[0] = 1 стоит от номера 3 на расстоянии 3 − 0 = 3, это больше k = 2. Поэтому код удаляет nums[0] ещё на шаге i = 2, и перед шагом i = 3 в window лежат 2 и 3.

Правило. Перед шагом i в window лежат числа nums[i − k..i − 1]. Если x = nums[i] есть в window, ответ True. Иначе добавьте x. Если в window стало больше k чисел, удалите nums[i - k].

В примере 3 равное число не нашлось ни на одном шаге: равные числа стоят на расстоянии 3, а k = 2. Ответ False.

Правило верно на каждом шаге. Пока код не вернул True, числа nums[i − k..i − 1] разные: равную пару нашёл бы шаг с большим из двух номеров. Значит, len(window) равно числу этих номеров. Число x тоже не равно ни одному из чисел nums[i − k..i − 1], иначе код вернул бы True. Поэтому число nums[i − k] стоит среди nums[i − k..i] один раз, и window.remove(nums[i - k]) убирает только число с номера i − k. Пока i < k, код ничего не удаляет: после шага в window не больше k чисел. Поэтому перед шагом i = k в window лежат k чисел nums[0..k − 1]. Дальше каждый шаг добавляет x, и в window становится k + 1 число. Код удаляет nums[i - k], и остаются k чисел nums[i − k + 1..i]: это числа, которые нужны на шаге i + 1. В примере 3 при i = 3 в window лежат числа 2 и 3, то есть nums[1..2]. После добавления nums[3] = 1 их три, и код удаляет nums[1] = 2. Остаётся nums[2..3]: это числа, которые нужны на шаге i = 4.

Поэтому x in window верно ровно тогда, когда слева от i на расстоянии от 1 до k стоит равное число. Подходящую пару номеров j < i код находит на шаге i. Если ни на одном шаге равного числа нет, подходящей пары нет, и ответ False.

При k = 0 подходящих пар нет: у двух разных номеров расстояние не меньше 1. Код даёт тот же ответ. Для nums = [1, 1] на шаге i = 0 число 1 попадает в window, len(window) = 1 больше 0, и код сразу удаляет nums[0]. На шаге i = 1 window пуст, и ответ False.

class Solution:
    def containsNearbyDuplicate(self, nums: list[int], k: int) -> bool:
        window = set()  # числа nums[i - k..i - 1], не больше k чисел
        for i, x in enumerate(nums):
            if x in window:
                return True
            window.add(x)
            if len(window) > k:
                window.remove(nums[i - k])  # nums[i - k] будет дальше k от номера i + 1
        return False

Время: ожидаемое для Hash Table. Код делает не больше n проверок, n добавлений и n удалений, каждое в среднем за O(1): O(n). В примере 3 это 6 проверок, 6 добавлений и 4 удаления. Дополнительная память: window хранит не больше k + 1 числа и не больше n чисел: O(min(n, k + 1)) в худшем случае. Ответ - одно значение.

Решение 2. Hash Table с последним местом числа

Решение 1 помнит k последних чисел. Другой способ: помнить для каждого числа номер его последнего места. Это dict с именем last: ключ - число, значение - номер места.

Возьмите пример 2: nums = [1, 0, 1, 1], k = 1. При i = 0 числа 1 нет в last, и last = {1: 0}. При i = 1 числа 0 нет, и last = {1: 0, 0: 1}. При i = 2 число 1 есть, его последнее место 0, расстояние 2 − 0 = 2 больше k = 1. Код всё равно записывает last[1] = 2. При i = 3 число 1 есть, его последнее место 2, расстояние 3 − 2 = 1 не больше k. Ответ True.

Последнее место числа x - это место ближайшего равного числа слева. Если даже оно дальше k, остальные равные числа левее и ещё дальше. При i = 3 в примере 2 равные числа стоят на местах 0 и 2 с расстояниями 3 и 1: ближайшее решает.

class Solution:
    def containsNearbyDuplicate(self, nums: list[int], k: int) -> bool:
        last = {}  # last[x] - номер последнего места числа x
        for i, x in enumerate(nums):
            if x in last and i - last[x] <= k:
                return True
            last[x] = i
        return False

Время: ожидаемое для Hash Table. Код делает не больше n проверок и n записей, каждую в среднем за O(1): O(n). Дополнительная память: last хранит все разные числа nums, не больше n: O(n) в худшем случае. Это не меньше, чем в решении 1. Пример: k = 1 и 105 разных чисел. Решение 1 хранит не больше 2 чисел, а решение 2 хранит 105.

Типичные ошибки

  • Окно из k + 1 числа: if len(window) > k + 1. Для nums = [1, 2, 1] и k = 1 равные числа стоят на расстоянии 2, ответ False. Такой код вернёт True.
  • Обычный set всех чисел без удаления. Для примера 3 код вернёт True при i = 3, а ответ False: число 1 стоит на расстоянии 3 > 2.
  • В решении 2 записывать место числа только при первой встрече. В примере 2 код сравнит i = 3 с местом 0: расстояние 3 больше 1, и код вернёт False вместо True.
