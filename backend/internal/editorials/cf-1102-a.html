Решение 1. Остаток от деления на 4

При n = 6 возьмём последние четыре числа и положим крайние, 3 и 6, в A. Два средних числа, 4 и 5, положим в B. Обе суммы равны 9. Если отдать 1 множеству A, а 2 множеству B, получим суммы 10 и 11. Разность по модулю равна 1. Суммы не могут быть равны, потому что вместе они дают нечётное число 21.

В любой четвёрке подряд идущих чисел крайние дают ту же сумму, что и два средних. Если наибольшее число равно k, то k + (k − 3) = (k − 1) + (k − 2). Пока остаётся хотя бы четыре числа, можно брать такую четвёрку с конца. Обе суммы увеличатся на одну величину, поэтому их разность сохранится.

Например, при n = 11 после первой четвёрки остаётся 11 − 4 = 7 чисел, а после второй остаётся 7 − 4 = 3. Вычитание 4 не меняет остаток от деления на 4. Когда остаётся меньше четырёх чисел, их количество равно остатку remainder = n % 4. Для n от 4 до 7 в таблице показано, куда можно положить оставшиеся числа.

При остатке 0 остаются две равные суммы. При остатке 3 получаем равные суммы, так как 1 + 2 = 3. При остатках 1 и 2 оставшиеся числа дают нечётную сумму 1 или 3 соответственно. Полные четвёрки прибавляют к общей сумме чётное число, поэтому разность 1 в этих двух случаях минимальна.

При n = 2 · 109 цикл по четвёркам сделал бы 500 000 000 шагов. Такой цикл требует O(n) времени в худшем случае. Коду достаточно проверить остаток.

n = int(input())
remainder = n % 4
if remainder == 1 or remainder == 2:
    print(1)
else:
    print(0)

Время: O(1) в худшем случае. Код вычисляет остаток и делает не больше двух сравнений. Дополнительная память: O(1) в худшем случае. Кроме входного n, хранится только remainder.

Решение 2. Чётность общей суммы

При n = 5 сложим ряд 1, 2, 3, 4, 5 с тем же рядом в обратном порядке. В каждой позиции получим 6, от 1 + 5 до 5 + 1. Мы посчитали каждое число дважды, поэтому удвоенная сумма ряда равна 5 · 6 = 30. Число 6 чётно, поэтому произведение 5 · 6 делится на 2 без остатка. В Python целочисленное деление 5 * 6 // 2 даёт точное целое число 15. Для любого n каждый из n столбцов даёт n + 1. Одно из двух соседних чисел n и n + 1 чётно, поэтому n · (n + 1) тоже делится на 2 без остатка. Поэтому запись total = n * (n + 1) // 2 вычисляет точную целую сумму.

Для A получаем 15 // 2 = 7, потому что операция // округляет частное вниз. Для B остаётся 15 − 7 = 8. Чтобы набрать 7, сначала берём 5. Не хватает 2, и это число ещё свободно. Берём его в A, а числа 1, 3, 4 в B дают сумму 8.

Таким выбором можно набрать любую целую сумму от 0 до total. Пока цель не меньше самого большого доступного числа, берём это число и вычитаем его из цели. Цель и сумма доступных чисел уменьшаются на одну величину, так что доступной суммы по-прежнему хватает. Если осталось набрать меньше следующего числа k, то все числа от 1 до k − 1 ещё свободны. Берём недостающее число, если оно положительно. При нулевой цели больше ничего брать не нужно.

В A возьмём сумму total // 2, а остальные числа отдадим B. При чётной общей сумме обе части равны, а при нечётной в B окажется на единицу больше. Как и в решении 1, нечётный итог исключает разность 0, ведь сумма двух равных целых чисел чётна. Значит, минимальную разность даёт остаток total % 2.

n = int(input())
total = n * (n + 1) // 2
print(total % 2)

Время: O(1) в худшем случае. Код вычисляет сумму по формуле и берёт остаток от деления на 2. Дополнительная память: O(1) в худшем случае. Кроме n, код сохраняет одно число total.

Типичные ошибки

  • Использовать / вместо // при вычислении total. При n = 5 выражение 5 * 6 / 2 даёт 15.0 типа float, поэтому код печатает 1.0 вместо 1. Тип float хранит все целые числа точно только до 253 = 9007199254740992. Даже с int(n * (n + 1) / 2) программа пройдёт примеры 3, 5 и 6, но потеряет чётность на больших входах. При n = 1999999998 точная сумма равна 1999999997000000001. Деление через / округляет это нечётное число до чётного значения 1999999997000000000, поэтому программа выводит 0.0 вместо 1, а с int выводит 0 вместо 1.
