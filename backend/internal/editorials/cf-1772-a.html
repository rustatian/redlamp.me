Решение 1. Цифры по индексам

Пусть s = "3+7". Индексы в Python начинаются с нуля, поэтому s[0] даёт "3", а s[2] даёт "7". Индексы одинаковы для всех выражений, потому что по обе стороны плюса стоит ровно по одной цифре без пробелов.

В Python "3" + "7" даёт строку "37". Чтобы получить сумму, переведём каждую цифру в число.

Вызов ord("3") даёт 51, а ord("0") даёт 48. Это коды символов в таблице ASCII. Разность кодов 51 − 48 = 3 даёт первое слагаемое. В ASCII коды цифр от "0" до "9" идут подряд, поэтому разность с кодом нуля равна значению цифры.

В переменной zero хранится код символа "0". Для строки 3+7 программа получит a = 3 и b = 7, а затем выведет их сумму 10.

t = int(input())
zero = ord("0")
for _ in range(t):
    s = input()
    a = ord(s[0]) - zero
    b = ord(s[2]) - zero
    print(a + b)

На строку из трёх символов приходятся два вычитания и одно сложение. Время: O(1) на строку, O(t) на все t строк в худшем случае. Дополнительная память: O(1) в худшем случае и для одной строки, и для всей программы. Программа сразу печатает сумму и не хранит предыдущие ответы.

Решение 2. Разделение по знаку плюса

Вызов "8+9".split("+") даёт список ["8", "9"]. В каждой строке ровно один плюс, поэтому left получает весь текст слева от него, а right получает весь текст справа. Вызов int("8") даёт число 8, а int("9") даёт 9. Их сумма равна 17.

Если оставить скобки пустыми, "8+9".split() вернёт список ["8+9"], поскольку в строке нет пробелов. Одного элемента не хватит для присваивания двум переменным.

t = int(input())
for _ in range(t):
    left, right = input().split("+")
    print(int(left) + int(right))

Для каждой строки split просматривает три символа, а int обрабатывает две цифры по отдельности. Время: O(1) на выражение, O(t) на весь ввод в худшем случае. Дополнительная память: O(1) в худшем случае и для одного выражения, и для всей программы. Временный список содержит две строки по одному символу, а ответ программа выводит сразу.
