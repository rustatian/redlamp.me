Решение 1. Sorting

В тройке 5 2 6 на втором месте стоит 2. Команда numbers.sort() располагает числа в том же списке по возрастанию. В списке [2, 5, 6] слева от 5 стоит меньшее число, а справа большее. Здесь numbers[0] даёт 2, а numbers[1] даёт 5.

После упорядочивания тройки разных чисел минимум стоит первым, а максимум последним. Между ними остаётся искомое число. В Python индексы начинаются с 0, поэтому второе число берём из numbers[1].

Для тройки 14 3 4 получаем 3 < 4 < 14. Ответ равен 4. Среднее арифметическое (14 + 3 + 4) / 3 = 7 не подходит, потому что в тройке числа 7 нет.

import sys

readline = sys.stdin.readline
t = int(readline())
answers = []
for _ in range(t):
    numbers = list(map(int, readline().split()))
    numbers.sort()
    answers.append(str(numbers[1]))
print("\n".join(answers))

Время: O(1) на выбор среднего числа из тройки и O(t) на всю программу в худшем случае. Список numbers всегда содержит только три числа. Дополнительная память: O(1) для обработки тройки и O(t) для всей программы в худшем случае. В конце цикла в списке answers лежат t строк. Каждое число тройки лежит в пределах от 1 до 20, поэтому в каждой строке одна или две цифры. Пока join собирает из них строку для печати, список тоже остаётся в памяти.

Решение 2. Сравнения

Пусть a = 5, b = 2 и c = 6. Неравенство 2 < 5 < 6 показывает, что ответ равен a. Если поменять b и c местами, число 5 по-прежнему будет средним. Поэтому условие для a допускает как b < a < c, так и c < a < b.

В тройке 20 2 1 число a = 20 больше двух остальных. Для b выполняется условие c < b < a, так как 1 < 2 < 20. Ответ равен b = 2. Проверка для b учитывает и обратный порядок a < b < c.

В тройке 14 3 4 число a = 14 самое большое, а b = 3 самое маленькое. Обе проверки дают False, и программа выбирает c = 4. Среди трёх разных чисел ровно одно лежит между остальными. Если ни a, ни b не подошли, остаётся c.

import sys

readline = sys.stdin.readline
t = int(readline())
answers = []
for _ in range(t):
    a, b, c = map(int, readline().split())
    if b < a < c or c < a < b:
        middle = a
    elif a < b < c or c < b < a:
        middle = b
    else:
        middle = c
    answers.append(str(middle))
print("\n".join(answers))

Время: O(1) на выбор среднего числа из тройки и O(t) на всю программу в худшем случае. Для каждой тройки код проверяет не более двух условий. Дополнительная память: O(1) для обработки тройки и O(t) для всей программы в худшем случае. Число переменных для сравнений постоянно, а для печати программа снова хранит список answers и общую строку.
