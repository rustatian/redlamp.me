Запрос запускает несколько операций подряд, а операция меняет несколько элементов подряд. Нужен Array после всех запросов.

Прямое применение

Первый пример: a = [1, 2, 3], операции (1, 2, 1), (1, 3, 2), (2, 3, 4) и запросы [1, 2], [1, 3], [2, 3]. Операция (l, r, d) прибавляет d к элементам с номерами от l до r. Операция 1 меняет 2 элемента, операция 2 меняет 3 элемента, операция 3 меняет 2 элемента. Запрос [1, 2] запускает операции 1 и 2: 2 + 3 = 5 прибавлений. Запрос [1, 3] запускает все три операции: 2 + 3 + 2 = 7 прибавлений. Запрос [2, 3] запускает операции 2 и 3: 3 + 2 = 5 прибавлений. Всего 5 + 7 + 5 = 17 прибавлений.

В худшем случае каждый запрос запускает все m операций, а каждая операция меняет все n элементов. Это k · m · n прибавлений, время O(k · m · n). При n = m = k = 105 получается 105 · 105 · 105 = 1015 прибавлений: слишком долго.

Решение 1. Difference Array два раза

Посмотрим на элемент 2 примера. Запрос [1, 2] прибавляет к нему 1 и 2. Запрос [1, 3] прибавляет 1, 2 и 4. Запрос [2, 3] прибавляет 2 и 4. Сумма всех прибавок 1 + 2 + 1 + 2 + 4 + 2 + 4 = 16. Сумма не зависит от порядка слагаемых, поэтому сгруппируем их по операциям. Операцию 1 запускают 2 запроса: 1 · 2 = 2. Операцию 2 запускают 3 запроса: 2 · 3 = 6. Операцию 3 запускают 2 запроса: 4 · 2 = 8. Снова 2 + 6 + 8 = 16, и элемент 2 становится равен 2 + 16 = 18.

Порядок запросов на ответ не влияет. Для каждой операции нужно одно число cnt: сколько запросов её запускают. В примере cnt = [2, 3, 2], по одному числу на операцию. Операция с числом cnt прибавляет d на [l, r] cnt раз. Одно прибавление d · cnt на [l, r] даёт тот же результат.

Теперь в задаче два вида прибавлений на отрезке. Запрос [x, y] прибавляет 1 к cnt операций с x по y. Операция (l, r, d) прибавляет d · cnt к элементам с l по r. В обоих случаях значения нужны только после всех прибавлений. Для этого подходит Difference Array: две отметки на каждый отрезок и одна Prefix Sum в конце.

Первый Difference Array: числа cnt. Список cd длины m + 1 = 4 хранит отметки запросов. Номера в условии идут с 1, а места списка с 0. Операции 1 и 2 запроса [1, 2] стоят на местах 0 и 1. Запрос ставит +1 в cd[0] и −1 на следующее место, в cd[2]. Сумма отметок слева направо равна 1 для операции 1, 1 для операции 2 и 1 − 1 = 0 для операции 3: запрос посчитан только для своих операций. Операция x стоит на месте x − 1, а следующее место после операции y это (y − 1) + 1 = y. Поэтому запрос [x, y] делает cd[x - 1] += 1 и cd[y] -= 1. После трёх запросов cd = [2, 1, -1, -2]. Prefix Sum по cd: 2, 2 + 1 = 3, 3 − 1 = 2. Это cnt = [2, 3, 2]. Число cd[3] = −2 в cnt не входит: оно закрывает два запроса, которые кончаются на операции 3.

Второй Difference Array: прибавки к элементам. Список ad длины n + 1 = 4 хранит отметки прибавок. Операция (l, r, d) делает ad[l - 1] += d * cnt и ad[r] -= d * cnt. Операция 1 ставит 1 · 2 = 2 в ad[0] и −2 в ad[2]. Операция 2 ставит 2 · 3 = 6 в ad[0] и −6 в ad[3]. Операция 3 ставит 4 · 2 = 8 в ad[1] и −8 в ad[3]. Итог ad = [8, 8, -2, -14]. Prefix Sum по ad: 8, 8 + 8 = 16, 16 − 2 = 14. Это прибавки к трём элементам, и ответ [1 + 8, 2 + 16, 3 + 14] = [9, 18, 17].

Операции во входе идут раньше запросов, а числа cnt известны только после всех запросов. Поэтому программа хранит операции в списке ops. В коде cnt и s это числа, а не списки. Цикл идёт слева направо, и после строки cnt += cd[i] в cnt лежит сумма cd[0] + cd[1] + ... + cd[i]. Так же s копит сумму чисел ad.

import sys

input = sys.stdin.readline
n, m, k = map(int, input().split())
a = list(map(int, input().split()))
ops = [tuple(map(int, input().split())) for _ in range(m)]

# запрос [x, y] прибавляет 1 к cnt операций с x по y
cd = [0] * (m + 1)
for _ in range(k):
    x, y = map(int, input().split())
    cd[x - 1] += 1
    cd[y] -= 1

ad = [0] * (n + 1)
cnt = 0
for i in range(m):
    # после сложения cnt это число запросов с операцией номер i + 1
    cnt += cd[i]
    l, r, d = ops[i]
    ad[l - 1] += d * cnt
    ad[r] -= d * cnt

s = 0
for i in range(n):
    # после сложения s это вся прибавка к элементу номер i + 1
    s += ad[i]
    a[i] += s
print(" ".join(map(str, a)))

Время: O(n + m + k) для любого входа: 2k изменений cd, m сложений для cnt, 2m изменений ad, n сложений для s и n прибавлений к a. Всего 2k + 3m + 2n действий. В примере это 6 + 9 + 6 = 21 действие, при n = m = k = 105 это 7 · 105 действий. Дополнительная память: O(n + m) для любого входа: в ops лежат m операций, в cd m + 1 число, в ad n + 1 число. Запросы программа не хранит. Ответ отдельно: n чисел в a.

На примере прямое применение короче: 17 прибавлений против 21 действия. Цена двух отметок не зависит от длины отрезка, поэтому выигрыш появляется на длинных отрезках.

Наибольшая прибавка к одному элементу: 105 операций с d = 105, каждую запускают 105 запросов. Это 105 · 105 · 105 = 1015. Целые числа Python не переполняются. В C++ 32-битный тип int хранит числа до 2 147 483 647, поэтому там для ad, s, a и для произведения d · cnt (до 1010) нужен 64-битный тип. О нём говорит совет про %lld в конце условия.

Типичные ошибки

  • Минус на одно место раньше. Если запрос [x, y] ставит −1 в cd[y − 1], операция y теряет этот запрос. В примере получается cnt = [2, 2, 0] вместо [2, 3, 2].
  • Список длины m вместо m + 1. Запрос [1, 3] пишет в cd[3], а в списке из 3 чисел есть только места 0, 1 и 2: Python останавливает программу с ошибкой IndexError. То же с ad длины n: операция (1, 3, 2) пишет в ad[3].
  • Отметка cd[i] вместо cnt. В примере cd[1] = 1, а операцию 2 запускают 3 запроса. Число запросов получается только после Prefix Sum.
  • Difference Array только один раз. Пусть числа cnt посчитаны верно, а прибавку d · cnt программа ставит циклом по элементам с l по r. В худшем случае это m · n = 105 · 105 = 1010 прибавлений: слишком долго. Подсчёт cnt циклом по операциям каждого запроса в худшем случае стоит столько же: k · m = 1010 прибавлений.
