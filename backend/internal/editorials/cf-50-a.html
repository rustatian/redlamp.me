На доске 2 × 4 поставим по одной кости вертикально в каждом столбце. Все восемь клеток заняты четырьмя костями.

На доске 3 × 3 девять клеток. Для пяти костей нужно 5 · 2 = 10 клеток, поэтому поместится не больше четырёх костей. Поставим три кости вертикально между первой и второй строками. В третьей строке положим одну кость горизонтально. Получилось четыре кости, и свободна только последняя клетка.

Повторим эту укладку для доски из m строк и n столбцов. Разобьём строки на соседние пары, начиная сверху. В каждой паре заполним каждый столбец одной вертикальной костью. Если число строк чётное, мы закрыли всю доску. Если осталась строка, заполним её горизонтальными костями слева направо. При чётном числе столбцов закроем строку целиком, при нечётном останется одна клетка. На доске 3 × 4 последнюю строку тоже заполним целиком, и поместятся шесть костей.

Каждая кость занимает две отдельные клетки, поэтому больше (m * n) // 2 костей не поместится. Наша укладка достигает этой границы: даже если остаётся клетка, для ещё одной кости её мало.

m, n = map(int, input().split())
answer = m * n // 2
print(answer)

Время: O(1) в худшем случае для одной доски и всего ввода. Программа читает два числа до 16, выполняет одно умножение и одно целочисленное деление. Она печатает не более трёх цифр и перевод строки: наибольший ответ равен 16 · 16 / 2 = 128. Дополнительная память: O(1) в худшем случае для одной доски и всего ввода. При разборе строки split() создаёт список из двух коротких строк. Для вывода достаточно записи одного числа.
