Ответ - длина самой длинной серии. Серия - это единицы подряд, слева и справа от которых стоит ноль или край Array. В примере 1 nums = [1, 1, 0, 1, 1, 1] две серии, их длины 2 и 3. Ответ 3.

Brute Force берёт каждое начало i и идёт вправо, пока стоят единицы. Для nums = [1, 1, 1] начало 0 даёт 3 шага, начало 1 даёт 2 шага, начало 2 даёт 1 шаг. Всего 6 шагов, и 6 = 3 · 4 / 2. Пусть n - длина nums. Для Array из n единиц это n · (n + 1) / 2 шагов, то есть O(n2). При n = 105 это 5 000 050 000 шагов: слишком долго.

Решение 1. Sliding Window

Окно [l, r] - Subarray из одних единиц. Правая граница r на каждом шаге сдвигается на 1 вправо. Левая граница l стоит на начале текущей серии. Длина окна равна r - l + 1, а best хранит наибольшую длину.

Возьмите пример 1: nums = [1, 1, 0, 1, 1, 1]. Сначала l = 0 и best = 0. На местах 0 и 1 стоят единицы, и l остаётся 0. Длины окон 1 и 2, поэтому best = 2. На месте 2 стоит ноль. Окно не может его содержать, поэтому l = 3. Окно [3, 2] пустое, его длина 2 − 3 + 1 = 0. На местах 3, 4 и 5 стоят единицы, и l остаётся 3. Длины окон 1, 2 и 3, поэтому best = 3.

Правило. Если nums[r] == 0, поставьте l = r + 1. Потом обновите best: best = max(best, r - l + 1).

Число l на 1 больше места последнего нуля не правее r. Если нулей ещё не было, l = 0. В примере 1 при r = 4 последний ноль стоит на месте 2, и l = 3. Окно [3, 4] состоит из единиц. Окно с началом левее 3 содержит ноль на месте 2. Поэтому [3, 4] - самое длинное окно из единиц, которое заканчивается на месте 4, и его длина 2.

Каждое окно состоит из одних единиц, поэтому best не больше ответа. Самая длинная серия заканчивается на каком-то месте r, и на этом шаге окно равно ей, поэтому best не меньше ответа. В примере 1 серия длины 3 заканчивается на месте 5, и на этом шаге 5 − 3 + 1 = 3.

Пример 2: nums = [1, 0, 1, 1, 0, 1]. Нули стоят на местах 1 и 4, и они ставят l = 2 и l = 5. Длины окон на шагах r от 0 до 5 равны 1, 0, 1, 2, 0, 1, поэтому ответ 2.

Если в Array нет нулей, l остаётся 0. Для nums = [1, 1, 1] длины окон 1, 2 и 3, ответ 3. Если в Array нет единиц, каждое окно пустое. Для nums = [0] при r = 0 получается l = 1 и длина 0 − 1 + 1 = 0, ответ 0.

Это шаблон Sliding Window переменной длины при k = 0, где k - допустимое число нулей в окне. Шаблон сдвигает l в цикле while, пока в окне больше k нулей. В примере 1 при k = 0 и r = 2 цикл делает 3 сдвига: он убирает из окна nums[0] = 1, nums[1] = 1 и nums[2] = 0 и заканчивается на l = 3. Так же при любом нуле на месте r: цикл заканчивается на l = r + 1, поэтому код ставит l = r + 1 сразу.

class Solution:
    def findMaxConsecutiveOnes(self, nums: list[int]) -> int:
        l = 0
        best = 0
        for r in range(len(nums)):
            if nums[r] == 0:
                l = r + 1  # новая серия начинается правее нуля
            best = max(best, r - l + 1)
        return best

Время: цикл делает n шагов, и каждый шаг стоит O(1): O(n) в худшем случае. Дополнительная память: переменные l, r и best: O(1) для любого входа.

Типичные ошибки

  • Посчитать все единицы через sum(nums). Для примера 2 nums = [1, 0, 1, 1, 0, 1] сумма равна 4, а ответ 2: нули разрывают серию.
  • Поставить l = r при нуле. Окно [r, r] тогда содержит ноль, и его длина 1 попадает в best. Для nums = [0] такой код вернёт 1, а ответ 0.
  • Обновлять best только при нуле. Серия, после которой нет нуля, тогда не попадает в best. Для примера 1 такой код вернёт 2, а ответ 3.
