Решение. Simulation

В первом ряду одна точка, поэтому для n = 1 ответ YES. Во втором ряду ещё две точки: 1 + 2 = 3. Получили треугольник для n = 3, а число 2 пропустили. Проверим n = 2: после первого ряда сумма равна 1, а после второго она становится 3, поэтому для n = 2 ответ NO.

Пусть row хранит длину последнего ряда, а total хранит общее число точек. В начале row = 0 и total = 0. Каждый новый ряд длиннее предыдущего на одну точку. Пока total < n, увеличиваем row на один и прибавляем его к total. Если после цикла total == n, построенные ряды дают нужный треугольник. Если сумма превысила n, ответ NO: мы проверили все меньшие треугольники, а каждый следующий ряд только увеличит сумму.

n = int(input())
row = 0
total = 0
while total < n:
    row += 1
    total += row
print("YES" if total == n else "NO")

Запишем сумму длин четырёх рядов дважды: 1 + 2 + 3 + 4 и 4 + 3 + 2 + 1. Сложим числа на одинаковых местах: 1 + 4, 2 + 3, 3 + 2 и 4 + 1. Получили четыре пары по пять, поэтому одна запись даёт 4 · 5 / 2 = 10. Для k рядов получим k пар по k + 1, значит, сумма равна k(k + 1) / 2.

Для k = 4 имеем 5 > 4, поэтому 4 · 5 / 2 = 10 не меньше 4 · 4 / 2 = 8. После k шагов сумма k(k + 1) / 2 не меньше k · k / 2, так как k + 1 > k.

Для n = 3 имеем 2n = 6, причём 2 · 2 = 4 < 6 < 9 = 3 · 3. При k = 3 получаем 3 · 3 = 9 ≥ 6 и нижнюю оценку 3 · 3 / 2 = 4,5 ≥ 3, поэтому цикл делает не больше 3 шагов. Для n = 3 цикл останавливается после 2 рядов, так как 1 + 2 = 3. В общем случае, как только k · k ≥ 2n, деление обеих частей на 2 даёт k · k / 2 ≥ n. Тогда сумма точек не меньше n, и цикл останавливается. Наименьшее целое k с условием k · k ≥ 2n равно ⌈√(2n)⌉, где ⌈x⌉ обозначает округление вверх.

При n = 500 получаем 2n = 1000 и 31 · 31 = 961 < 1000 < 1024 = 32 · 32, поэтому ⌈√1000⌉ = 32. Проверим точные суммы: после 31 ряда получаем 31 · 32 / 2 = 496 < 500 точек, а после 32 рядов уже 32 · 33 / 2 = 528 ≥ 500. Цикл делает ровно 32 шага, что совпадает с верхней оценкой 32.

Время: O(√n) в худшем случае для всего ввода из одного числа: цикл делает не больше ⌈√(2n)⌉ шагов, а каждый шаг добавляет один ряд за постоянное время. Дополнительная память: O(1) в худшем случае. Программа хранит три целых числа: n, row и total. При чтении input() создаёт временную строку длиной до трёх цифр, так как n ≤ 500. Программа сразу печатает одно короткое слово и перевод строки.
