В примере [1, 2, 3, 1, 1] только одно значение меньше двойки, хотя единица встречается трижды. Поэтому ответ равен 2.

В этом примере Brute Force проверит только единицу и двойку. Для очередного числа программа считает, сколько разных значений во всём списке меньше него. Если такое значение ровно одно, программа выводит проверяемое число и останавливается. Для 100 одинаковых чисел придётся сделать 100 · 100 = 10 000 сравнений. При длине n это n2 сравнений в худшем случае.

Решение 1. Два минимума за один проход

Возьмём [1, 2, 2, -4]. После первого числа знаем только минимум first = 1. В second пока запишем 101. Входные числа не больше 100, поэтому 101 означает, что второго значения ещё нет.

Двойка больше единицы и меньше 101, поэтому становится вторым значением. Повторная двойка оставляет пару (1, 2) прежней. Когда приходит -4, прежний минимум 1 становится ответом. Все прочитанные до этого числа не меньше единицы, а сама единица больше нового минимума. Поэтому при x < first сначала сохраняем прежнее first в second и только потом меняем first.

Пусть после 1 и 5 пришло 3. До прихода тройки пятёрка была наименьшим из прочитанных чисел выше минимума. Так как 1 < 3 < 5, оставляем first = 1 и записываем second = 3.

На входе [1, 1] после первого числа получаем first = 1 и second = 101. Второе число даёт x = first = 1. Поскольку 1 < 1 неверно, оба условия x < first и first < x < second не выполняются. Переменные first и second не меняются. В second так и остаётся 101, и программа выводит NO. Число, равное first, повторяет минимум, а число не меньше second уже не улучшит ответ.

n = int(input())
words = input().split()
first = int(words[0])
second = 101

for i in range(1, n):
    x = int(words[i])
    if x < first:
        second = first
        first = x
    elif first < x < second:
        second = x

print("NO" if second == 101 else second)

Время: O(n) в худшем случае. После первого числа цикл проверяет ещё n − 1 чисел. Дополнительная память: O(n) в худшем случае. Для двух минимумов хватает двух переменных, но split() сохраняет в words все n частей строки.

Решение 2. Таблица отметок

В списке [1, 2, 2, -4] двойка встречается дважды, но для ответа достаточно знать, что она есть. Отведём каждому возможному числу свою ячейку в seen. Для -4 номер ячейки равен −4 + 100 = 96, для 2 он равен 102. Так числа от -100 до 100 занимают ячейки от 0 до 200 по возрастанию. До первого появления числа в его ячейке хранится False. При каждом появлении двойки программа записывает True в seen[102].

При просмотре по возрастанию сначала найдём отметку для -4, затем для 1. До первой отметки в found_first хранится False. Когда находим минимум, записываем found_first = True. Следующая отметка даёт наименьшее из встретившихся чисел выше минимума, поэтому выводим это число и прерываем цикл.

На входе [1, 1] обе единицы отмечают одну и ту же ячейку seen[101]. При x = 1 программа записывает found_first = True. Дальше цикл доходит до x = 100 без второй отметки. Цикл заканчивается без break, поэтому программа выполняет блок else и выводит NO.

n = int(input())
words = input().split()
seen = [False] * 201
for i in range(n):
    x = int(words[i])
    seen[x + 100] = True

found_first = False
for x in range(-100, 101):
    if seen[x + 100]:
        if found_first:
            print(x)
            break
        found_first = True
else:
    print("NO")

Время: O(n) в худшем случае. Программа ставит отметку n раз и проверяет не более 201 ячейки. Дополнительная память: O(n) в худшем случае. В words лежат n частей входной строки, а в seen всегда 201 ячейка.
