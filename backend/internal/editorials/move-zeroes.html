Ненулевые числа должны встать в начало nums в том же порядке, а все нули после них.

Решение 1. Two Pointers с обменом

Возьмите пример 1: nums = [0, 1, 0, 3, 12]. Указатель read проходит все ячейки слева направо. Указатель write показывает ячейку, куда встанет следующее ненулевое число. Сначала write = 0. Если nums[read] не равно 0, код меняет местами числа в ячейках write и read, затем увеличивает write на 1.

В ячейке 0 стоит 0, и код его пропускает. При read = 1 число 1 меняется местами с нулём из ячейки 0. Получается [1, 0, 0, 3, 12] и write = 1. В ячейке 2 снова 0. При read = 3 число 3 меняется местами с нулём из ячейки 1: [1, 3, 0, 0, 12], write = 2. При read = 4 число 12 меняется местами с нулём из ячейки 2: [1, 3, 12, 0, 0], write = 3. Это ответ.

Перед проверкой read = 3 в ячейке 0 стоит прочитанное ненулевое число 1, а в ячейках 1 и 2 стоят нули. Обмен ставит 3 в ячейку 1, а 0 из ячейки 1 уходит в ячейку 3. Теперь ненулевые числа 1 и 3 стоят в ячейках 0 и 1, а нули в ячейках 2 и 3. Так происходит на каждом шаге. Перед каждой проверкой nums[read] в ячейках от 0 до write − 1 стоят прочитанные ненулевые числа в исходном порядке, а в ячейках от write до read − 1 стоят только нули. Если левее read нет ни одного нуля, то write = read, и обмен меняет ячейку саму с собой. Так идут все 3 обмена в [1, 2, 3]. Обмен только меняет два числа местами, поэтому ни одно число не пропадает. После последнего шага все ненулевые числа стоят в начале в исходном порядке, а нули после них.

Время: n - длина nums, k - количество ненулевых чисел. Код делает n проверок nums[read] != 0 и k обменов: O(n). Каждый обмен пишет в 2 ячейки, всего 2k записей. В примере 1 это 5 проверок, 3 обмена и 6 записей. Дополнительная память: read, write и два числа на время обмена, O(1). Ответ лежит в самом nums.

class Solution:
    def moveZeroes(self, nums: list[int]) -> None:
        write = 0
        for read in range(len(nums)):
            if nums[read] != 0:
                # в ячейке write стоит 0, или write == read
                nums[write], nums[read] = nums[read], nums[write]
                write += 1

Решение 2. Two Pointers и заполнение нулями

Вместо обмена код может копировать ненулевое число в ячейку write. В примере 1 первый цикл пишет 1, 3 и 12 в ячейки 0, 1 и 2. После него nums = [1, 3, 12, 3, 12] и write = 3. В ячейках 3 и 4 лежат старые копии чисел 3 и 12. Второй цикл пишет 0 в эти 2 ячейки и даёт [1, 3, 12, 0, 0].

За один шаг read растёт на 1, а write на 1 или на 0. Оба начинают с 0, поэтому при каждой проверке write ≤ read. Значит, код пишет только в ячейки, которые read уже прочитал, и непрочитанные числа не портятся. Первый цикл пишет k ненулевых чисел в ячейки от 0 до k − 1 в исходном порядке. Второй цикл пишет нули в остальные n − k ячеек.

Время: n проверок, k записей ненулевых чисел и n − k записей нулей. Всего ровно n записей: O(n). В примере 1 это 3 + 2 = 5 записей вместо 6 в решении 1. Дополнительная память: read, write и i, O(1).

class Solution:
    def moveZeroes(self, nums: list[int]) -> None:
        write = 0
        for read in range(len(nums)):
            if nums[read] != 0:
                nums[write] = nums[read]  # write ≤ read: эту ячейку read уже прочитал
                write += 1
        for i in range(write, len(nums)):
            nums[i] = 0

Меньше записей

Решение 1 делает 2k записей, решение 2 делает n записей. Решение 2 пишет меньше, когда 2k > n, то есть когда нулей меньше половины. Для [0, 0, 0, 0, 1] решение 1 делает 2 записи, а решение 2 делает 5. Ещё решение 1 тратит записи на обмены ячейки с самой собой. Проверка read != write перед обменом убирает их: для [1, 2, 3, 4, 5] остаётся 0 записей вместо 10.

Типичные ошибки

  • Запись nums[write] = nums[read] без второго цикла. В примере 1 код оставляет [1, 3, 12, 3, 12]: в ячейках 3 и 4 остаются старые копии вместо нулей.
  • Новый list под именем nums: nums = [x for x in nums if x != 0] + [0] * nums.count(0). После этой строки имя nums внутри метода указывает на новый list, а list, который передал тест, не меняется. В примере 1 тест получает [0, 1, 0, 3, 12]. Запись nums[:] = ... меняет сам list и даёт верный ответ, но новый list занимает O(n) дополнительной памяти. Это копия Array, а условие её запрещает.
  • nums.pop(i) и nums.append(0) внутри for i in range(len(nums)). После pop(i) следующее число встаёт в ячейку i, а цикл переходит к i + 1 и это число не проверяет. Для [0, 0, 1] код даёт [0, 1, 0].
