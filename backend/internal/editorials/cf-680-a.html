В первом примере сумма всех карт равна 40. Пара троек уменьшит её на 6, а пара семёрок на 14. Выбираем семёрки: останется 40 − 14 = 26.

У карт 4 4 4 7 7 есть и тройка, и пара. Три четвёрки дают 3 · 4 = 12, две семёрки дают 2 · 7 = 14. Сумма всех карт равна 12 + 14 = 26. Выгоднее убрать пару: 26 − 14 = 12.

Для каждого числа value посчитаем его карты. Одну карту убрать нельзя. Если карт две, можно убрать пару. Если их три, четыре или пять, берём три: числа положительные, а больше трёх карт убрать нельзя. Так мы проверим лучший ход для каждого числа. В best сохраним наибольшую сумму, которую можно убрать за один ход. Если пары нет, best останется нулём. Вычтем best из общей суммы и получим наименьший остаток.

cards = list(map(int, input().split()))
best = 0
for value in cards:
    copies = cards.count(value)
    if copies >= 2:
        saved = value * min(copies, 3)
        best = max(best, saved)
print(sum(cards) - best)

Время: на единственный набор и на весь ввод в худшем случае O(1): для каждой из пяти карт count проверяет пять значений. Если считать символы, чтение строки длины L занимает O(L). Дополнительная память: на набор и на всю программу в худшем случае O(1) при заданных пределах. При чтении нужна память O(L) для строки, затем split даёт пять строк, а list собирает пять чисел. print выводит одно число без списка ответов.
