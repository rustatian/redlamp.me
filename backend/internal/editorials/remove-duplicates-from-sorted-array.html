Нужно собрать в начале nums все разные числа по одному разу и вернуть их количество k. Далее n - длина nums.

Решение 1. Two Pointers

Возьмите пример 2: nums = [0, 0, 1, 1, 1, 2, 2, 3, 3, 4]. Array отсортирован, поэтому равные числа стоят подряд. Три единицы занимают ячейки 2, 3 и 4, две тройки занимают ячейки 7 и 8.

Решение идёт по Array двумя индексами. Индекс read читает ячейки слева направо. Индекс write показывает ячейку для следующего нового числа. Число nums[0] = 0 не может быть повтором: левее него чисел нет. Поэтому оно остаётся на месте, write = 1, а read начинает с ячейки 1. Последнее оставленное число лежит в ячейке write - 1.

  • read = 1: число 0 равно последнему оставленному числу nums[0] = 0. Это повтор, записи нет.
  • read = 2: число 1 больше, чем nums[0] = 0. Число 1 записано в ячейку 1, и write = 2.
  • read = 3 и read = 4: число 1 равно nums[1] = 1. Это повторы.
  • read = 5: число 2 больше, чем nums[1] = 1. Число 2 записано в ячейку 2, и write = 3.

Остальные шаги показывает рисунок. В конце write = 5, и первые 5 ячеек содержат [0, 1, 2, 3, 4]. Метод возвращает k = write = 5.

Почему достаточно одного сравнения. После read = 6 оставлены числа 0, 1 и 2. Они идут по возрастанию, поэтому последнее оставленное число 2 самое большое из них. При read = 7 читается число 3. Array отсортирован, поэтому 3 не меньше всех прочитанных чисел. Число 3 больше последнего оставленного числа 2. Значит, оно больше всех оставленных чисел и встречается первый раз. При read = 8 снова читается 3. Оно равно последнему оставленному числу 3, и это повтор. Число nums[read] никогда не меньше последнего оставленного, поэтому условие nums[read] != nums[write - 1] в коде значит «больше».

Почему запись не портит непрочитанные числа. Каждый шаг увеличивает read на 1, а write на 0 или на 1. Оба индекса начинают с 1, поэтому при записи write не больше read. Например, при read = 5 число 2 идёт в ячейку 2. Старое число 1 из ячейки 2 уже прочитано при read = 2. Ячейки с 6 по 9 эта запись не меняет.

Инвариант. После каждого шага первые write ячеек содержат все разные числа из ячеек от 0 до read, по одному разу и по возрастанию. После read = 5 это [0, 1, 2]. На последнем шаге read = n - 1, поэтому в конце k = write.

При n = 1, например nums = [7], цикл не делает ни одного шага, и метод возвращает write = 1.

class Solution:
    def removeDuplicates(self, nums: list[int]) -> int:
        write = 1  # nums[0] остаётся всегда
        for read in range(1, len(nums)):
            if nums[read] != nums[write - 1]:  # равные числа идут подряд
                nums[write] = nums[read]
                write += 1
        return write

Время: цикл делает одно сравнение для каждой ячейки от 1 до n − 1: всего n − 1 сравнений. Запись идёт только для нового числа. Все разные числа, кроме nums[0], дают k − 1 записей. Итого O(n) в худшем случае. В примере 2 n = 10 и k = 5: 9 сравнений и 4 записи. Дополнительная память: индексы read и write, O(1) для любого входа. Ответ лежит в самом nums.

Медленный способ

Можно удалять повторы: если nums[i + 1] == nums[i], выполнить del nums[i + 1], иначе увеличить i на 1. Ответ будет верным. Но после каждого удаления все числа правее сдвигаются на одну ячейку влево. Для [4, 4, 4, 4, 4] четыре удаления сдвигают 3, 2, 1 и 0 чисел: всего 6 сдвигов. Для n одинаковых чисел удаления сдвигают n − 2, n − 3, …, 1 и 0 чисел: всего (n − 1)(n − 2)/2 сдвигов, O(n²) в худшем случае. При n = 3 · 104 это около 4,5 · 108 сдвигов. Решение 1 на этом входе делает 29 999 сравнений и ни одной записи. При n = 3 · 104 код с del всё же проходит тесты: один del сдвигает все числа правее одним быстрым копированием памяти. Но если бы n было в 10 раз больше, сдвигов было бы примерно в 100 раз больше.

Типичные ошибки

  • Сравнение с nums[write] вместо nums[write - 1]. Ячейка write стоит после ответа, поэтому в ней лежит не последнее оставленное число. В примере 2 при read = 6 число 2 сравнивается с nums[3] = 1, и второе число 2 попадает в ответ. Такой код возвращает 7, и в начале стоит [0, 1, 2, 2, 3, 3, 4].
  • Начало с write = 0 и read = 0. Тогда первое сравнение читает nums[-1], а в Python это последний элемент. Для nums = [7] число 7 равно nums[-1] = 7, и метод возвращает 0 вместо 1.
  • Только подсчёт k. Код return len(set(nums)) в примере 1 возвращает 2, но в начале nums остаётся [1, 1]. Код nums = sorted(set(nums)) тоже не помогает: имя nums внутри метода получает новый list, а list проверяющей программы остаётся [1, 1, 2].
