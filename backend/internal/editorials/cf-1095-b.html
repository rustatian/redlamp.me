Решение 1. Sorting

В первом примере числа уже не убывают: [1, 3, 3, 7]. Если убрать 1, разность станет 7 − 3 = 4. Если убрать 7, получим 3 − 1 = 2. Удаление любой тройки сохранит оба края и разность 7 − 1 = 6.

После Sorting удаление внутреннего элемента сохраняет прежнюю разность. Удаление крайнего элемента может только уменьшить разность или оставить её прежней. Поэтому достаточно сравнить два удаления: без первого числа разность равна a[-1] − a[1], без последнего она равна a[-2] − a[0].

Иногда лучший ответ даёт и внутренний элемент: в [1, 1, 2, 3, 3] после любого удаления останутся и единица, и тройка. Во втором примере после удаления останется одно число, поэтому обе разности равны нулю.

Оставим крайние числа 1 и 9 и поменяем среднее по порядку число. При 7 лучше убрать 1, а при 3 лучше убрать 9: в обоих случаях останется разность 2. При 5 можно убрать любой край: 9 − 5 = 5 − 1 = 4.

import sys

n = int(sys.stdin.readline())
a = list(map(int, sys.stdin.readline().split()))
a.sort()
print(min(a[-1] - a[1], a[-2] - a[0]))

Время: O(n log n) в худшем случае на весь ввод из одного случая: больше всего времени может занять Sorting. Дополнительная память: O(n) в худшем случае на весь ввод. При чтении Python хранит строку и результат split(), а при переводе в числа строит список из n чисел. Для Sorting также может понадобиться временное место на O(n) элементов. Программа сразу печатает одно число.

Решение 2. Linear Scan

В первом примере после первых двух чисел меньшая пара по возрастанию равна (1, 3), а большая по убыванию равна (3, 1). Следующая тройка занимает второе место в большой паре: (3, 3). Когда приходит семёрка, она становится наибольшей, а прежняя тройка занимает второе место: (7, 3).

Для уже прочитанных чисел будем хранить два наименьших значения (low, low2) с low ≤ low2 и два наибольших значения (high, high2) с high ≥ high2. Запись values = map(int, words) переводит слова в числа по одному при чтении и запоминает текущую позицию. По условию n ≥ 2, поэтому первые два вызова next(values) всегда получают пару чисел. Вызов sorted ставит меньшее число в low, а большее в high. Для этих двух чисел (low ≤ high) второе наименьшее равно high, а второе наибольшее равно low, поэтому задаём low2, high2 = high, low. Цикл for x in values: читает только оставшиеся числа, начиная с третьего (при n = 2 таких чисел нет). Переменная x обозначает каждое следующее число.

Если x меньше low, сдвигаем low в low2 и записываем x в low. Иначе заменяем только low2 на x, если x меньше low2. Для большой пары (high, high2) сравниваем в обратную сторону. Если x больше high, сдвигаем high в high2 и записываем x в high. Иначе заменяем только high2 на x, если x больше high2. Так обе пары учитывают повторы: после цикла (low, low2) равно (a[0], a[1]), а (high, high2) равно (a[-1], a[-2]) из Sorting. Поэтому удаление минимума low даёт разность high − low2 (как a[-1] − a[1]), а удаление максимума high даёт high2 − low (как a[-2] − a[0]).

import sys

n = int(sys.stdin.readline())
words = sys.stdin.readline().split()
values = map(int, words)
low, high = sorted((next(values), next(values)))
low2, high2 = high, low
for x in values:
    if x < low:
        low2, low = low, x
    elif x < low2:
        low2 = x
    if x > high:
        high2, high = high, x
    elif x > high2:
        high2 = x
print(min(high - low2, high2 - low))

Время: O(n) в худшем случае на весь ввод из одного случая: для каждого числа хватает нескольких сравнений. Дополнительная память: O(n) в худшем случае на весь ввод. Для двух пар хватает O(1) памяти, но split() создаёт из входной строки список из n слов. Ответ занимает O(1) памяти и сразу идёт на печать.
