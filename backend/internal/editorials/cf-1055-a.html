Во втором примере цель на станции 4, но первый поезд проезжает её без остановки. Можно доехать до станции 5, пересесть и вернуться на станцию 4.

Теперь пусть цель на станции 3, а оба поезда останавливаются на станциях 2 и 4. Если пересесть на станции 2, обратный поезд поедет к станции 1. Для пересадки подходит станция 4: она находится за целью.

В третьем примере n = 5, s = 2, a1 = 0 и b1 = 1, а ответ NO. Второй путь идёт в сторону меньших номеров и заканчивается на станции 1, поэтому даже при b1 = 1 нельзя поехать по нему к станции s ≥ 2. При a1 = 0 первый поезд проезжает станцию 1 без остановки. В первом примере n = 5, s = 3 и a1 = a3 = 1: на первый поезд можно сесть на станции 1 и сразу доехать до станции 3, поэтому ответ YES.

Сначала проверим станцию 1: если первый путь там закрыт, уехать к цели нельзя. Если можно сесть в первый поезд и он останавливается на станции s, едем прямо до неё.

Иначе попасть на станцию s можно только по второму пути, поэтому он должен быть там открыт. Чтобы приехать с этой стороны, нужно сесть в обратный поезд за целью. Туда можно сразу доехать первым поездом, если на станции пересадки открыты оба пути. Поэтому достаточно одной пересадки. Для пересадки должны быть открыты оба пути, поэтому станция с одним открытым направлением не подходит. Пересадка на второй путь до s ведёт к станции 1, поэтому попасть на обратный поезд за s даже с несколькими пересадками можно только при смене пути за целью. Если за целью нет общей остановки, такой маршрут невозможен.

В списке a станция s имеет индекс s − 1, поэтому проверку станций за целью начинаем с индекса s.

n, s = map(int, input().split())
a = input().split()
b = input().split()

possible = False
if a[0] == "1":
    if a[s - 1] == "1":
        possible = True
    elif b[s - 1] == "1":
        for i in range(s, n):
            if a[i] == b[i] == "1":
                possible = True
                break

print("YES" if possible else "NO")

Программа обрабатывает один случай. Время: O(n) в худшем случае на этот случай и на весь ввод. Для каждого пути split() обрабатывает n значений, а цикл for проверяет не больше n − s станций (не больше n − 2 при s = 2, до 998 проверок при n = 1000). Дополнительная память: O(n) в худшем случае для всей программы. При чтении split() создаёт список из n значений для каждого пути. Исходная строка нужна только до конца её разбиения. На вывод одного слова с переводом строки нужно O(1) памяти.
