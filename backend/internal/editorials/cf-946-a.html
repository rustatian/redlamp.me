Как выбрать группу для числа

В первом примере положим 1 в группу b, а −2 в группу c. Тогда разность сумм равна 1 − (−2) = 3. Ноль можно положить в любую группу: обе суммы останутся прежними.

Число x из группы b даёт вклад x в разность, а из группы c даёт вклад −x. Для положительного числа больше первый вклад, для отрицательного больше второй. Больший из двух вкладов равен модулю числа: например, abs(-2) даёт 2.

Выбор группы для одного числа не меняет вклад остальных. Поэтому можно взять больший вклад для каждого числа и сложить их в total. Такое разбиение даёт максимум: ни одно число не может дать больше своего модуля.

Во втором примере все числа идут в b, а группа c остаётся пустой. Получаем 16 + 23 + 16 + 15 + 42 + 8 = 120.

n = int(input())
tokens = input().split()
total = 0
for token in tokens:
    x = int(token)
    total += abs(x)
print(total)

Во входных данных один набор из n чисел. Время: O(n) в худшем случае за весь запуск: программа читает каждое число и один раз прибавляет его модуль. Дополнительная память: O(n) в худшем случае за весь запуск. При чтении программа хранит строку ввода, а split() создаёт список из n коротких строк. Для вывода нужна строка длиной до пяти цифр: при n ≤ 100 и модуле числа до 100 сумма не больше 100 · 100 = 10000.
