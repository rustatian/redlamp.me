В примере 9 чисел: три единицы, четыре двойки и две тройки. Оставим двойки и заменим остальные числа на двойки: 3 + 2 = 5 замен.

Если выбрать другое число, придётся заменить каждое число, которое с ним не совпадает. Поэтому выгодно оставить число, которое встречается чаще всего. В примере можно сохранить не больше четырёх чисел, поэтому 9 − 4 = 5 замен достаточно и меньше сделать нельзя.

Четыре тройки уже равны. В наборе 2 3 2 2 достаточно заменить одну тройку на двойку. В наборе 1 2 1 2 единиц и двоек поровну, поэтому при любом из этих двух выборов нужны 4 − 2 = 2 замены.

В списке Python индексы идут с 0. Поэтому список хранит три счётчика с индексами 0, 1 и 2 для значений 1, 2 и 3. Для двойки увеличим на 1 счётчик с индексом 2 − 1 = 1. Так для каждого числа увеличим его счётчик на 1. Затем вычтем наибольший счётчик из n.

import sys

n = int(sys.stdin.readline())
numbers = sys.stdin.readline().split()
counts = [0, 0, 0]
for number in numbers:
    counts[int(number) - 1] += 1

print(n - max(counts))

Время: O(n) в худшем случае для всего ввода: в нём один набор из n чисел, каждое занимает одну цифру. Дополнительная память: O(n) в худшем случае для всего набора. При вызове split() в памяти находятся строка ввода и список из n одноцифровых слов. Для подсчёта нужны три счётчика. Программа сразу печатает один ответ длиной не больше семи цифр, так как n ≤ 106.
