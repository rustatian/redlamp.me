Нужно выписать каждый набор чисел из nums ровно один раз, вместе с пустым набором.

Решение 1. Backtracking

Пусть n это длина nums. Возьмите пример 1: nums = [1, 2, 3]. Каждое число либо входит в Subset, либо нет. Это 2 · 2 · 2 = 8 вариантов выбора. Все числа разные, поэтому разные варианты дают разные Subsets. Для n чисел Subsets 2n, при n = 10 их 1024.

Наборы [1, 3] и [3, 1] это один и тот же Subset. Чтобы не получить его два раза, пишем числа Subset в порядке их мест в nums: сначала число с меньшим местом. Тогда у каждого Subset ровно одна запись.

Функция dfs(start) работает с одним общим list по имени path. Сначала она сохраняет копию path в res. Затем цикл идёт по местам i от start до n − 1: кладёт nums[i] в path, вызывает dfs(i + 1) и убирает это число через path.pop(). Вызов dfs(i + 1) берёт числа только с мест правее i. Поэтому места чисел в path всегда идут по возрастанию.

Для [1, 2, 3] вызовы сохраняют ответы в таком порядке: [], [1], [1, 2], [1, 2, 3], [1, 3], [2], [2, 3], [3]. Это 8 вызовов и 8 ответов. Рисунок показывает каждый вызов.

Каждый Subset появляется ровно один раз. Возьмите [1, 3]: это места 0 и 2. Цепочка вызовов к нему одна. dfs(0) при i = 0 кладёт 1 и вызывает dfs(1). Затем dfs(1) при i = 2 кладёт 3 и вызывает dfs(3), а он сохраняет [1, 3]. Запись [3, 1] не появится: после числа 3 с места 2 идёт dfs(3), а он берёт числа только с мест правее 2. Число 1 стоит на месте 0, левее. Так же для любого Subset: его первое место выбирает цикл dfs(0), второе место цикл следующего вызова, и так далее. Каждый вызов сохраняет ответ, а не только самый глубокий: dfs(1) сохраняет [1] раньше, чем path станет [1, 2].

class Solution:
    def subsets(self, nums: list[int]) -> list[list[int]]:
        res = []
        path = []

        def dfs(start):
            res.append(path[:])  # копия: path ещё изменится
            for i in range(start, len(nums)):
                path.append(nums[i])
                dfs(i + 1)  # дальше только места правее i
                path.pop()

        dfs(0)
        return res

Время: каждый вызов сохраняет один ответ, поэтому вызовов ровно 2n. Каждый вызов, кроме dfs(0), начат одним шагом цикла: append, вызов, pop. Значит, шагов цикла 2n − 1. Копия path[:] переписывает все числа path. Число 1 входит в 4 из 8 Subsets примера: пары [] и [1], [2] и [1, 2], [3] и [1, 3], [2, 3] и [1, 2, 3] отличаются только числом 1. Так каждое из n чисел входит в половину Subsets, то есть в 2n − 1. Поэтому всего копируется n · 2n − 1 чисел: 12 при n = 3. Время O(n · 2n) для любого входа длины n. При n = 10 это 1024 вызова и 5120 скопированных чисел.

Дополнительная память: path хранит до n чисел, а Call Stack держит до n + 1 вызовов dfs: O(n). При n = 3 это до 3 чисел и 4 вызовов. Ответ занимает 2n объектов list с n · 2n − 1 числами, его считаем отдельно.

Решение 2. Bitmask Enumeration

Для [1, 2, 3] Subset [1, 3] берёт места 0 и 2 и не берёт место 1. Запишем этот выбор битами: бит 0 равен 1, бит 1 равен 0, бит 2 равен 1. Бит 0 стоит справа в двоичной записи, поэтому получаем 101, то есть число 5. Так любой выбор для n мест это число mask из n битов: бит i равен 1, когда берём nums[i]. Для mask = 6 запись 110: биты 1 и 2 равны 1, ответ [2, 3].

При n = 3 запись 1 << 3 сдвигает 1 на 3 бита влево: получаем двоичную запись 1000, то есть 8. Для любого n запись 1 << n равна 2n. Цикл range(1 << n) проходит числа от 0 до 7: все записи из 3 битов от 000 до 111. Два разных значения mask отличаются хотя бы одним битом, то есть хотя бы одним местом. Поэтому разные значения mask дают разные Subsets. Каждый Subset тоже получает свою mask: [2, 3] это места 1 и 2, mask = 21 + 22 = 6. Так цикл выдаёт все 2n Subsets без повторов.

Для mask = 5 и i = 2 сдвиг 5 >> 2 убирает 2 правых бита: из записи 101 остаётся 1. Затем & 1 оставляет только бит 0: 1 & 1 = 1, поэтому nums[2] = 3 входит в ответ. Для i = 1 сдвиг 5 >> 1 убирает 1 правый бит: из 101 остаётся 10, то есть 2. Бит 0 числа 2 равен 0, и 2 & 1 = 0, поэтому nums[1] = 2 не входит. Так выражение mask >> i & 1 даёт бит i числа mask. Python выполняет сдвиг раньше, чем &.

На рисунке строка «бит i» идёт по местам: бит 0 слева, над nums[0]. Поэтому для mask = 1 в строке стоят 1, 0, 0, а двоичная запись 001.

Для [1, 2, 3] решение 2 выдаёт ответы в том же порядке, что и выход примера 1. Решение 1 даёт другой порядок, и оно тоже верно: порядок ответов любой.

class Solution:
    def subsets(self, nums: list[int]) -> list[list[int]]:
        n = len(nums)
        res = []
        for mask in range(1 << n):
            # бит i числа mask равен 1: берём nums[i]
            res.append([nums[i] for i in range(n) if mask >> i & 1])
        return res

Время: mask принимает 2n значений, и для каждого код проверяет n битов: n · 2n проверок. При n = 3 это 24 проверки, при n = 10 это 10 240. В ответы попадают те же n · 2n − 1 чисел, что и в решении 1. Время O(n · 2n) для любого входа длины n.

Дополнительная память: кроме ответа код хранит только n, mask и i: O(1). Новый list сразу становится частью ответа.

Типичные ошибки

  • res.append(path) без копии. Тогда все 8 элементов res это один и тот же list path. После последнего pop он пустой, и для [1, 2, 3] ответ равен [[], [], [], [], [], [], [], []].
  • dfs(start + 1) вместо dfs(i + 1). Тогда после числа с места i следующий вызов снова может взять место i или места левее. Для [1, 2, 3] выйдет 16 объектов list, среди них [2, 2], [3, 2] и [3, 3, 3].
