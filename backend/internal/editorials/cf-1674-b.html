Номер слова на 1 больше числа слов перед ним. Эти слова можно сосчитать по Product Rule, без перебора словаря.

Решение 1. Product Rule

Пронумеруем буквы с 0: a это 0, b это 1, c это 2, и так до z с номером 25. Слова словаря идут блоками: сначала все слова на a, затем все слова на b и так далее. В блоке на a вторая буква любая, кроме самой a: b, c, ..., z. Это 25 слов с номерами от 1 до 25. В каждом блоке тоже 25 слов: вторая буква любая из 26, кроме первой. Блоков 26, по одному на каждую первую букву. Product Rule даёт 26 · 25 = 650 слов, поэтому последнее слово zy имеет номер 650.

Возьмём слово bc из примера. Первая буква b имеет номер i = 1, вторая буква c имеет номер j = 2. Перед блоком на b стоит один блок на a: 1 · 25 = 25 слов. Внутри блока на b вторые буквы идут по алфавиту: a, c, d и так далее. Букв меньше c две: a и b. Но слова bb нет, поэтому в блоке перед bc стоит одно слово ba. Всего перед bc 25 + 1 = 26 слов, и номер bc равен 27, как в примере.

Теперь слово ba: i = 1, j = 0. Букв меньше a нет, поэтому в блоке перед ba 0 слов. Номер 25 + 0 + 1 = 26.

Правило. Пусть i и j - номера первой и второй буквы, от 0. Перед блоком первой буквы стоят i блоков по 25 слов: i · 25 слов. В блоке перед словом стоят слова, у которых номер второй буквы меньше j. Таких букв j. При i < j среди них есть сама первая буква, а слова из двух одинаковых букв нет. Поэтому before = j − 1 при i < j и before = j при j < i. Номер равен i · 25 + before + 1.

На рисунке блок первой буквы и номера его слов для каждого слова примера. Все 7 номеров совпадают с ответом примера.

import sys

t = int(sys.stdin.readline())
out = []
for _ in range(t):
    s = sys.stdin.readline().strip()
    i = ord(s[0]) - ord("a")  # номер первой буквы, от 0
    j = ord(s[1]) - ord("a")  # номер второй буквы, от 0
    # среди j меньших букв есть сама первая буква, если i < j
    before = j - 1 if i < j else j
    out.append(i * 25 + before + 1)
print("\n".join(map(str, out)))

Время: O(t): на каждое слово четыре вызова ord, одно сравнение и одна формула. Дополнительная память: O(1): числа i, j и before. Список out с t числами это ответ.

Решение 2. Hash Table

Все 650 слов можно перебрать заранее двумя циклами. Внешний цикл перебирает первую букву x от a до z. Внутренний цикл перебирает вторую букву y от a до z и пропускает y = x. Все слова на a появляются раньше слов на b: это первое условие порядка. Внутри блока вторые буквы идут по алфавиту: это второе условие. Значит, слова появляются ровно в порядке словаря.

Каждое новое слово получает номер len(index) + 1. Слово ab получает 1, слово az получает 25. Затем x = b, и при y = a слово ba получает 26. При y = b условие x != y ложно, и следующее слово bc получает 27. Dict index хранит номер каждого слова, поэтому ответ для s это один поиск по ключу в Hash Table: index[s].

import sys

letters = "abcdefghijklmnopqrstuvwxyz"
index = {}
for x in letters:
    for y in letters:
        if x != y:
            index[x + y] = len(index) + 1  # слова идут в порядке словаря
t = int(sys.stdin.readline())
out = []
for _ in range(t):
    out.append(index[sys.stdin.readline().strip()])
print("\n".join(map(str, out)))

Время: построение делает 26 · 26 = 676 проверок x != y и 650 записей в index при любом t. Затем на каждое слово один поиск index[s], в среднем случае Hash Table это O(1). Построение не зависит от t, поэтому всего O(t) в среднем случае. Дополнительная память: O(1) относительно t: index всегда хранит 650 слов с номерами. Список out с t числами это ответ.

Другие способы

Слова можно хранить в списке и искать s проходом по списку. Можно и ничего не хранить: для каждого s снова перебирать слова двумя циклами и считать их, пока не встретится s. Для слова zy оба способа делают 650 сравнений слов. При t = 650 это 650 · 650 = 422 500 сравнений. На нашем компьютере способ без хранения слов прошёл тест из 650 слов zy меньше чем за 0,1 с, а лимит задачи 2 с.

Типичные ошибки

  • В каждом блоке 25 слов, а не 26: например, слова bb нет. С множителем 26 слово ba получит номер 1 · 26 + 0 + 1 = 27 вместо 26.
  • Если всегда брать before = j, слово ab получит номер 0 · 25 + 1 + 1 = 2 вместо 1: буква a меньше b, но слова aa нет. Слова ba, zx и zy эта ошибка не меняет, потому что у них j < i.
  • sys.stdin.readline() возвращает строку вместе с переводом строки: "ab\n". Ключа "ab\n" в index нет, и Решение 2 без strip() упадёт с KeyError.
