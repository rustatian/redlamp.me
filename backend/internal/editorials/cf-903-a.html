Для x = 6 без больших порций (b = 0) остаётся 6 − 7 · 0 = 6 кусочков: подходят 6 / 3 = 2 маленькие порции. Для x = 7 одна большая порция оставляет 7 − 7 · 1 = 0 кусочков: маленьких порций не нужно. Для x = 17 две большие порции оставляют 17 − 7 · 2 = 3 кусочка: к ним добавляем одну маленькую порцию. Для x = 5 большая порция уже велика, а маленькие дают только 0 или 3 кусочка без превышения.

Пусть b больших порций уже выбраны. Тогда на маленькие порции остаётся rest = x − 7 · b кусочков. Если остаток неотрицателен и делится на 3, берём rest / 3 маленьких порций. Нулевой остаток тоже подходит: хватило одних больших порций. При отрицательном остатке 7 · b больше x, а по условию число маленьких порций a неотрицательно.

Пусть в заказе нашлось не меньше трёх больших порций, например x = 28 = 4 · 7 (b = 4). Три большие порции можно заменить семью маленькими: 3 · 7 = 7 · 3 = 21. Для x = 28 замена трёх больших порций оставляет 1 большую и 7 маленьких: 1 · 7 + 7 · 3 = 28, где b = 1 < 3. При b = 7 (x = 49) две такие замены уменьшают b с 7 до 4, а затем до 1: 1 · 7 + 14 · 3 = 49. Повторяем замену, пока больших порций не станет меньше трёх. Если заказ можно собрать, то его можно собрать и с нулём, одной или двумя большими порциями. Проверим эти три варианта методом Brute Force. Если ни один остаток не подошёл, ответ NO.

На первом рисунке показана проверка для примеров условия. Для x = 6 перебор останавливается после 1 проверки (b = 0, остаток 6) с ответом YES. Для x = 5 перебор делает все 3 проверки (b = 0, 1, 2) и получает остатки 5, -2 и -9. Остаток 5 на 3 не делится, а при b = 1 и b = 2 значения отрицательны (7 · b > 5), поэтому ответ NO.

Для 10 кусочков нужно по одной порции каждого размера: 3 + 7 = 10. Если нужны 11 кусочков, без большой порции остаётся набрать 11, а с одной большой порцией остаётся 4. Ни 11, ни 4 не делятся на 3, а две большие порции дадут слишком много. Для 14 кусочков две большие порции подходят точно: 7 + 7 = 14.

n = int(input())
for _ in range(n):
    x = int(input())
    answer = "NO"
    for b in range(3):
        rest = x - 7 * b
        if rest >= 0 and rest % 3 == 0:
            answer = "YES"
            break
    print(answer)

Время: в худшем случае O(1) на запрос и O(n) на все n запросов. Дополнительная память: в худшем случае O(1) на запрос и на всю программу. Программа читает по одной строке и сразу печатает ответ. Числа на входе не больше 100, поэтому текущая строка ввода и слово ответа занимают O(1) памяти. Списков входных чисел и ответов программа не создаёт.

Типичные ошибки

  • Если пропустить rest >= 0, программа ошибётся на x = 5. При b = 2 остаток 5 − 7 · 2 равен -9, и в Python проверка -9 % 3 == 0 даёт True. Код выведет YES вместо NO, хотя две большие порции уже дают 2 · 7 = 14 > 5, и число маленьких порций a не может быть отрицательным.
