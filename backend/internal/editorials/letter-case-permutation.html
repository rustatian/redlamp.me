Нужно перебрать все способы выбрать форму каждой буквы: строчную или заглавную.

Решение 1. Backtracking

Возьмите пример 1: s = "a1b2". Место 0 даёт a или A, место 1 только 1, место 2 даёт b или B, место 3 только 2. Выбор на одном месте не зависит от выбора на другом, поэтому ответов 2 · 1 · 2 · 1 = 4.

Пусть n это длина s, а l число букв в ней. Каждая буква умножает число ответов на 2, поэтому ответов 2l. Ответы не повторяются: два разных набора выборов различаются хотя бы на одном месте с буквой. На этом месте у одного ответа строчная буква, а у другого заглавная. Так у "bbb" 23 = 8 разных ответов, хотя все три буквы одинаковые.

Функция dfs(i) выбирает символ для места i. Общий для всех вызовов list path хранит символы, уже выбранные для мест от 0 до i − 1. Для буквы цикл по options делает два шага, для цифры один. Каждый шаг кладёт форму символа в path, вызывает dfs(i + 1) и убирает эту форму через path.pop(). При i == len(s) в path лежат все n символов, и ''.join(path) даёт один ответ для res.

Для "a1b2" вызовы идут уровнями: 1 вызов dfs(0), затем 2, 2, 4 и 4 вызова dfs(1), dfs(2), dfs(3) и dfs(4). Всего 13 вызовов. Число вызовов растёт вдвое только после буквы. Рисунок показывает вызовы по порядку.

После path.pop() в path снова те же символы, что до path.append(c). На шаге 5 рисунка join даёт ответ a1b2. Затем один pop убирает 2, второй убирает b, и на шаге 6 path равен ['a', '1', 'B']. Ветка с B на месте 2 начинается с того же префикса a1, что и ветка с b. Поэтому каждый набор выборов доходит до join ровно один раз: ответы не теряются и не повторяются.

class Solution:
    def letterCasePermutation(self, s: str) -> list[str]:
        res = []
        path = []

        def dfs(i):
            if i == len(s):
                res.append(''.join(path))
                return
            ch = s[i]
            # буква даёт две ветки, цифра одну
            options = (ch.lower(), ch.upper()) if ch.isalpha() else (ch,)
            for c in options:
                path.append(c)
                dfs(i + 1)
                path.pop()  # path снова такой, как до append

        dfs(0)
        return res

Время: вызовов на уровне i столько, сколько вариантов у первых i символов: не больше 2l. Уровней n + 1, поэтому вызовов не больше (n + 1) · 2l. Вызов с i < len(s) делает не больше двух append и двух pop. Каждый из 2l вызовов с i == len(s) делает join из n символов. Всего O(n · 2l) в худшем случае. Для "a1b2" вызовов 13, и это не больше 5 · 4 = 20, а join пишет 4 · 4 = 16 символов. При n = l = 12 вызовов 8191, а join пишет 12 · 4096 = 49 152 символа.

Дополнительная память: path хранит до n символов, а Call Stack держит до n + 1 вызовов dfs: O(n). Ответ занимает n · 2l символов: цифры есть в каждом ответе.

Решение 2. Расширение префиксов в цикле

Те же ответы можно строить без Recursion. После i шагов цикла list level хранит все варианты первых i символов s. Сначала level = ['']: один пустой префикс. Символ ch продлевает каждый префикс каждой своей формой. Для "a1b2" после символов a, 1, b и 2 в level 2, 2, 4 и 4 префикса. Последний level и есть ответ.

Вариант первых i + 1 символов состоит из варианта первых i символов и одной формы символа s[i]. Запись [p + c for p in level for c in options] берёт каждую пару из префикса p и формы c один раз. Поэтому новый level содержит каждый вариант ровно один раз.

class Solution:
    def letterCasePermutation(self, s: str) -> list[str]:
        level = ['']
        for ch in s:
            options = (ch.lower(), ch.upper()) if ch.isalpha() else (ch,)
            # каждый префикс продлеваем каждым вариантом символа ch
            level = [p + c for p in level for c in options]
        return level

Время: шаг с символом номер i, считая с 1, создаёт до 2l новых String длины i. Всего это не больше 2l · (1 + 2 + ... + n) = 2l · n(n + 1)/2 символов: O(n² · 2l) в худшем случае. Для "a1b2" шаги пишут 2 + 4 + 12 + 16 = 34 символа, а join решения 1 пишет 16. Больше всего работы, когда буквы стоят в начале: каждая следующая цифра снова копирует все префиксы. Для "a" и 11 цифр после неё решение 2 пишет 2 · (1 + 2 + ... + 12) = 156 символов, а ответ занимает 24. При n = l = 12 решение 2 пишет 90 114 символов: это наибольшее число для n ≤ 12, и оба решения проходят все тесты.

Дополнительная память: пока строится новый level, старый ещё хранится. Для "a1b2" перед последним шагом старый level хранит 4 String по 3 символа: 12 символов. У решения 1 path на этом входе хранит не больше 4 символов. Каждый уровень содержит до 2l String длины до n, поэтому дополнительная память O(n · 2l) в худшем случае. Последний level в эту оценку не входит: это ответ.

Типичные ошибки

  • Две формы для каждого символа. У цифры ch.lower() и ch.upper() равны. Для "3z4" такой код вернёт 8 String: каждый из 2 ответов по 4 раза.
  • Проверка ch.islower() вместо ch.isalpha(). Заглавная буква тогда получает одну ветку. Для "aB" выйдет 2 ответа вместо 4: ответы "ab" и "Ab" пропадут.
