Greedy

В третьем примере d = 4. Из точки 1 можно прыгнуть на лилию в точке 2 или 3. Выберем точку 3. Если каждый раз брать самую дальнюю доступную лилию, получим путь 1 → 3 → 6 → 8 за три прыжка.

Пусть другая лягушка сначала прыгнет в точку 2. Если следующим прыжком она попадёт в точку 3, наша уже там. Если она выберет точку 6, наша тоже туда допрыгнет, ведь 6 − 3 = 3 ≤ 4.

Обе лягушки стартуют в точке 1. Пусть после одинакового числа прыжков наша лягушка стоит в точке pos, а другая не правее неё. Если другая прыгнет в точку pos или левее, наша уже добралась как минимум до этой точки. Если другая прыгнет правее pos, расстояние от pos до её новой лилии не больше, чем от прежней точки другой лягушки до этой же лилии. Прыжок другой лягушки не длиннее d, поэтому от pos до этой лилии тоже не больше d. Наша может выбрать эту лилию или прыгнуть ещё дальше. Так после каждого прыжка наша лягушка остаётся не левее другой. Значит, ни один путь не приведёт домой за меньшее число прыжков.

Во втором примере расстояние между соседними лилиями равно 4 − 1 = 3, а d = 2. Если промежуток между соседними лилиями длиннее d, с левой лилии до правой не допрыгнуть. Из любой точки левее пришлось бы прыгнуть ещё дальше. Поэтому ответ во втором примере равен -1.

Чтобы не просматривать точки повторно, код идёт по строке один раз слева направо. Переменная pos хранит текущую точку, last хранит номер последней найденной лилии, а jumps считает прыжки. В начале pos = last = 1 и jumps = 0, а переменная point по очереди проходит точки от 2 до n. В третьем примере n = 8 и d = 4, поэтому сначала point проверяет точки 2, 3, 4, 5 до границы 1 + 4 = 5. После лилий в точках 2 и 3 переменная last равна 3, а точки 4 и 5 пусты ("0"). На границе 5 код задаёт pos = last (теперь pos = 3 и last == pos) и увеличивает jumps на 1. Точки 4 и 5 уже проверены и пусты, поэтому point идёт дальше с точки 6. Из точки 3 граница равна 3 + 4 = 7, и в точке 7 код прыгает в last = 6. Из точки 6 сумма 6 + 4 = 10 > 8, поэтому правую границу ограничивают числом n: min(6 + 4, 8) = 8. На границе 8 стоит лилия, поэтому last = 8, и код засчитывает третий прыжок в точку 8.

На любом входе цикл сдвигает point от 2 до n и при s[point - 1] == "1" обновляет last = point. Когда point доходит до границы min(pos + d, n), код проверяет last. Без min при pos + d > n цикл закончился бы при point = n, и код пропустил бы последний прыжок. В начале и сразу после каждого прыжка pos = last верно равенство last == pos. Если на границе всё ещё last == pos, значит после pos до границы не встретилось ни одной лилии ("1"). Тогда доступной лилии впереди нет, код ставит jumps = -1 и прерывает цикл. Иначе код прыгает в last (pos = last) и увеличивает jumps на один. Все точки после last до старой границы содержат "0", поэтому перепроверять их не нужно и поиск идёт дальше с point + 1. При point < n старая граница равна pos + d = point, а прыжок pos = last делает pos строго больше прежнего. Поэтому и новое pos + d, и n больше point, так что граница min(pos + d, n) сдвигается строго правее point. Граница всегда не меньше point, поэтому при point == n она равна n. В точке n всегда стоит "1", а прежнее pos меньше n, поэтому last = n больше pos: код засчитывает последний прыжок, и цикл заканчивается.

import sys

n, d = map(int, sys.stdin.readline().split())
s = sys.stdin.readline()
pos = last = 1
jumps = 0
for point in range(2, n + 1):
    if s[point - 1] == "1":
        last = point
    if point == min(pos + d, n):
        if last == pos:
            jumps = -1
            break
        pos = last
        jumps += 1
print(jumps)

Время: O(n) в худшем случае. Программа читает все n символов и проверяет каждую точку после старта не более одного раза. Дополнительная память: O(n) в худшем случае с учётом чтения и O(1) сверх входной строки. В s хранится до n + 1 символов с учётом перевода строки. Только первую строку split() разбивает на список из двух коротких частей. При n ≤ 100 команда print сразу выводит не более двух знаков числа и перевод строки. Во входе один случай, поэтому эти оценки относятся и ко всей программе.
