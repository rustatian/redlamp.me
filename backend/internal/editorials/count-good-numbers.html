При n = 2 первая цифра 0 даёт строки 02, 03, 05 и 07. В начале строки может стоять 0, 2, 4, 6 или 8. За любой из этих пяти цифр могут идти те же четыре цифры. Всего получается 5 · 4 = 20 строк.

Для длины 4 начнём с одной пустой строки. При добавлении позиции умножаем число строк на число допустимых цифр. Получится 5 · 4 · 5 · 4 = 400. Если после каждого умножения брать остаток, такой цикл займёт O(n) времени в худшем случае. При n = 1015 он выполнит 1015 умножений и не уложится в 3 с.

Решение. Product Rule и Binary Exponentiation

При n = 3 на каждую из позиций 0 и 2 подходят пять цифр, а на позицию 1 подходят четыре простые цифры. Поэтому строк длины 3 ровно 52 · 4 = 100. Допустимые цифры зависят только от чётности позиции, поэтому подходит любая комбинация разрешённых цифр. Разные комбинации дают разные строки. По Product Rule перемножаем числа вариантов для всех позиций.

Разобьём позиции на пары (0, 1), (2, 3) и так далее. В каждой паре одна позиция чётная, а другая нечётная. При n = 3 остаётся чётная позиция 2 без пары, поэтому чётных позиций (3 + 1) // 2 = 2. При n = 4 выражения 4 // 2 и (4 + 1) // 2 дают 2, поскольку // округляет вниз. При нечётной длине после пар остаётся ещё одна чётная позиция. Поэтому число нечётных позиций odd = n // 2, а число чётных even = (n + 1) // 2. После группировки одинаковых множителей получаем 5even · 4odd.

При n = 14 это произведение равно 57 · 47 = 1 280 000 000. Остаток от деления на mod = 1_000_000_007 равен 279 999 993.

В выражении 4 ** odd % mod Python сначала вычисляет степень целиком. При odd = 2 число 42 = 16 имеет двоичную запись 10000 из 5 бит. Так как 4 = 22, получаем 4odd = 22 · odd. В двоичной записи этой степени после единицы идут 2 · odd нулей. При n = 1015 имеем 2 · odd = 1015, поэтому для записи степени нужно 1015 + 1 бит. Встроенная функция pow(4, odd, mod) берёт остатки при вычислении степени.

При делении на 5 числа 7 и 8 дают остатки 2 и 3. Произведения 7 · 8 = 56 и 2 · 3 = 6 дают один и тот же остаток 1. Их разность 56 − 6 = 50 делится на 5. Когда заменяем множитель его остатком, отбрасываем число, кратное mod. После умножения на другой множитель эта часть тоже делится на mod. Поэтому можно брать остаток и при вычислении каждой степени, и после умножения двух результатов.

При n = 9 для чётных позиций нужна степень 55. Оставим одну пятёрку отдельно, а остальные четыре разобьём на две пары. Получится 5 · 252. Два множителя 25 дают 625, поэтому 55 = 5 · 625 = 3125.

Функция power хранит в result произведение уже выбранных множителей по модулю mod. Если exponent нечётный, умножаем result на один множитель base и берём остаток. Остальные множители образуют пары. Записываем в base остаток его квадрата, а в exponent оставляем число пар. Когда показатель доходит до нуля, все нужные множители уже учтены в result.

При n = 1 нечётных позиций нет. Вызов power(4, 0) сразу возвращает начальное значение result = 1, и ответ равен 5 · 1 = 5.

class Solution:
    def countGoodNumbers(self, n: int) -> int:
        mod = 1_000_000_007

        def power(base: int, exponent: int) -> int:
            result = 1
            while exponent:
                if exponent % 2:
                    result = result * base % mod
                base = base * base % mod
                exponent //= 2
            return result

        even = (n + 1) // 2
        odd = n // 2
        return power(5, even) * power(4, odd) % mod

Время: O(log n) в худшем случае. За шаг цикл выполняет не больше двух умножений и делит показатель на 2 с округлением вниз. Даже при n = 1015 каждый из двух вызовов power делает 49 шагов. Дополнительная память: O(1) в худшем случае. В цикле меняются только основание, показатель и текущий результат.
