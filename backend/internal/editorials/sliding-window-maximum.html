n - длина nums, окон n − k + 1. Соседние окна отличаются двумя числами: справа входит nums[i], слева выходит nums[i - k]. Поэтому каждое окно не нужно читать заново.

Решение 1. Monotonic Deque

Возьмите пример 1: nums = [1, 3, -1, -3, 5, 3, 6, 7], k = 3. При i = 4 приходит x = 5. С этого шага число −3 с номером 3 попадёт ещё в два окна: [−1, −3, 5] и [−3, 5, 3]. Оба окна содержат и 5 с номером 4, а 5 больше −3. Поэтому −3 уже не станет максимумом. Число −1 с номером 2 попадёт только в окно [−1, −3, 5], и там тоже есть 5. Число 3 с номером 1 уже вне окна. Все три числа можно забыть.

Deque dq хранит номера чисел, которые ещё могут стать максимумом. Их значения слева направо строго убывают, а максимум окна стоит первым: nums[dq[0]].

Правило. Пришло число x = nums[i]. Сзади удалите из dq все номера со значением ≤ x. Добавьте i в конец. Если dq[0] ≤ i − k, этот номер вышел из окна: удалите его спереди. С i = k − 1 записывайте в ответ nums[dq[0]].

Удаление сзади ничего не теряет. Пусть x = nums[i] удаляет номер j, тогда j < i и nums[j] ≤ x. Окна с шага i кончаются на номере i или правее. Если такое окно содержит номер j, оно содержит и номер i, а x не меньше nums[j]. Поэтому без nums[j] максимум окна тот же. При nums[j] = x остаётся более новый номер i: он выйдет из окна позже.

С шага i = k окно за шаг теряет ровно один номер: i − k. Номера в dq растут слева направо. После прошлого шага все они в прошлом окне, то есть не меньше i − k. Поэтому выйти может только dq[0], и одного popleft хватает. После него все номера dq в окне. В примере 1 popleft не нужен ни разу: pop удаляет каждый старый номер раньше. Например, номер 1 выходит из окна при i = 4, но pop удаляет его на этом же шаге до проверки dq[0]. На входе [9, 1, 1, 1], k = 2 при i = 2 номер 0 выходит из окна, и popleft удаляет его.

После удалений сзади все значения в dq больше x, и номер i встаёт в конец. Поэтому значения слева направо строго убывают: при i = 5 в dq номера 4 и 5 со значениями 5 и 3. Каждое число окна, которого нет в dq, удалено сзади более новым и не меньшим числом. Если и оно удалено, то удалено ещё более новым и не меньшим числом, и так до номера из dq. Все эти номера стоят между удалённым номером и i, то есть в окне. Значит, наибольшее число окна есть в dq. Все номера dq в окне, а значения убывают, поэтому это nums[dq[0]]. В окне [3, 6, 7] при i = 7 число 3 с номером 5 удалено при i = 6 числом 6 с номером 6. Число 6 удалено при i = 7 числом 7 с номером 7, а номер 7 есть в dq. Номера 5, 6 и 7 в окне, и nums[dq[0]] = 7.

from collections import deque


class Solution:
    def maxSlidingWindow(self, nums: list[int], k: int) -> list[int]:
        dq = deque()  # номера; их значения слева направо строго убывают
        res = []
        for i, x in enumerate(nums):
            while dq and nums[dq[-1]] <= x:
                dq.pop()  # x новее и не меньше: старое число уже не станет максимумом
            dq.append(i)
            if dq[0] <= i - k:
                dq.popleft()  # номер i - k вышел из окна
            if i >= k - 1:
                res.append(nums[dq[0]])
        return res

Время: каждый номер один раз входит в dq через append и не больше одного раза выходит через pop или popleft. Поэтому вызовов append ровно n, а вызовов pop и popleft вместе не больше n. Каждая проверка условия while либо ведёт к pop, либо заканчивает while: проверок не больше 2n. Всего O(n) в худшем случае. В примере 1 код делает 8 append, 7 pop, ни одного popleft и 15 проверок условия while. Дополнительная память: после шага в dq только номера окна, их не больше k. Перед проверкой dq[0] там может быть ещё вышедший номер i − k. Всего не больше k + 1 номеров: O(k). Для [5, 4, 3, 2, 1] при k = 2 и i = 2 в dq номера 0, 1 и 2. Ответ res отдельно: n − k + 1 чисел.

Решение 2. Heap с отложенным удалением

heapq - это Min-Heap, поэтому код хранит пары (-x, i): в h[0] пара с наибольшим x. Модуль heapq не умеет удалять пару из середины. Поэтому пара, которая вышла из окна, остаётся в h, пока не окажется в h[0]. Тогда while удаляет её через heappop.

В примере 1 при i = 3 в h[0] пара (-3, 1). Номер 1 больше i − k = 0, пара в окне, ответ 3. При i = 7 окно [3, 6, 7] занимает номера 5, 6 и 7, а в h все 8 пар. Пять пар с номерами от 0 до 4 вне окна, но ни одна из них не попала в h[0] после выхода из окна. Поэтому heappop в примере 1 не нужен ни разу.

Каждая пара окна есть в h: её номер больше i − k, и while её не удаляет. После while пара h[0] в окне. Она наименьшая в h, то есть её x наибольшее среди всех пар h, а значит, и среди пар окна. Поэтому максимум окна равен -h[0][0]. На входе [9, 1, 1, 1], k = 2 при i = 2 в h[0] пара (-9, 0). Номер 0 ≤ 2 − 2, и heappop удаляет её. Новая пара h[0] = (-1, 1) в окне, ответ 1.

import heapq


class Solution:
    def maxSlidingWindow(self, nums: list[int], k: int) -> list[int]:
        h = []  # пары (-x, i): в h[0] наибольшее x
        res = []
        for i, x in enumerate(nums):
            heapq.heappush(h, (-x, i))
            while h[0][1] <= i - k:
                heapq.heappop(h)  # вершина вышла из окна
            if i >= k - 1:
                res.append(-h[0][0])
        return res

Время: код делает n вызовов heappush. Каждая пара удаляется не больше одного раза, поэтому вызовов heappop не больше n. В h не больше n пар, и каждый вызов стоит O(log(n + 1)). Всего O(n log(n + 1)) в худшем случае. Дополнительная память: O(n) в худшем случае. На возрастающем входе каждое новое число встаёт в h[0], и старые пары туда не поднимаются: для [1, 2, 3, 4, 5], k = 3 в конце в h все 5 пар. Ответ res отдельно: n − k + 1 чисел.

Что не подходит

Brute Force ищет максимум каждого окна заново и читает все его k чисел: (n − k + 1) · k чтений, O((n − k + 1) · k). В примере 1 это 6 · 3 = 18 чтений. Произведение (n − k + 1) · k наибольшее при k около n / 2. При n = 105 и k = 5 · 104 это 50 001 · 50 000 = 2 500 050 000 чтений: слишком долго.

Типичные ошибки

  • Нет проверки dq[0] <= i - k. Тогда старый максимум остаётся в dq[0] и после выхода из окна. Для [9, 1, 1, 1], k = 2 ответ [9, 9, 9] вместо [9, 1, 1].
  • Deque значений вместо номеров. Код хранит в dq сами числа, сзади удаляет числа ≤ x и удаляет dq[0], когда оно равно вышедшему nums[i - k]. Для [7, 7, 2], k = 2 при i = 1 вторая 7 удаляет первую. При i = 2 выходит nums[0] = 7, и код удаляет вторую 7, хотя она ещё в окне. Ответ [7, 2] вместо [7, 7].
  • Запись ответа с i = 0. Первые k − 1 записей идут для неполных окон. Для примера 1 ответ [1, 3, 3, 3, 5, 5, 6, 7] из 8 чисел вместо 6.
