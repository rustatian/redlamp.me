При n = 5 строки **D**, *DDD* и DDDDD образуют верхнюю половину ромба вместе с серединой. Ниже те же отступы идут в обратном порядке: сначала по одной звёздочке с каждой стороны, затем по две.

Пронумеруем строки с нуля: при n = 5 это строки 0, 1, 2, 3 и 4. Средняя строка имеет номер 2, и целочисленное деление 5 // 2 тоже даёт 2. Для нечётного n над серединой и под ней лежит по n // 2 строк, поэтому у средней строки номер middle = n // 2. За каждый шаг от неё вверх или вниз с каждой стороны добавляется одна звёздочка. Обозначим номер текущей строки через i. При i = 1 разность 1 − 2 равна −1, а до средней строки один шаг. Функция abs вычисляет модуль разности и убирает знак минус, поэтому abs(1 - 2) даёт 1. Ниже середины abs(3 - 2) даёт 1, а abs(4 - 2) даёт 2. Поэтому расстояние gap = abs(i - middle) от строки i до середины даёт нужный отступ с обеих сторон.

В строке 1 между отступами остаётся место для 5 − 2 · 1 = 3 букв D. Если напечатать gap звёздочек слева и справа, то ровно n − 2 · gap букв заполнят промежуток между ними. При gap = 0 на средней строке выражение "*" * 0 даёт пустую строку "", а в общем случае "*" * gap повторяет символ gap раз. Функция print с sep="" печатает side, core и side подряд без пробелов.

n = int(input())
middle = n // 2
for i in range(n):
    gap = abs(i - middle)
    side = "*" * gap
    core = "D" * (n - 2 * gap)
    print(side, core, side, sep="")

Время: O(n2) в худшем случае на весь ввод: кристалл один, и в каждой из n строк программа печатает n символов и перевод строки. Дополнительная память: O(n) в худшем случае на весь кристалл. При чтении программа временно хранит цифры числа n ≤ 101: их не больше трёх, это O(1). Для вывода она строит строки side длины gap и core длины n − 2 · gap: вместе в них не более n символов, это O(n). В print программа дважды использует одну и ту же строку side. Готовые строки рисунка программа печатает сразу.
