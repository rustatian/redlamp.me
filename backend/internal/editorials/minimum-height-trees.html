В первом примере корень 1 даёт высоту 1, а от корня 0 до листа 2 уже два ребра. Чтобы сравнить высоты всех четырёх корней, можно из каждого обойти всё дерево. Тогда получится 4 · 4 = 16 посещений вершин. Для n корней такой перебор занимает O(n2) времени. При n = 20 000 это 400 000 000 посещений.

Решение 1. Два обхода BFS

Во втором примере самая дальняя вершина от 0 находится в конце пути 0 → 3 → 4 → 5. BFS извлекает из Deque сначала саму вершину 0, затем её соседей, потом вершины на расстоянии двух рёбер и так далее. Последнюю извлечённую вершину код берёт за a.

Теперь начнём BFS из a = 5. При переходе из 4 в 3 код записывает parent[3] = 4. Затем при просмотре соседей вершины 3 код пропускает 4. В parent[u] код записывает вершину, из которой пришёл в u. Из v можно идти ко всем соседям, кроме parent[v], потому что другого пути в уже посещённую часть дерева нет. От 5 до каждой из вершин 0, 1 и 2 по три ребра. Последней BFS извлекает b = 2. От 2 по parent получаем path = [2, 3, 4, 5].

В списке path четыре вершины, а рёбер в пути d = 3. Длина самого длинного пути в рёбрах называется диаметром. Середина этого пути лежит между 3 и 4, поэтому оба корня дают высоту 2. В первом примере у пути 0 → 1 → 2 два ребра, и середина приходится на саму вершину 1. При чётном d берём path[mid], где mid = d // 2. При нечётном d нужны вершины path[mid] и path[mid + 1]. Для одиночной вершины path = [0] и d = 0, так что ответом будет [0].

Почему два BFS находят диаметр и почему нужна его середина

Возьмём середину M ребра между 3 и 4. От неё до концов пути, 2 и 5, по 1,5 ребра. Путь от 0 до 5 проходит через M и имеет длину 3. Если идти из 0 к вершине 1 или 2 через M, в маршрут той же длины войдёт участок 3 → M → 3. Без этого участка остаётся путь длины 2 через вершину 3.

Теперь рассмотрим самый длинный путь длины d > 0 с серединой M. Обозначим расстояние от корня до M через t. От M половины этого пути ведут к его концам в разные стороны. Выберем ту половину, по которой можно идти дальше без обратного шага. Если корень совпадает с M, подойдёт любая половина. До выбранного конца расстояние от корня равно t + d / 2.

Если бы от какой-то вершины до M было больше d / 2, тем же способом мы получили бы путь длиннее d. Маршрут от корня через M до любой вершины имеет длину не больше t + d / 2. Расстояние до этой вершины не больше длины маршрута, поскольку шаги туда и обратно можно убрать. Значит, высота равна t + d / 2 и наименьшая она у вершин, ближайших к M.

В первом примере BFS из 0 последней извлекает вершину a = 3. От 3 через M = 1 до любого конца пути 0 → 1 → 2 ровно два ребра. У самой дальней от старта вершины a расстояние до M равно d / 2, иначе даже через M до неё было бы меньше t + d / 2. Возьмём a за корень и выберем в M половину диаметра, по которой можно идти без обратного шага. От a до выбранного конца получится d / 2 + d / 2 = d рёбер. Поэтому BFS от a находит второй конец диаметра даже при нескольких одинаково далёких вершинах.

from collections import deque


class Solution:
    def findMinHeightTrees(self, n: int, edges: list[list[int]]) -> list[int]:
        adj = [[] for _ in range(n)]
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)

        def bfs(start):
            parent = [-1] * n
            queue = deque([start])
            while queue:
                v = queue.popleft()
                for u in adj[v]:
                    if u != parent[v]:
                        parent[u] = v
                        queue.append(u)
            return v, parent

        a = bfs(0)[0]
        b, parent = bfs(a)
        path = [b]
        while path[-1] != a:
            path.append(parent[path[-1]])

        d = len(path) - 1
        mid = d // 2
        if d % 2 == 0:
            return [path[mid]]
        return [path[mid], path[mid + 1]]

Время: O(n) в худшем случае. Каждый BFS извлекает n вершин и просматривает 2 · (n − 1) записей о соседях. Дополнительная память: O(n) в худшем случае для списков соседей, parent, Deque и path.

Решение 2. Leaf Peeling

На пути 0 → 1 → 2 → 3 → 4 у вершин 0 и 4 по одному соседу. Удалим эти два листа вместе. Теперь по одному соседу у 1 и 3, а после их удаления останется вершина 2.

Если взять корнем лист 0, высота равна 4, а у его соседа 1 она равна 3. Пока вершин больше двух, у соседа листа есть хотя бы одна другая ветвь. Если сдвинуть корень с листа к соседу, все остальные вершины станут на ребро ближе, а до самого листа будет одно ребро. Поэтому высота уменьшится на один и лист можно исключить из ответа.

На пути из пяти вершин высота при корне 2 сначала равна 2, после первого слоя равна 1, а после второго равна 0. От корня 2 путь к вершине 1 можно продлить ещё на ребро до её соседа 0. Если бы у самой дальней вершины был сосед, кроме предыдущей вершины пути, он был бы на ребро дальше от корня. Поэтому все самые дальние от корня вершины оказываются листьями, и код удаляет их за один слой. Перед таким листом на пути стоит либо сам оставшийся корень, либо вершина с двумя соседями на пути. Путь до этой вершины сохраняется и на одно ребро короче пути до листа. Значит, высота всех оставшихся корней уменьшается на один, и корни с наименьшей высотой сохраняются.

Во втором слое leaves = [1, 3], а у вершины 2 ещё два соседа. Число оставшихся соседей вершины v называется её степенью. Код хранит это число в degree[v]. При удалении 1 значение degree[2] падает до 1, и код добавляет 2 в next_leaves. При удалении 3 оно падает до 0, а вершина 2 остаётся в списке. Так код добавляет вершину в next_leaves в тот момент, когда её степень падает до 1.

Удаление листьев сохраняет путь между любыми двумя оставшимися вершинами, потому что у каждой внутренней вершины пути есть два соседа на этом пути. Поэтому если у оставшейся вершины нет соседей, она осталась одна. Тогда remaining = 1 и следующая проверка remaining > 2 завершает цикл. В нашем примере после присваивания leaves = next_leaves код возвращает [2].

Во втором примере из условия после удаления листьев 0, 1, 2 и 5 остаётся только ребро [3, 4]. У каждого его конца по одному соседу, поэтому следующий слой удалил бы обе вершины. Если остались две вершины, сохранившийся путь между ними состоит из одного ребра. У обоих корней в оставшемся дереве высота 1, поэтому код возвращает обе вершины.

class Solution:
    def findMinHeightTrees(self, n: int, edges: list[list[int]]) -> list[int]:
        if n <= 2:
            return list(range(n))

        adj = [[] for _ in range(n)]
        for u, v in edges:
            adj[u].append(v)
            adj[v].append(u)

        degree = [len(neighbors) for neighbors in adj]
        leaves = [v for v in range(n) if degree[v] == 1]
        remaining = n
        while remaining > 2:
            remaining -= len(leaves)
            next_leaves = []
            for leaf in leaves:
                degree[leaf] = 0
                for u in adj[leaf]:
                    if degree[u] > 0:
                        degree[u] -= 1
                        if degree[u] == 1:
                            next_leaves.append(u)
            leaves = next_leaves
        return leaves

Время: O(n) в худшем случае. Каждую вершину код удаляет не больше одного раза. Суммарно при удалении он просматривает не больше 2 · (n − 1) записей о соседях. Дополнительная память: O(n) в худшем случае для списков соседей, степеней и двух слоёв листьев.
