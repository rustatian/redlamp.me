Нужно узнать, есть ли во входной строке все 26 латинских букв, независимо от регистра каждой буквы.

Решение. Hash Table

В строке AaB три символа, но только две разные буквы: a и b. Вызов ch.lower() переводит заглавную букву (например, 'A') в строчную ('a'), а строчную оставляет без изменений. Чтобы учесть обе формы буквы один раз, создадим set с именем seen и будем добавлять в него ch.lower(). В Python set хранит разные значения в Hash Table: повторная запись 'a' не меняет их число.

В первом примере после всех 12 символов в seen всего 9 букв. Например, z нет, поэтому ответ NO. Во втором примере среди 35 символов встречаются все 26 букв, и ответ равен YES. Каждая буква из строки попадает в seen при первом появлении. Латинских букв всего 26, поэтому размер seen равен 26 только при полном алфавите.

Пусть n - длина входной строки text. В первой строке ввода записано число n, а во второй - сама строка text. Цикл for ch in text проходит по всем символам прочитанной строки без использования n, поэтому первый вызов input() пропускает строку с числом n, а второй читает text.

input()  # пропускаем число n
text = input()
seen = set()
for ch in text:
    seen.add(ch.lower())
print("YES" if len(seen) == 26 else "NO")

Время: ожидаемое O(n) для всего ввода, где n - длина строки text. Строка с числом n (1 ≤ n ≤ 100) содержит до 3 цифр и читается за O(1), строка text из n букв читается за O(n), а цикл для каждой буквы делает одно добавление в set за ожидаемое O(1). Дополнительная память: O(1) в худшем случае сверх входной строки: в seen не больше 26 букв, а lower() обрабатывает один символ за раз. С учётом строки text из n символов всей программе нужно O(n) памяти. Программа сразу печатает ответ длиной не более 4 символов с учётом перевода строки.

Типичные ошибки

  • Если добавлять в seen сам символ ch без вызова ch.lower(), заглавная и строчная формы одной буквы попадают в seen как разные элементы. Во втором примере TheQuickBrownFoxJumpsOverTheLazyDog буквы 'O' и 'o' обе остаются в seen, поэтому его размер становится равен 27 вместо 26 и проверка len(seen) == 26 выводит NO вместо YES. Если же проверять len(seen) >= 26, то строка AaBbCcDdEeFfGgHhIiJjKkLlMm длиной 26 даёт 26 символов в seen при 13 буквах алфавита и ответ YES вместо NO.
  • Если проверять только длину строки n >= 26 вместо подсчёта разных букв, код проходит оба примера из условия: 12 < 26 даёт NO, а 35 >= 26 даёт YES. На входе из 26 одинаковых букв aaaaaaaaaaaaaaaaaaaaaaaaaa условие 26 >= 26 выводит YES, хотя в строке только 1 буква и правильный ответ равен NO.
  • Если читать вторую строку через sys.stdin.readline() без .strip(), в конец text попадает символ перевода строки '\n'. На 25 буквах abcdefghijklmnopqrstuvwxy в seen окажутся 26 символов (25 букв и '\n'), и программа выведет YES вместо NO. Во втором примере размер seen вырастет до 27, поэтому проверка len(seen) == 26 выведет NO. Если убрать первый вызов input(), программа во втором примере прочитает строку "35", запишет в seen только '3' и '5' и выведет NO.
