Окно - это k соседних клеток полоски.

Цена окна

Пример: s = "BBWBW", k = 3. Клетки в коде нумеруются с 0. Окон n − k + 1 = 5 − 3 + 1 = 3: BBW, BWB и WBW. В них 1, 1 и 2 клетки W.

Цена окна - число клеток, которые нужно перекрасить, чтобы окно стало чёрным. Отрезок BBB на клетках 0..2 требует перекрасить клетку 2: цена 1. Отрезок BBB на клетках 2..4 требует перекрасить клетки 2 и 4: цена 2. Цена окна равна числу W в нём: каждая W окна обязана стать B, а перекраска клеток вне окна ему не помогает. Окно из одних B стоит 0. Ответ - наименьшая цена окна, в примере 1. Во втором наборе примера k = n = 5: окно одно, в нём 2 клетки W, ответ 2.

Brute Force считает W в каждом окне заново: (n − k + 1) · k чтений на набор. При n = 2 · 105 и k = 105 это 100 001 · 100 000 = 10 000 100 000 чтений, около 1010: слишком долго.

Решение 1. Sliding Window

Окна BBW и BWB (клетки 0..2 и 1..3) имеют общие клетки 1 и 2. Окно сдвинулось на 1 клетку: клетка 3 вошла, клетка 0 вышла. Пусть w - число W в окне. Вошла W: w увеличивается на 1. Вышла W: w уменьшается на 1. Вошла или вышла B: w не меняется. Считать окно заново не нужно.

Для s = "BBWBW" и k = 3 окно 0..2 имеет w = 1. Вошла клетка 3 (B), вышла клетка 0 (B): w = 1 + 0 − 0 = 1. Вошла клетка 4 (W), вышла клетка 1 (B): w = 1 + 1 − 0 = 2. Значения w: 1, 1, 2, наименьшее 1.

На шаге r окно занимает клетки r − k + 1..r: клетка r вошла, клетка r − k вышла. В коде (s[r] == "W") даёт True или False, а в арифметике это 1 или 0. Первое окно - клетки 0..k − 1, его w считает s.count("W", 0, k). Цикл идёт по r от k до n − 1 и делает n − k сдвигов. Вместе с первым окном получается n − k + 1 окон: при n = 5 и k = 3 это 2 сдвига и 3 окна. При k = n сдвигов нет, окно одно.

import sys

t = int(sys.stdin.readline())
out = []
for _ in range(t):
    n, k = map(int, sys.stdin.readline().split())
    s = sys.stdin.readline()
    # w - число W в окне из k клеток
    w = s.count("W", 0, k)
    best = w
    for r in range(k, n):
        # клетка r входит в окно, клетка r - k выходит
        w += (s[r] == "W") - (s[r - k] == "W")
        best = min(best, w)
    out.append(best)
print("\n".join(map(str, out)))

Время: O(n) в худшем случае на набор: k чтений для первого окна и по 2 чтения на каждый из n − k сдвигов, всего 2n − k. Все наборы вместе имеют не больше 2 · 105 клеток, поэтому на весь вход нужно не больше 4 · 105 чтений. Дополнительная память: O(1) в худшем случае: только числа t, n, k, w, best, r и счётчик цикла по наборам. Запись s.count("W", 0, k) не копирует клетки, а s[:k].count("W") скопировала бы k клеток: O(k). Строка s и список out - вход и ответ, их считаем отдельно.

Решение 2. Prefix Sum

Пусть p[j] - число W среди первых j клеток. Для s = "BBWBW" получается p = [0, 0, 0, 1, 1, 2]: в первых 3 клетках BBW одна W, поэтому p[3] = 1. Окно из клеток 1..3 (BWB) считаем при r = 4: p[4] − p[1] = 1 − 0 = 1. Из первых 4 клеток вычли первую клетку, и остались клетки 1..3. Так для любого r: окно из клеток r − k..r − 1 содержит p[r] − p[r − k] клеток W. Значения r от k до n дают n − k + 1 окон. В примере r = 3, 4, 5, и разности равны 1, 1, 2. Цена окна не больше k, потому что в окне k клеток: в примере 1, 1 и 2 при k = 3. Поэтому best = k можно взять как начальное значение. Хотя бы одно окно есть, потому что k ≤ n.

import sys

t = int(sys.stdin.readline())
out = []
for _ in range(t):
    n, k = map(int, sys.stdin.readline().split())
    s = sys.stdin.readline()
    # p[j] - число W среди первых j клеток
    p = [0] * (n + 1)
    for i in range(n):
        p[i + 1] = p[i] + (s[i] == "W")
    best = k
    for r in range(k, n + 1):
        # окно из клеток r - k..r - 1 содержит p[r] - p[r - k] клеток W
        best = min(best, p[r] - p[r - k])
    out.append(best)
print("\n".join(map(str, out)))

Время: O(n) в худшем случае на набор: n шагов для p и n − k + 1 разностей. Дополнительная память: O(n) в худшем случае на набор: список p хранит n + 1 число, при n = 2 · 105 это 200 001 число. Решение 1 не хранит p. Зато p даёт число W в любом отрезке клеток, а не только в окне: для клеток a..b − 1 это p[b] − p[a].

Типичные ошибки

  • Последнее окно пропущено: при k < n цикл range(k, n - 1) делает на 1 сдвиг меньше. Для s = "WWBB" и k = 2 окна WW, WB и BB имеют 2, 1 и 0 клеток W. Без последнего окна ответ 1 вместо 0.
  • Вышедшая клетка не вычтена: в Sliding Window есть только w += (s[r] == "W"), и w не уменьшается. Для s = "WBBB" и k = 2 всюду w = 1, ответ 1 вместо 0.
  • Ответ считают как k минус длина самой длинной серии B. Для s = "BBWBB" и k = 5 это 5 − 2 = 3, а в единственном окне одна W: ответ 1.
