Решение 1. Brute Force по двум переменным

При n = 9 значение a = 4 уже слишком велико. Даже при b = 0 получим 42 + 0 = 16. При m = 3 значение b = 2 тоже слишком велико, потому что 22 = 4. Остаются четыре значения a от 0 до 3 и два значения b от 0 до 1.

Число b неотрицательно, поэтому a2 ≤ n. По той же причине b2 ≤ m, ведь a ≥ 0. Например, isqrt(3) даёт 1, поскольку 12 ≤ 3 < 22. Функция isqrt возвращает целую часть квадратного корня.

В range(4) последнее значение a равно 3, потому что range не включает правую границу. При a = 3 внутренний цикл по range(2) проверяет пары (3, 0) и (3, 1). Первая пара даёт 32 + 0 = 9 и 3 + 02 = 3. Вложенные циклы проверяют каждую пару в найденных границах ровно один раз. Если обе суммы совпали с входными числами, программа прибавляет единицу к answer.

from math import isqrt

n, m = map(int, input().split())
max_a = isqrt(n)
max_b = isqrt(m)
answer = 0

for a in range(max_a + 1):
    for b in range(max_b + 1):
        if a * a + b == n and a + b * b == m:
            answer += 1

print(answer)

При n = m = 1000 квадрат числа 31 равен 961, а квадрат числа 32 равен 1024. С учётом нуля циклы проверят 32 · 32 = 1024 пары. Для каждого из max_a + 1 значений a внутренний цикл проверяет max_b + 1 значений b. Время: O(√n · √m) в худшем случае. Дополнительная память: O(1) в худшем случае. Программа хранит границы, текущую пару и число совпадений.

Решение 2. Подстановка из первого уравнения

Пусть n = 14 и m = 28. При a = 2 первое уравнение даёт b = 14 − 4 = 10. Во втором уравнении получается 2 + 102 = 102, поэтому пара не подходит. При a = 3 получаем b = 14 − 9 = 5, и теперь 3 + 52 = 28. При a = 4 получилось бы b = 14 − 16 = −2, а по условию b ≥ 0.

При выбранном a первое уравнение даёт единственное значение b = n − a2. Перебор начинается с a = 0 и продолжается, пока a2 ≤ n. Каждая допустимая пара встречается при своём a, и для неё остаётся проверить только второе уравнение.

Из четырёх проверенных пар для 14 28 подходит только (3, 5). Для 4 20 получаются суммы 16, 10 и 2. Ни одна не равна 20, поэтому ответ равен 0. При n = m = 1 подходят обе пары (0, 1) и (1, 0). Если закончить поиск после первого совпадения, ответ уменьшится с 2 до 1.

n, m = map(int, input().split())
answer = 0
a = 0
while a * a <= n:
    b = n - a * a
    if a + b * b == m:
        answer += 1
    a += 1

print(answer)

При n = 1000 цикл проверяет 32 значения a и для каждого вычисляет одно b. Время: O(√n) в худшем случае. Дополнительная память: O(1) в худшем случае. Для следующей проверки программа меняет значения тех же переменных a и b.
