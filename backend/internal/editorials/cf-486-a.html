При n = 5 прямой цикл прибавит к сумме пять слагаемых. Цикл делает одно сложение на каждое слагаемое, поэтому при наибольшем n = 1015 потребуется 1015 сложений: такой цикл слишком медленный.

При n = 4 сгруппируем соседние слагаемые: (−1 + 2) + (−3 + 4) = 1 + 1 = 2. В каждой паре положительное число на единицу больше числа, которое мы вычитаем, поэтому сумма каждой пары равна 1. Целочисленное деление 4 // 2 = 2 даёт число полных пар. Если n чётное, все слагаемые входят в пары, поэтому ответ равен числу пар.

При n = 5 получаем 5 // 2 = 2: полных пар столько же, сколько при n = 4. После двух пар остаётся слагаемое −5, поэтому ответ равен 2 − 5 = −3.

Для любого n целочисленное деление pairs = n // 2 даёт число полных пар, и сначала запишем answer = pairs. При n = 4 остаток 4 % 2 = 0, а при n = 5 остаток 5 % 2 = 1. В проверке if n % 2: значение 1 истинно, а 0 ложно. Поэтому только при нечётном n строка answer -= n вычитает n, то есть прибавляет последнее слагаемое −n. При наименьшем n = 1 получаем 1 // 2 = 0 пар, 1 % 2 = 1 и answer = 0 − 1 = −1.

n = int(input())
pairs = n // 2
answer = pairs
if n % 2:
    answer -= n
print(answer)

Время: O(1) в худшем случае. При 1 ≤ n ≤ 1015 входное число содержит не более 16 цифр, помещается в 64-битное целое и читается за постоянное время. Программа выполняет 5 строк кода при чётном n и 6 при нечётном: чтение числа, // 2, % 2, самое большее одно вычитание -= и печать ответа длиной до 16 символов. Дополнительная память: O(1) в худшем случае. Программа хранит постоянное число целых чисел ограниченного размера: рабочую переменную pairs, а также входное число n и ответ answer, которые считаем отдельно. Временная строка от input() и запись ответа содержат не более 16 символов и также ограничены условием 1 ≤ n ≤ 1015.
